Search (1a)
Route /search?q=
Behaviour One pill searches titles and ingredients across originals and branches. "Write it" sends the query to Chat as the prompt. Chips filter: All, Under 30 min, Easy, Branches.
Empty result Accent-100 card that turns the query into a new recipe. Never a dead end.
Try: type "walnut", or "pizza" for the empty state.
Pantry sheet (1c)
Opened from the Explore card and the Pantry chip in Search.
Behaviour Recipes must use every listed ingredient. Count in the CTA updates live. Secondary action writes a new recipe with the same constraints.
Sheet 36px top radius, 44×5 grabber, backdrop neutral-900 at 45%, tap backdrop to close.
Recipe
Original recipe (2a)
Route /recipe/:id when parentId is null
Order Title + emoji blob (76px, organic radius), description, pills (author, time, difficulty, kcal), ingredients with stepper (18a), method, nutrition (collapsed), sibling carousel (3d).
Ingredients Tap to tick off while cooking (sage). Scaled amounts turn accent-700 with a "Scaled ×n" strip and Reset.
Footer Suggest (or Edit if yours) + Branch this recipe. Save, Branch, Suggest open the 5a sheet when signed out.
Branch recipe (2a + 2b)
Route /recipe/:id when parentId is set
Back Goes up the family, not through history: branch → parent → … → original → the list you came from. Changes and Tree go back to their recipe.
Family label Under the title, bold accent-2-700 "Banana bread variation", so a branch name like "Chocolate chunk" always reads in context. Search rows carry the same label.
Differences from original 230px hero (photo, or emoji on accent-200) with floating 44px controls; sage lineage strip (17a) replaces the description.
Breadcrumb Root and parent always shown; deeper paths collapse to "+N". Each crumb navigates. "See what changed" opens the diff vs parent.
Carousel Children of this recipe; on a leaf, its siblings ("Other ways from here"). Cards: 290px, 32px radius, Compare (diff vs this recipe) and Open. "The original" row links to root.
What changed (2c / 3e)
Route /recipe/:id/changes?vs= (default: parent)
Data diffRecipes() from ticket 2: ingredients matched by name before the comma, so amount edits are one "~" row.
Rows ~ changed accent-100, + added accent-2-100, − removed neutral-100 struck. Old value struck at the right.
Modes Changes only / Side by side (two minmax(0,1fr) columns, works at 320px). Only changed steps are listed, old text struck above new.
Entry points Breadcrumb link, carousel Compare, Timeline/Map stop card tags.
Suggest mode (9b)
Replaces SuggestChangeModal
Behaviour The page becomes the form: sage banner replaces the header, tapping an ingredient opens an inline amount editor with the accent ring. Sends a structured edit the author can apply in one tap.
Gap to fill Add a "General note" row at the end of the list for suggestions that aren't one line (9a's General).
Edit (8a)
Route /recipe/:id/edit · only the author
Fields Title with dashed accent-400 underline; amount (76px) and name pills on neutral-100; drag handle; remove; dashed "Add ingredient".
Footer States how many branches keep their own copy. Method editing uses the same row pattern (not shown).
Family
Tree (3a)
Route /recipe/:id/tree?view=tree|timeline|map
Connectors 3px, 16px elbow radius, 40px per depth. Rails continue for any ancestor with later siblings, so it generalises to any depth.
Path Elbows on the ancestry path to the current recipe are accent; current node gets accent-100 fill, 2px ring and a "Here" tag.
First visit Shows the 16a intro sheet once.
Timeline (3b)
Layout x by createdAt order (66px spacing), lanes 60px apart. A first child continues its parent's lane; other children open a new lane named after their prompt.
Colours Lane ramp cycles neutral-700, accent, accent-2-600, accent-400, accent-2-400. Ancestry path strokes are 7px, others 5px.
Stop Tap selects (2px ink ring) and fills the card below: generation, author, change tags, Open, Branch here.
Map (3c)
Layout Rings 78px apart per generation, dashed neutral-400. Angles are split by leaf count so big subtrees get more room.
Nodes Root filled ink; path nodes accent-200 with accent stroke; current node dashed outer ring.
Over ~20 versions Suggest switching to Timeline in a banner above the map.
Tree intro (16a)
Replaces TreeIntro. Its diagram is a scaled 3a (14px elbows, 36px indent), per the decisions.md rule that the intro mirrors the real tree.
Shown Once per device, on first tree visit. "Got it" or backdrop dismisses.
Create and branch
Branch composer (6b)
Route /recipe/:id/vary
Behaviour One instruction, quick-change chips append to it. Grow shows a skeleton card while generating, then opens What changed for the new branch.
Try: tap "Less sugar" then Grow.
Create tab (6c)
Behaviour Each underlined word cycles through three options. Write it builds the same prompt text the chat would and hands over to Chat. "My own way" goes to Search, whose Write it also feeds Chat.
Chat (6a)
Replaces RecipeChatPage
Behaviour The recipe is a collapsible card at the top; refinement chips sit above the composer. Save creates an original.
Dedup (7a) When the prompt matches an existing family, a sage banner offers to branch instead. See 7a to 7d.
