# Capabilities

Every feature, its status, where it lives, and what gates it. Verified against the code on
2026-07-31; rows added or changed since by a backlog ticket (RL-nnn) were written with that
ticket and carry its id. Several of those rows say "rules deployed by RL-051" or similar: the
rules are in the repo and not yet live, see the
[release runbook](operations.md#release-and-deploy-runbook-first-production-release).

Status values: **shipped** (works end to end), **partial** (works with a stated limit),
**cut** (deliberately not built — see [decisions.md](decisions.md)).

Gates: **local** works with no Firebase project configured; **firebase** needs
`VITE_FIREBASE_*`; **auth** needs a signed-in user (any account, anonymous included; reads only since RL-040);
**verified email** needs a signed-in user with a verified email (every cloud write since RL-040,
except view counts and error reports); **appcheck** additionally needs
`VITE_RECAPTCHA_SITE_KEY`.
