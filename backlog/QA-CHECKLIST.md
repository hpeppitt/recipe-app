## Preview

The GitHub preview deploy is skipped (the FIREBASE_SERVICE_ACCOUNT secret is not set), so build one locally:

```bash
npm run build && npx firebase hosting:channel:deploy qa --expires 7d
```

Open the channel URL on your phone, then tap Reload on the app so you are not seeing the old cached version.
