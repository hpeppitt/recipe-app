## Context

Organic specifies Lucide icons at stroke width 2.75 (`docs/design/organic/tokens.css`,
last comment line). The app has no icon library: about 30 hand-inlined Heroicons-style
SVGs at `strokeWidth={1.5}` across the 15 files listed in `files` (found with
`grep -rln "<svg" src`).

`lucide-react` is not installed. Adding it is a client-bundle dependency, which
`backlog/README.md` ("What needs a human") reserves for the author, hence
`risk: irreversible`. The author chooses at approval:

- **A. Add `lucide-react`** (ISC). Named imports are tree-shaken, so the bundle carries
  only the icons used. Becomes `ready` once the author approves the dependency here.
- **B. No dependency.** Copy the Lucide SVG paths (ISC permits it, keep the licence notice
  in a comment) into the existing inline-SVG pattern, `stroke-width="2.75"`. Then this
  ticket is `risk: reversible`.

Either way the result on screen is the same.

## Acceptance criteria

- [ ] Every `<svg>` icon under `src/` is replaced by its closest Lucide equivalent (examples: back `ChevronLeft`, library `BookOpen`, profile `User`, settings `Settings`, bell `Bell`, plus `Plus`, share `Share2`, minus `Minus`), rendered at `strokeWidth={2.75}` and the existing size classes. The implementer lists the mapping in Notes.
- [ ] Decorative icons keep `aria-hidden="true"`; icon-only buttons keep their `aria-label`. No accessible name changes.
- [ ] Option A only: `lucide-react` in `dependencies`, imported by name only (`import { Bell } from 'lucide-react'`), never the whole set. The build's main chunk grows by no more than about 10 kB gzip (report the before and after sizes from `npm run build`).
- [ ] Option B only: no new dependency; a one-line ISC attribution comment per file or one shared `src/components/ui/icons.tsx` holding all paths (the implementer picks; fewer files wins).
- [ ] `docs/architecture.md` names the icon source.
- [ ] A `backlog/QA.md` entry: at 390x844 check every screen's icons are the heavier Lucide style and none is missing or mis-sized.

## Out of scope

- Redesigning the bottom nav (open question) or adding new icons for screens that do not exist yet.
- Replacing emoji used as recipe icons or `EmptyState` icons.

## Verification

`npm run build` (bundle size before and after), `npm run lint`, `npm test`. `ui-reviewer`.
A human checks the icons visually (QA.md).
