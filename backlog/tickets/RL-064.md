## Context

Organic specifies Lucide icons at stroke width 2.75 (`docs/design/organic/tokens.css`,
last comment line). The app has no icon library: about 30 hand-inlined Heroicons-style
SVGs at `strokeWidth={1.5}` across the 15 files listed in `files` (found with
`grep -rln "<svg" src`).

`lucide-react` is not installed. Author decision 2026-10-19: no dependency. The Lucide SVG
paths (ISC licence) are copied into one shared `src/components/ui/icons.tsx` at
`stroke-width` 2.75.

## Acceptance criteria

- [x] Every `<svg>` icon under `src/` is replaced by its closest Lucide equivalent (examples: back `ChevronLeft`, library `BookOpen`, profile `User`, settings `Settings`, bell `Bell`, plus `Plus`, share `Share2`, minus `Minus`), rendered at `strokeWidth={2.75}` and the existing size classes. The implementer lists the mapping in Notes.
- [x] Decorative icons keep `aria-hidden="true"`; icon-only buttons keep their `aria-label`. No accessible name changes.
- [x] No new dependency; a one-line ISC attribution comment per file or one shared `src/components/ui/icons.tsx` holding all paths (the implementer picks; fewer files wins).
- [x] `docs/architecture.md` names the icon source.
- [x] A `backlog/QA.md` entry: at 390x844 check every screen's icons are the heavier Lucide style and none is missing or mis-sized.

## Out of scope

- Redesigning the bottom nav (open question) or adding new icons for screens that do not exist yet.
- Replacing emoji used as recipe icons or `EmptyState` icons.

## Verification

`npm run build` (bundle size before and after), `npm run lint`, `npm test`. `ui-reviewer`.
A human checks the icons visually (QA.md).

drawing SVGs. Small icons (14 to 16 px) use 2.75 too; QA asks for a visual check.
