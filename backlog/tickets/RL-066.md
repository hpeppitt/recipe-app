## Context

The Organic branching screens show what a variation changed: short change tags on the
timeline sheet (RL-070) and carousel cards (RL-075), and the full "What changed" screen
(RL-073). The author decided change tags and diffs are computed client-side from the two
recipes' ingredients and steps, with no schema or Firestore change
(`docs/design/organic/BRIEF.md`, "Decisions the author already made").

`Recipe`, `Ingredient` (`amount: number | null`, `unit: string | null`, `name`, `notes`,
`group: string | null`) and `Instruction` (`step`, `text`, `group`) are in
`src/types/recipe.ts`. Published cloud records carry ingredients and instructions (only
`chatHistory` is stripped), so a diff works on any node `useRecipeTree` returns.

Reuse, do not duplicate: `canonicalUnit` (`src/lib/units.ts`) to treat "g" and "grams" as
the same unit; `formatAmount` (`src/lib/amount.ts`) and `formatUnit` (`src/lib/units.ts`)
for display. Project rule (CLAUDE.md): nothing in `lib/` imports from `services/` or
`hooks/`.

The pure tree-layout tickets (RL-069, RL-071) are independent of this one. It has no
dependency on the theme tickets either: it is pure logic and can merge first.

## Acceptance criteria

- [x] `src/lib/recipeDiff.ts` exports `diffRecipes(parent: Recipe, child: Recipe): RecipeDiff` and `summariseChanges(diff: RecipeDiff, max: number): string[]`, plus the exported types. Imports only from `src/types` and `src/lib`.
- [x] Ingredient matching, one-to-one, in this order: (1) same normalised name and same `group`; (2) same normalised name, any group; (3) similar names among the leftovers, where one name's word set contains the other's (e.g. "butter" and "unsalted butter") or their word Jaccard is at least 0.5, best score first. Normalised name: lower case, punctuation to spaces, collapsed whitespace, a trailing plural `s` dropped per word ("bananas" matches "banana").
- [x] Each ingredient entry is one of `unchanged`, `changed` (with `before` and `after` ingredients), `added`, `removed`. An amount edit on the same ingredient is exactly one `changed` entry, never a removed plus an added. A unit change ("1 cup" to "240 ml") is `changed`. Units that `canonicalUnit` maps to the same key with the same amount are `unchanged`. A `null` amount on either side compares by unit and name only and never throws.
- [x] Method: steps aligned by longest common subsequence on normalised step text; identical steps are `unchanged`; a step between two aligned anchors that pairs by position with a step on the other side is `changed` and carries word-level spans `{ type: 'same' | 'insert' | 'delete', text }[]` (word LCS); unpaired steps are `added` or `removed`. Inserting one step in the middle yields one `added` step, not every later step `changed`.
- [x] `diff.totalTime` and `diff.servings` are `{ before, after, delta }`, `delta` 0 when equal.
- [x] `diff.identical` is true when there are no ingredient or step changes and both deltas are 0.
- [x] `summariseChanges` returns at most `max` short tags in this order: added, changed, removed ingredients, then method. Formats: an amount change with the same canonical unit is a signed delta, no space after the sign: `+1 banana`, `-50 g sugar`. An added ingredient: `+ 80 g walnuts`, or `+ purée swirl` with no amount. A removed ingredient: `- raisins`. Any other change (unit change, null amount): `~ butter`. A method change with no ingredient tags: `~ method`. If changes exceed `max`, the last slot is `+N more` and the result still has at most `max` entries. `max` of 0 returns `[]`; an identical diff returns `[]`.
- [x] `src/lib/recipeDiff.test.ts` uses `makeRecipe` and `makeIngredient` from `src/test/factories.ts` and covers at least: identical parent and child; an amount edit is one `changed`; added and removed ingredients; renamed-but-similar ("butter" to "unsalted butter") is `changed`; plural/singular match; unit change; `g` vs `grams` same amount is unchanged; null amounts on one and both sides; the same name in two groups pairs within its group; a step inserted mid-method; a reworded step yields insert and delete spans; time and servings deltas; `summariseChanges` formats, ordering, `+N more` truncation and `max` 0.
- [x] `docs/architecture.md` adds `recipeDiff` to the `lib/` pure-logic list in the diagram and one sentence on what it is for.

## Out of scope

- Any UI. RL-070, RL-073 and RL-075 consume this.
- Diffing `notes`, `tags`, `nutrition`, `description` or `title` (not in the design).
- Fuzzy matching beyond the rules above (edit distance, synonyms).
- Any persisted change data: no schema, Dexie or Firestore field.
