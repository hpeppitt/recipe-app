## Context

`/search` (RL-124, `src/pages/SearchPage.tsx`) searches the device and the loaded shared pages
with chips All, Under 30 min, Easy, Branches, keeping `?q=` and `?f=` in the URL with
`replace`. The spec adds a Pantry chip opening the 1c sheet. RL-168 has the matching and prompt
helpers. Sheets use `components/ui/Sheet.tsx` (36px top radius, grabber, backdrop, dialog
semantics). Token mapping: spec "surface" is `bg-surface-secondary`, ground is `bg-surface`.

### The design (the implementer has no other copy)

**Pantry chip**: first in the chips row, before All. 34px tall pill, `bg-neutral-100`, inset
1px `divider` ring, `SlidersHorizontal` icon, 13px "Pantry", padding 0 12px, gap 6px. When a
pantry filter is active it takes the active chip style and reads "Pantry · 3".

**Sheet** (padding 12px 22px 28px, 18px gaps):
- Header row: Caprasimo 24px "What have you got?" with a "Reset" text button at the right
  (13px semibold `accent-700`) that clears items and sets Time to Any.
- "Ingredients" label (12px semibold `neutral-700`, 8px below). Wrap of chips, 8px gap: each
  item a button pill `bg-accent-200` `text-accent-900` 14px, padding 7px 10px 7px 14px, with an
  `X` (accessible name "Remove eggs"). Last, a dashed "Add" pill (1.5px dashed `neutral-500`,
  `text-neutral-800`, `Plus`) that turns into an inline text field in the same pill shape;
  Enter or a comma adds the item, Escape cancels, empty input does nothing.
- "Time" label, then a segmented control (`components/ui/SegmentedControl.tsx`) with 15 min,
  30 min, 1 hr, Any (default Any).
- Footer, 6px gap: primary 52px block button "Show N recipes" ("Show 1 recipe", or "Show
  recipes" while N is 0), and a ghost 44px button with `Sparkles` "Or write a new one with these".
- Show applies the filter to Search, closes the sheet and moves focus to the results. N is
  counted live from the same data Search has (device plus loaded shared pages).
- "Or write a new one with these" opens `/create` with `state: { suggestion: buildPantryPrompt(...) }`
  (unsent, the same hand-off Write it uses); local-only mode hides it.

**Results while a pantry filter is active**: the query box is cleared, the results are
`filterPantry` over originals and branches, and a 13px `neutral-700` line above them reads
"Using eggs, tomatoes, feta · under 30 min" (no "under" part for Any). The scope line and live
region keep working. Typing a query clears the pantry filter.

**URL**: the filter lives in `?p=eggs,tomatoes,feta&pt=30` written with `replace`, so Back from
a result restores it, like `?q=` and `?f=`. `?sheet=pantry` opens the sheet on load (RL-170
uses it).

## Acceptance criteria

- [ ] Chip, sheet, results line and URL behave as above.
- [ ] The sheet is keyboard operable: focus starts on the first chip or Add, Tab order follows the layout, Escape closes, focus returns to the Pantry chip.
- [ ] Tests: add and remove items, live count, Show filters and writes the URL, reload with `?p=` restores, write-a-new-one navigates with the built prompt, typing a query clears the filter, local-only hides the write action.
- [ ] `docs/capabilities.md` Search row lists the Pantry chip and sheet, its scope (the same device plus loaded pages) and URL params.
- [ ] A `backlog/QA.md` entry: on a phone, open Search, Pantry, add three items by typing, pick 30 min, see the count change as items are added, Show, check the Using line and results, open one and come Back, then Or write a new one: the chat composer holds "Something with ... in under 30 minutes" unsent. Light and dark.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
