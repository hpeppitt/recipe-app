## Context

Written for RL-184's recommended answers 1, 4 and 5; regroom if the author chose otherwise.
Generation goes through Firebase AI Logic (`services/gemini.ts`, `responseSchema` in
`src/schemas/recipe.responseSchema.ts`, prompts in `src/lib/prompts.ts`; docs/architecture.md
"AI path"). This is a separate one-shot call, not a chat session, so the chat's history and
photo handling are untouched. Generation path, so tier hard.

## Acceptance criteria

- [ ] First, confirm that URL context works on the AI Logic free tier for the project's model (one live call from the dev app, or Firebase docs that say so). If it does not, stop with status `needs-human` and propose the paste-text fallback (RL-184 question 1c).
- [ ] `src/lib/linkImport.ts`: `normalizeImportUrl(input)` (trims, adds `https://` when missing, accepts only http and https, rejects localhost, IP literals and non-public hosts), `importHost(url)` ("seriouseats.com"), and `toImportDraft(response, url)` validating the model output with the existing recipe schema plus per-ingredient `uncertain?: boolean`, returning `{ recipe, uncertainCount, error }`. Tests for each.
- [ ] `IMPORT_SYSTEM_PROMPT` in `lib/prompts.ts`: extract the recipe exactly as written; never invent or convert amounts; when an amount is unreadable set `amount: null` and `uncertain: true`; keep the source's title and steps; choose an emoji; return the schema.
- [ ] `importRecipeFromUrl(url)` in `services/gemini.ts` calls the model with the URL context tool and the import response schema, bounded at 30 s, and returns `toImportDraft` output. Errors map to "Couldn't read that page. Check the link, or try a photo of it." Telemetry never includes the URL path (host only), matching the route-only rule.
- [ ] `Recipe` gains optional `importedFrom?: string` and `importedVia?: CreatedBy` (types only here; RL-186 writes them). The share schema keeps them when present.
- [ ] Generation gates are unchanged: same `canGenerate`, App Check, verified email.
- [ ] Service tests with the AI SDK mocked: tool passed, schema used, timeout, error mapping, uncertain count.
- [ ] `docs/architecture.md` AI path section describes the import call; `docs/capabilities.md` gains an "Import from a link" row marked partial (no UI yet).
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
