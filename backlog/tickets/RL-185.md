- [x] `src/lib/linkImport.ts`: `normalizeImportUrl(input)` (trims, adds `https://` when missing, accepts only http and https, rejects localhost, IP literals and non-public hosts), `importHost(url)` ("seriouseats.com"), and `toImportDraft(response, url)` validating the model output with the existing recipe schema plus per-ingredient `uncertain?: boolean`, returning `{ recipe, uncertainCount, error }`. Tests for each.
- [x] `IMPORT_SYSTEM_PROMPT` in `lib/prompts.ts`: extract the recipe exactly as written; never invent or convert amounts; when an amount is unreadable set `amount: null` and `uncertain: true`; keep the source's title and steps; choose an emoji; return the schema.

## Notes

- Free tier check answered from the docs, no live call: Firebase AI Logic's URL context page (updated 2026-10-20) supports web via `tools: [{ urlContext: {} }]` with GoogleAIBackend, lists gemini-3.6-flash as supported, and excludes paywalled, signed-in, localhost and private-network pages; max 20 URLs, 34 MB each; content may not be live. The Gemini API pricing page lists URL context as "Free of charge" on the free tier (retrieved content counts as input tokens on paid).
- No docs page confirms URL context with `responseSchema`. The call sends both; the prompt asks for the same JSON and `toImportDraft` parses and validates it, so dropping `generationConfig` is the fallback. Logged in backlog/DECISIONS.md (pending); RL-186 QA must confirm with the live call.
- `toImportDraft(response, url)` takes the model's text. It forces an uncertain amount to null, and treats a reply with no ingredients or no steps as no recipe. `importRecipeFromUrl` never throws: every failure, including a refused URL, returns `{ recipe: null, uncertainCount: 0, error }` with the one message.
- Telemetry carries no part of the URL. The failure console warning names the host only.
- `lib/share.ts` was touched (not in `files:`) because the share schema criterion lives there.
- Not touched: `ImportedRecipeSchema` (export file import) strips `importedFrom`/`importedVia`, and the Firestore write path and rules do not know them yet; RL-186 needs both.
- Review fixes: `toImportDraft` refuses drafts past the `hasBoundedContent()` caps (title 200, ingredients 100, instructions 100; `IMPORT_LIMITS`). A share hash `importedFrom` must be http(s) and at most 2048 characters, or the field is dropped and the rest of the link still opens. The failure warning logs the error name only, not the SDK error.
