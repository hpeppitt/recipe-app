## Context

`SuggestionThreadPage.tsx` (RL-106, route `/recipe/:id/suggestion/:suggestionId`, name kept by
the author) pins the suggestion as raw text (~203-216) and has an owner footer Decline / Approve
(~285-300). RL-149 adds `SuggestionDiffRow`; RL-148 the actions.

### Design (10a)

Pinned card (surface, radius 30px, padding 16px, gap 12px): avatar row "<b>Sami</b> on
<b>Less sugar</b>" and time, then the diff rows (in the thread the row is radius 18px, padding
10px 14px, 15px text, with a leading "~" in accent-800 bold), then the note. Header tag follows
the status labels of RL-149. Owner footer (pending only), gap 8px, 48px buttons: **Decline**
(secondary, flex 1), **Keep as branch** (secondary, flex 1.3, GitBranch icon; only with
applicable edits), **Apply** (primary, flex 1.2; **Mark applied** without applicable edits).

## Acceptance criteria

- [x] Pinned card and footer render as above; Approve is gone; a closed suggestion shows no owner footer.
- [x] Buttons call RL-148's hook with the shared in-flight guard; Keep as branch navigates to the new branch; Apply stays and the header tag turns Applied.
- [x] Tests: diff rows pinned; footer buttons by status and edits; Mark applied label; no footer for the suggester.
- [x] A `backlog/QA.md` entry. `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Bubble sides (stay "mine" right), the composer, the route name.

## Verification

Gates: tests, `ui-reviewer`. Human at 320px: three footer buttons fit without truncating
"Keep as branch"; the pinned card scrolls with the thread.
