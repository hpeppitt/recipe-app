## Context

12c (deferred from v1) and 30a/30b (Phase 4) both bring an existing recipe in as an original.
A browser cannot fetch an arbitrary recipe site (CORS), and decision 2 rules out a Cloud
Function (Blaze would end the free Gemini tier; docs/operations.md ~422). The installed
`firebase` (^12.9) AI Logic SDK exposes Gemini's URL context tool (`urlContext` in
`@firebase/ai` typings), which lets Gemini read the page server-side through the existing
AI Logic path, the same path that already accepts photos as generation input (RL-118). This
ticket is the author's choice; RL-185, RL-186 and the Phase 4 tickets are written for the
recommendation and are regroomable.

## Questions and the groomer's recommendation

1. **Reading a link**: (a) Gemini URL context through AI Logic, prompted to extract the recipe
   as written into the existing `responseSchema` (recommended; no server, no bill, App Check
   still applies); (b) a Cloud Function fetch (Blaze, against decision 2); (c) paste the page
   text instead of a link.
2. **Free tier check**: confirm URL context is available on the AI Logic free tier for the
   project's model (`gemini-3.6-flash`) before RL-185 starts; if not, fall back to (c).
3. **Photo of a page** (Phase 4 "Snap a page"): the RL-118 photo path, generation input only,
   never stored (recommended; already covered by decision 3's dated notes).
4. **Never guessed**: the model returns `amount: null` plus an `uncertain: true` flag per
   ingredient it could not read, and the review screen flags those (recommended; spec 30b).
5. **Credit**: the recipe keeps `importedFrom` (the URL, or "photo") and the importer is the
   author shown as "via <importer>" (recommended). New optional recipe fields, no rules change
   (recipe creates do not restrict keys).
6. **"Add to <family>"** on a dedup match: save the import as a branch of that family's
   original with prompt "Imported from <host>" (recommended) or as a new original linked with
   `relatedFamilyId` (RL-162's mechanism).
7. **Route**: `/import` (recommended), because `/shared` already serves hash share links and
   routes keep their names (spec Overrides).
8. **Copyright and terms**: imported recipes are published to the shared library. Recommend a
   Terms line that importers must have the right to share what they import, and that the source
   URL is always kept; author to approve wording (RL-190).
9. **Rate**: imports count as recipe creates (30 a day, RL-049) and generations; no new limit.
