## Context

Single-user in Phase 2; RL-240 adds household avatars and ageing. Data from `useKitchen`
(RL-213); `aisleFor` (RL-212) picks the group. "Cook from what's here" is 1c with the whole
pantry: link to `/search?p=<items>` (RL-169).

### The design (the implementer has no other copy)

- Back row, Caprasimo 30px "Pantry".
- An add field: 52px pill, `bg-neutral-100`, placeholder "Add things…", `Plus` button at the
  right; Enter or comma adds; several items separated by commas add at once.
- Groups (16px gap): 12px bold `neutral-700` "FRESH" and "CUPBOARD", each a wrap of pills
  (`bg-surface-secondary`, 14px, padding 7px 10px 7px 14px, gap 6px) with an `X` remove
  (name "Remove bananas").
- Footer: primary 52px block "Cook from what's here" on `bg-accent-2-700` with
  `text-accent-2-100` (`Sparkles`), disabled when the pantry is empty.
- Empty: 19a empty state "Your pantry is empty" · "Add what you have and we'll find recipes
  that use it." with the field still above.
