## Context

Almost every screen in the Organic export (`docs/design/organic/export/App Prototype.dc.html`)
repeats three pieces. Building them once first keeps the per-screen tickets small and the
shapes identical.

**Design token map** (design CSS variable to this repo's Tailwind class, `src/index.css`):
`--color-bg` is `bg-surface` (#f5ead8); `--color-surface` is `bg-surface-secondary`
(#ebddc5); `--color-text` is `text-text-primary`; neutral-800 text is `text-text-secondary`;
neutral-700 text is `text-text-tertiary`; ramps keep their names (`bg-accent-200`,
`text-accent-2-700`, `bg-neutral-100`); `--color-divider` is `border-border`. A filled
terracotta control with cream text uses `bg-primary-600 text-on-accent` (accent-700), not
`bg-accent`, because cream on #c67139 is 3.03:1 (RL-062). Light only (RL-065): write no
`dark:` classes. Keep 44px touch targets even where the design draws smaller.

1. **Emoji blob tile.** The recipe emoji on a soft organic shape:
   `border-radius: 58% 42% 52% 48% / 46% 56% 44% 54%`, emoji centred, emoji font size half
   the tile. Sizes used by the design: 52 (chat card), 72 (shared page, edit page), 76 (recipe
   title, emoji 38px), 84 (empty states and profile avatar, icon 36px), 150 (branch hero,
   emoji 78px). Default tint `bg-accent-200`. Photos are cut permanently (decision 3), so
   there is no image variant.
2. **User pill** (`User Pill.dc.html`): a `tag-neutral` pill, `bg-neutral-100 text-neutral-800`,
   12px, line-height 20px, `padding: 2px 10px 2px 2px`, gap 5px, `rounded-full`, no wrap. At
   the left a 20px circle holding the author's initial (10px, 700, `text-neutral-900`) on a
   tint; then the display name. Fallback name "Anonymous". The circle should reuse the
   existing `Avatar` component's generated look at 20px if that is simpler, so the colour
   matches the rest of the app; otherwise use `bg-accent-300`.
3. **Floating icon button**: 44px circle, `bg-surface`, `shadow-md`, icon 19 to 20px, used on
   the branch hero and elsewhere. A flat variant (no fill, no shadow) for header rows.

Icons: `src/components/ui/icons.tsx` holds Lucide paths (ISC) in one inline-SVG wrapper at
stroke width 2.75 with no dependency (RL-064). The new screens need these Lucide icons,
which are not there yet: `Compass`, `Bookmark`, `BookmarkCheck`, `GitBranch`, `GitBranchPlus`,
`Search`, `Clock`, `Gauge`, `Flame`, `Scale`, `MessageCircle`, `Send`, `ArrowUp`,
`ArrowRight`, `ChevronRight`, `ChevronUp`, `Diff`, `Sparkles`, `ShieldCheck`, `Mail`,
`MailOpen`, `Smartphone`, `CloudOff`, `RotateCw`, `Download`, `UserRound`, `UserPlus`,
`Link`, `Check`, `Hourglass`, `Image`, `Type`, `Ellipsis` (horizontal), `Wheat`, `Droplet`,
`Drumstick`.

## Acceptance criteria

- [x] `src/components/ui/EmojiBlob.tsx` exports `EmojiBlob({ emoji, size, tint?, className?, label? })` with `size` one of 52, 72, 76, 84, 120, 150; it renders the organic radius above, the tint (default `bg-accent-200`) and the emoji at half the size. It is `aria-hidden` unless `label` is given, in which case it has `role="img"` and that `aria-label`. It also accepts `children` instead of `emoji`, so empty states can put an icon in the blob.
- [x] `src/components/ui/UserPill.tsx` exports `UserPill({ uid, name })` rendering the pill above. It is not itself a link; callers wrap it.
- [x] `src/components/ui/IconButton.tsx` exports `IconButton({ label, icon, onClick, variant: 'floating' | 'flat', href? })`: 44x44, `rounded-full`, accessible name from `label`, `floating` adds `bg-surface shadow-md`, `flat` is transparent with `hover:bg-surface-tertiary`. Renders a `Link` when `href` is set.
- [x] Every icon in the Context list is exported from `icons.tsx` with the same wrapper and stroke width as the existing ones, paths copied from Lucide. No icon package is added (`package.json` unchanged).
- [x] Tests: `EmojiBlob.test.tsx` covers hidden by default, `role="img"` with a label, children instead of emoji. `UserPill.test.tsx` covers the name and the "Anonymous" fallback.
- [x] `docs/architecture.md` lists `EmojiBlob`, `UserPill` and `IconButton` in the `ui/` primitive set.
- [x] A `backlog/QA.md` entry: nothing visible yet; check after RL-100 that the blob on a recipe title is the soft organic shape, not a circle, at 390px.
- [x] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Using the pieces on any page (later tickets do that). Restyling `Avatar` itself. Photo tiles
(decision 3).
