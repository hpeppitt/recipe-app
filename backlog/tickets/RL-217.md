## Context

Shop mode is a view of RL-216's page, not a route (`?mode=shop` in the URL, written with
`replace`, so a reload keeps it). `useWakeLock` comes from RL-203.

## Acceptance criteria

- [ ] Shop mode hides the source chips, notice, share and footer; shows aisle headings at 14px and lines at 22px with 40px check circles and 56px row height; ticked lines move to a "Got it" group at the bottom.
- [ ] A top bar has "Done" (back to the normal view) and "N left".
- [ ] The screen stays awake while in shop mode (`useWakeLock`).
- [ ] Tests: toggle mode, larger targets, ticked lines move, wake lock requested.
- [ ] `docs/capabilities.md` Shopping list row.
- [ ] A `backlog/QA.md` entry: on a phone in a shop, the list is readable at arm's length and stays on.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Reordering aisles.

Component tests. Human: device check.
