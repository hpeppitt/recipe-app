## Context

Shop mode is a view of RL-216's page, not a route (`?mode=shop` in the URL, written with
`replace`, so a reload keeps it). `useWakeLock` comes from RL-203.

## Acceptance criteria

- [x] Shop mode hides the source chips, notice, share and footer; shows aisle headings at 14px and lines at 22px with 40px check circles and 56px row height; ticked lines move to a "Got it" group at the bottom.
- [x] A top bar has "Done" (back to the normal view) and "N left".
- [x] The screen stays awake while in shop mode (`useWakeLock`).
- [x] Tests: toggle mode, larger targets, ticked lines move, wake lock requested.
- [x] `docs/capabilities.md` Shopping list row.
- [x] A `backlog/QA.md` entry: on a phone in a shop, the list is readable at arm's length and stays on.
- [x] `npm test`, `npm run lint`, `npm run build` pass.
