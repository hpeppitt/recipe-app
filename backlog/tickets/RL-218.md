## Context

The More sheet (RL-100) lists Share, Suggest, Delete and similar. Servings live in the page's
stepper state (display only, RL-102). `useKitchen().addRecipe(recipe, servings)` (RL-213).

## Acceptance criteria

- [ ] A More sheet row "Add to shopping list" (`ShoppingBasket`) on the recipe page and `/shared/:id` for verified users; signed out and anonymous it opens the sign-in sheet (`{ kind: 'continue' }`); hidden in local-only mode.
- [ ] Adds at the current servings; the toast says "Added 6 things to your list" counting lines not already in the pantry, with "View" linking to `/kitchen/list`; adding the same recipe again adds it again (×2 on the chip).
- [ ] Failure: "Couldn't add to your list. Check your connection and try again."
- [ ] Tests: row visibility, scale passed, toast count, failure.
- [ ] `docs/capabilities.md` Shopping list row.
- [ ] A `backlog/QA.md` entry: scale a recipe to 12, add it, the list shows scaled amounts.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
