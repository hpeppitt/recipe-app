## Context

`src/pages/ProfilePage.tsx` shows four `StatTile`s: on the own profile Originals, Branches,
Followers (toggles the followers list) and Following (toggles the following list); on another
cook's profile the same four, inert. The tabs below are already Started / Grew. The 4a design
names the tiles Started / Grew / Followers / Saves; Phase 1 later swaps Saves for Cooked
(RL-202). Saves is the total of `favoriteCount` across the person's published recipes, which
the "views and favourites line" already sums.

## Acceptance criteria

- [x] Tiles read Started (own recipes with no parent), Grew (own recipes with a parent), Followers, Saves (sum of `favoriteCount` over the person's published recipes; "–" while loading) on both profiles. The values for Started and Grew are unchanged from Originals and Branches.
- [x] On the own profile, Followers still toggles the followers list. Following becomes a 14px `accent-700` text button under the tiles, "Following N", toggling the following list as the tile did, with the same `aria-expanded`.
- [x] The views and favourites line no longer repeats the saves total (it keeps views).
- [x] Tests updated for both profiles.
- [x] `docs/capabilities.md` Profiles row lists the new tiles.
- [x] A `backlog/QA.md` entry: own and another cook's profile at 390px show the four tiles; Following N opens and closes the list.
- [x] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Cooked (RL-202). The Collabs tab (RL-173). Forest (RL-175).

Component tests. Human: the QA.md check.
