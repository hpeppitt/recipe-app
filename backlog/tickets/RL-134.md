## Context

Every branch entry point navigates to `/recipe/:id/vary` whatever the visitor's state:
`RecipeDetailPage.tsx` ~648, `SharedRecipePage.tsx` ~369 (Make it yours), `VersionTreePage.tsx`
~151 (sticky Branch from) and `TimelineView.tsx` ~224 (Branch here). For anyone who cannot
generate (`canGenerate` in `src/lib/generation.ts`: configured app and no verified email),
`RecipeChatPage` then shows its full-page "Sign up to start cooking up recipes" screen
(~200-240). The spec wants the 5a contextual sheet, as Suggest and Follow already get through
`SignUpDialog` (`src/components/auth/SignUpDialog.tsx`: no guest option, because an anonymous
account cannot branch either, decision 1a). The full-page gate on `/vary` and `/create` stays for
direct visits; it is the generation gate (see the comment above it).

## Acceptance criteria

- [ ] `AuthAction` gains `{ kind: 'branch' }`; `actionCopy` returns "branch this recipe" with the `GitBranchPlus` icon, so the headline reads "Sign in to branch this recipe".
- [ ] At all four entry points, when `!authLoading && !canGenerate({ isConfigured, user })`, the tap opens `SignUpDialog` with `action={{ kind: 'branch' }}` and body "Branches are new recipes written by AI, so they need an account with an email. Your branch is credited to you and the original stays as it is." and does not navigate. Otherwise it navigates as today.
- [ ] While auth is still loading the tap navigates as today (the route's own gate handles it), so a signed-in user never sees the sheet flash.
- [ ] `RecipeDetailPage.test.tsx`: signed out, tapping Branch this recipe opens a dialog named "Sign in to branch this recipe" and the location is unchanged; verified, it navigates to `/recipe/<id>/vary`. One equivalent test for Make it yours.
- [ ] `docs/capabilities.md` "Passwordless email sign-in" row lists "branch this recipe" among the sheet headlines.
- [ ] A `backlog/QA.md` entry. `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Running the branch after sign-in (RL-135, RL-136). Google, Apple, password, guest recipes
(author decisions 1a and 7). The full-page gate on `/create` and `/recipe/:id/vary`.

## Verification

Gates: tests, `ui-reviewer`. Human signed out and as an anonymous guest at 390px: Branch this
recipe, Make it yours on a shared link, the tree page CTA and a Timeline stop's Branch here
each open the sheet; Not now closes it and leaves the page as it was.
