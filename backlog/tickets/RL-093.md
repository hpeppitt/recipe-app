## Context

The author picked 13a, "Grouped list": "A familiar settings list on surface cards."
Markup: `docs/design/organic/export/Collaboration and Account.dc.html` 13a and the `settings`
block in `App Prototype.dc.html`. In the new nav (RL-097) Settings is reached from the You tab's
gear and has a back button.

Today `src/pages/SettingsPage.tsx` uses `TopBar` and stacked sections: account buttons to the
profile, Units (`SegmentedControl`, three options from `useUnitSystem`), Data (Export All
Recipes, Download my data, Import Recipes, Delete Recipes on This Device with help text and
status lines), Legal (Terms, Privacy, Cookies, and the analytics switch shown only when
PostHog is configured). Sign out lives on the own profile (`OwnProfile` in
`src/pages/ProfilePage.tsx`), with an extra confirm for anonymous accounts. Every behaviour,
help text and status message stays; this is layout.

Rows in the design that are NOT built (new features, see Out of scope): "Sign-in methods",
the Theme segment (hidden by RL-065, light only), "Weigh spoons and liquids", and the
"Notify me when" toggles.

**Design token map:** `--color-bg` is `bg-surface`; `--color-surface` is
`bg-surface-secondary`; neutral-700 text is `text-text-tertiary`; `--color-divider` is
`border-border`. Light only: no `dark:` classes. 44px targets.

Values to copy:

- Header row: back `IconButton` (flat, `ChevronLeft`, label "Back", goes to `/profile`
  when there is no history, otherwise `navigate(-1)`), then "Settings" in `font-heading`
  22px. No sticky blur bar.
- Body: padding `12px 18px 30px`, groups with gap 18px. Group label: 12px, 600,
  `text-text-tertiary`, margin `0 0 6px 6px`. Card: `rounded-[28px] bg-surface-secondary`,
  padding `4px 16px`; rows inside separated by a 1px `border-border` bottom rule, row padding
  `14px 0`, 15px text, trailing `ChevronRight` or icon.
- **Account**: one row, a 40px `Avatar`, name 15px 700, sub 12px `text-text-tertiary`
  (email for a verified account; "Guest · this device only" for anonymous; "Not signed in"
  when signed out), chevron. Tap goes to `/profile` (RL-094 later makes it open the avatar
  sheet). Hidden in local-only mode.
- **Appearance**: card padding `14px 16px`; a row "Units" with the existing three-option
  `SegmentedControl` at the right (wrap below the label at 320px).
- **Your data**: rows "Export my recipes" (`Download` icon), "Download my data", "Import
  recipes", and "Delete recipes on this device" in `text-accent-700` 600. Existing help text
  and status lines render under the relevant row in 12px `text-text-tertiary`. Copy changes
  are case only ("Export All Recipes" becomes "Export my recipes", "Delete Recipes on This
  Device" becomes "Delete recipes on this device"); the confirm dialogs keep their text.
- **Legal**: rows Terms of Service, Privacy Policy, Cookie Policy with chevrons, and the
  analytics row when shown, as a toggle: track 44x26 `rounded-full`, `bg-accent-2-600` on,
  `bg-neutral-400` off, a 20px `bg-surface` knob at `left: 3px` off and `left: 21px` on,
  `role="switch"` with `aria-checked`.
- **Sign out**: last card, one row, 15px 600 `text-accent-700`, shown when a user is
  signed in. Uses the existing `signOut` and, for anonymous accounts, the existing
  "Sign out of this anonymous account?" confirm, moved from `ProfilePage`.

## Acceptance criteria

- [ ] `SettingsPage` renders the groups above in that order with every existing control, help text, status message and confirm dialog working as before.
- [ ] Sign out (with the anonymous confirm) is in Settings and removed from `OwnProfile`; `ProfilePage.test.tsx` and `SettingsPage.test.tsx` move the sign-out assertions accordingly, none deleted.
- [ ] The analytics row is a `role="switch"` toggle with the stated sizes, keyboard operable (Space toggles), still hidden when PostHog is not configured.
- [ ] No Theme, Sign-in methods, Weigh or notification toggle rows exist.
- [ ] Rows are buttons or links with 44px height; the destructive row keeps its confirm.
- [ ] `docs/capabilities.md`: the Sign out row's "Where" names `SettingsPage`; the Delete Recipes on This Device and Export rows keep their names with the new case in quotes.
- [ ] A `backlog/QA.md` entry: at 390x844 and 320px, walk every row: export (confirmation shows), download my data, import a file, delete on this device (confirm copy unchanged), legal links, analytics switch with keyboard, sign out as verified and as anonymous (confirm shows).
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
