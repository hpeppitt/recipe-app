## Context

Cooks are public (RL-192). One bounded read serves Explore's cook sections (RL-243), the
Tonight card's neighbours and the "open the leader" rule (RL-247), like RL-126's single
`createdAt` query: `cooks where createdAt >= now - 90d orderBy createdAt desc limit 500` (one
range and sort on one field, the automatic index).

## Acceptance criteria

- [ ] `getRecentCooks(sinceMs, max = 500)` and `useRecentCooks()` (module cache per session, 6 s bound, reported as `recent-cooks`, local-only returns empty).
- [ ] `cookedThisWeek(cooks, now)` returns `{ recipeId, rootId, count, uids (<= 3) }[]` for the last 7 days, most first, at most 8.
- [ ] `mostCooked(cooks, now, days)` ranks families (by `rootId`) over 30 or 90 days, top 3, with the most-cooked version per family ("most cook the feta branch").
- [ ] `familyLeader(cooks, rootId, now)` returns the version id when one non-root version has at least 3 times the original's cooks in the last 90 days (and at least 3 cooks), else null.
- [ ] Tests for windows, ties, threshold edges.
- [ ] `docs/data-model.md` read cost (at most 500 per session) and the shortcut comment `shortcut: counts only the newest 500 cooks in 90 days, upgrade to a counter`.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
