## Context

Spec (`docs/design/organic/export/App Spec.dc.html`, "Desktop ≥1024px 21a, layout/* (tab bar
→ left rail)") and 21a in `Recipe Parts and System.dc.html`: "From 1024px the tab bar becomes
a left rail and a second pane opens. Below 1024px the app stays the mobile column." This
ticket is the rail only; the second pane is RL-116.

The nav after RL-097 has five links (Explore, Saved, Create, Activity, You) with an unread
badge on Activity. `AppShell` lays out the shell routes in a `max-w-lg` column.

**Design token map:** `--color-bg` is `bg-surface`; `--color-surface` is
`bg-surface-secondary`; neutral-800 text is `text-text-secondary`. Light only. 44px targets.

Values to copy (21a `rail`):

- At `lg` (1024px) and up: the bar is a fixed left column 220px wide, full height,
  `bg-surface-secondary`, padding `28px 16px`, column, gap 4px. First, "Recipe Lab" in
  `font-heading` 22px, padding `0 12px 20px` (not a link to avoid a duplicate Explore
  target, or a link to `/` with the same name, implementer's choice).
- Items: height 44px, padding `0 14px`, `rounded-full`, flex, gap 12px, 14px 600, icon then
  label. Active: `bg-surface text-accent-700`; inactive: transparent `text-text-secondary`.
  Create is a normal item in the rail (no raised circle). The Activity badge sits after the
  label.
- Shell content gets `margin-left: 220px` at `lg` and keeps its own `max-w-lg` column,
  centred in the remaining width; the bottom padding for the bar is removed at `lg`.
- Below 1024px nothing changes.

## Acceptance criteria

- [x] At 1024px and wider the nav renders as the rail above; below it, the RL-097 bar is unchanged. One `nav` element either way, same links, same accessible names and `aria-current`.
- [x] Detail routes outside the shell (recipe, tree, settings and others) are unaffected.
- [x] `BottomNav.test.tsx` still passes; add a check that the wordmark exists and the links are unchanged (layout is CSS, so no viewport test is needed).
- [x] A `backlog/QA.md` entry: at 1280x800 and 1024x768 the rail shows, active item highlights, badge shows; at 1023px the bottom bar returns; keyboard Tab order top to bottom.
- [x] `npm test`, `npm run lint`, `npm run build` pass.
