## Context

Ingredient rows tick through hidden checkboxes (`IngredientList.tsx`, RL-102), not persisted.
Cook mode is a route so Back closes it naturally (tier hard: routing). The Screen Wake Lock API
(`navigator.wakeLock.request('screen')`) is a platform feature, no dependency; it is released
when the tab hides and must be re-requested on `visibilitychange`. Hands-free (voice, gestures)
is "Not on the roadmap". The scale chosen on the recipe page should carry over through
navigation state.

### The design (the implementer has no other copy)

- **Offer**: when the first ingredient is ticked on a recipe page, a slim bar slides in above the
  footer for 8 seconds or until dismissed: `bg-accent-2-100`, 22px radius, `ChefHat`, 14px "Start
  cooking? Steps one at a time, screen stays on." and a 36px primary pill "Start cooking". Once
  per recipe visit.
- **Cook mode page** (outside `AppShell`, full height, ground background): top row with a 44px
  close (`X`, "Close cook mode") and 13px `neutral-700` "Step 3 of 8"; a 6px progress bar
  (`bg-neutral-200` track, `accent` fill). The step text in 24px body font (Figtree), line-height
  1.4, padded 24px, scrolling if long. Under it, a collapsible "Ingredients" (closed by default)
  listing the scaled ingredients. Footer: two 56px buttons, "Back" (secondary) and "Next step"
  (primary); on the last step the primary reads "Done" and opens `CookedSheet`.
- Swipe left and right also move steps; arrow keys too. The step region is `aria-live="polite"`.
- If wake lock is unavailable or refused, a 12px line says "Your screen may still dim."

## Acceptance criteria

- [ ] Route `/recipe/:id/cook`, lazy; reads the recipe like the recipe page (`useRecipe`) and the scale from `location.state.servings` (default stored servings).
- [ ] `useWakeLock(active)` requests and releases the lock, re-requests on visibility, and reports support.
- [ ] Done opens `CookedSheet` for verified users and the sign-in sheet otherwise; saving returns to the recipe.
- [ ] Respects `prefers-reduced-motion` (no slide animations).
- [ ] Tests: step navigation, last step Done, wake lock mocked request and release, offer shown once.
- [ ] `docs/capabilities.md` gains a Cook mode row and the route.
- [ ] A `backlog/QA.md` entry: on a real phone, tick an ingredient, Start cooking, leave the phone for two minutes: the screen stays on; switch apps and back: still on; swipe through steps; Done opens the sheet.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Voice or gesture control. Timers.
