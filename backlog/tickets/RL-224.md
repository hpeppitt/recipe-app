## Context

Kitchen (RL-214) has tiles and a Saved row. Collections go under the Saved row. Tiles reuse
`RecipeTileGrid` (4c). Recipes not on the device are read with `getPublishedRecipe` (one read
each, in memory per session, as the Saved page does, RL-121).

## Acceptance criteria

- [ ] Kitchen: Caprasimo 18px "Collections" with rows like RL-223's (52px 2x2 emoji square, name, "N recipes", chevron) linking to `/kitchen/c/<id>`; hidden when there are none.
- [ ] Collection page: back row with a More button (Rename, Delete with 19a confirm "Delete <name>? The recipes stay saved."), Caprasimo 30px name, "N recipes", the tile grid; each tile has a remove control in an edit mode toggled by "Edit".
- [ ] Missing or deleted recipes show as "A deleted recipe" tiles with remove.
- [ ] Tests: list, rename, delete, remove, missing recipe.
- [ ] `docs/capabilities.md` Collections row and route.
- [ ] A `backlog/QA.md` entry: create two collections, open one, rename it, remove a recipe, delete it.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
