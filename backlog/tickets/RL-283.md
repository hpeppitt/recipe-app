## Context

`src/content/legal/privacy.ts` lists what is on the public profile ("What is public" and "Your
profile") and the correction rights. The export copies the whole profile document
(`exportSection('profile')` in `services/firestore.ts`) and the erase script deletes
`profiles/{uid}` whole (`scripts/data-request.mjs`), so no code change is expected there, only
tests that prove it. The author signs the wording before `/release` (RL-046 pattern, RL-260).

## Acceptance criteria

- [x] "What is public" and "Your profile" name the bio (up to 160 characters, written by the user) and the country flag (set once from the device's time zone when the account first signs in, never from IP address or GPS, changeable or removable at any time).
- [x] The Correction line names bio and country.
- [x] `lastUpdated` moves; `TERMS_VERSION` does not.
- [x] `docs/legal/data-inventory.md` profiles row lists `bio` and `country` and where they come from.
- [x] Tests: Download my data includes `bio` and `country`; the erase script's plan deletes the profile document that holds them.
- [x] A `backlog/QA.md` entry: "Author: sign off the bio and country flag wording in /privacy before release."
- [x] `npm test`, `npm run lint`, `npm run build` pass.
