## Context

The edit page (`RecipeEditPage.tsx`) has no way to reorder ingredients, and every method step is
open. 8a: each ingredient row starts with a grip handle (`grip-vertical`, neutral-500, 16px)
before the 72px amount pill; the Method heading row reads "Method" then, at the right, "6 steps"
(13px, neutral-700) and a chevron, collapsed by default. A drag library would be a client
bundle dependency, which needs a human (`backlog/README.md`), so the reorder is pointer events
plus keyboard. Depends on RL-132 only because both edit the same JSX block.

## Acceptance criteria

- [x] Pure `moveItem<T>(list: T[], from: number, to: number): T[]` in `src/lib/recipeEdit.ts`, returning a new array; out-of-range indexes return the list unchanged. Tests cover forward, backward, same index, ends, out of range.
- [x] Each ingredient row has a handle button before the amount: `GripVertical` (add to `icons.tsx` from Lucide: six `circle` r=1 at (9,12) (9,5) (9,19) (15,12) (15,5) (15,19)), 44px hit area, `aria-label="Move ingredient N, <name>"`, `aria-describedby` pointing at a visually hidden hint "Use the up and down arrow keys to move".
- [x] Keyboard: ArrowUp / ArrowDown on the handle move the row one place with `moveItem`, keep focus on the moved row's handle, and announce "Moved to position N of M" in a polite live region.
- [x] Pointer: pressing the handle and dragging vertically moves the row past its neighbours' midpoints (pointer capture, `touch-action: none` on the handle only, so the page still scrolls elsewhere). No new dependency.
- [x] Rows keep stable React keys across a move (add a draft-only id, not saved), so inputs keep their text and focus. `draftToPatch` output is unchanged apart from order.
- [x] Method collapsed by default: the section heading is a button "Method" with "<N> steps" and a chevron, `aria-expanded`; expanding shows the existing step editors. It opens by itself when validation flags `instructions`, so the error is never hidden.
- [x] Tests: keyboard move updates order and saved order; the method toggle; an instructions error expands it.
- [x] A `backlog/QA.md` entry. `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Reordering method steps or notes. Moving an ingredient between groups (it keeps its group).
The picker pills (RL-132).

## Verification

Gates: tests, `ui-reviewer`. Human on a phone: drag an ingredient up and down with a thumb, the
page still scrolls when dragging elsewhere; with a keyboard and VoiceOver, move a row and hear
the announcement; save and check the recipe page shows the new order.

## Notes

Row keys live in a parallel `ingKeys` state in the page, not in the draft, so `isDraftDirty` and `draftToPatch` are untouched. The collapsed method is a `hidden` wrapper (not unmounted) so the typed steps and focus survive; a failed save uses `flushSync` to open it before focusing. Drag has no jsdom test (no layout); keyboard, toggle and auto-open are tested.
