## Context

The Map view (3c, RL-072) draws the family as a radial map: the original in the centre,
one dashed ring per generation, children spread around their parent by subtree size. The
brief asks for the radial math in `src/lib` with tests. Input is the `TreeNode` from
`buildTree` (`src/lib/tree.ts`). Project rule: no imports from `services/` or `hooks/`.

## Acceptance criteria

- [ ] `src/lib/radialLayout.ts` exports `layoutRadial(tree, options?)` returning `{ nodes: { id, x, y, generation, angle }[], edges: { from, to }[], rings: number[], size }`. Options: `ringGap` (default 72), `padding` (default 40). Coordinates are relative to the centre `(size / 2, size / 2)`.
- [ ] The root is at the centre, generation 0. A node at generation g sits on the ring of radius `g * ringGap`. `rings` lists the radii for generations 1 to max.
- [ ] Angular spans: the root owns the full circle; each node's children split their parent's span in proportion to subtree size (node count), in `buildTree` child order, starting at the top (-π/2) clockwise; each node sits at the middle of its span.
- [ ] `size` is `2 * (maxGeneration * ringGap + padding)`; a root alone returns one node at the centre, no edges, no rings.
- [ ] `src/lib/radialLayout.test.ts` covers: root only; one child; three equal children 120 degrees apart; uneven subtrees get proportional spans; each child's angle lies within its parent's span; no two nodes share a position on a 20-version family; ring radii; `size`.
- [ ] `docs/architecture.md` adds `radialLayout` to the `lib/` list.

## Out of scope

- Rendering, zoom, or the large-family fallback (RL-072).
- Minimum angular spacing for crowded rings beyond proportional spans (the view's fallback handles big families).

## Verification

`npm test`, `npm run build`, `npm run lint`. No browser check; QA.md one-liner.
