## Context

Three generate polish items need small pure rules first:
- 7b tags each dedup match Same or Similar. Matches come from `rankByQuery` (`src/lib/search.ts`)
  over `recipeHaystack`, threshold 0.5.
- 6b orders the quick-change chips (`BRANCH_CHIPS` in `src/lib/constants.ts`: Less sugar,
  Vegetarian, Vegan, Gluten-free, Quicker, Spicier) by how often this family's branch prompts
  used them, falling back to the global order.
- 7c splits them into "Nobody's tried these yet" and "Already a branch, open it instead" for the
  parent being branched, the second linking to the child that did it.

## Acceptance criteria

- [x] `matchKind(query, match)` returns `'same'` when every word of the match's title (via `queryWords`) is in the query's words, or the query's words are all in the title; otherwise `'similar'`. Tests with "banana bread" vs "Banana bread", "Brown butter banana bread", "chocolate banana loaf".
- [x] `promptMatchesChip(prompt, chip)` is true when the chip's lower-case label (or a listed synonym: "less sugar" also "lower sugar", "reduced sugar"; "quicker" also "faster", "quick"; "gluten-free" also "gluten free"; "spicier" also "spicy", "more heat") is a substring of the lower-cased prompt.
- [x] `orderChips(chips, familyPrompts)` sorts chips by the number of family prompts matching them, descending, ties in the original order; with no prompts it returns the input order.
- [x] `splitChips(chips, children)` with `children: { id, prompt }[]` (direct children of the parent) returns `{ untried: string[], tried: { chip, childId }[] }`, the first matching child per chip, each list keeping `orderChips` order.
- [x] Tests cover synonyms, ties, empty inputs and a chip matched by two children.
- [x] `npm test`, `npm run lint`, `npm run build` pass.
