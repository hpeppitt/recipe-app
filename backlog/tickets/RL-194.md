## Context

Written for RL-192's recommendations; regroom if the author chose otherwise. The rules already
have the patterns needed: `verified()`, the `writeWindows` move proved with `existsAfter`/
`getAfter` and `last` (RL-048/049, `capFor()` and `windowMsFor()` ~98-105), server-time
`createdAt` checks, and owner-only key-limited updates (`changedKeys().hasOnly`). Editing rules
in the repo is reversible; deploying is RL-209.

## Acceptance criteria

- [ ] `match /cooks/{cookId}`: `allow read: if true`. Create: `verified()`; keys exactly `uid, displayName, recipeId, rootId, recipeOwnerId, vote, note, branchId, createdAt`; `uid == request.auth.uid`; `vote in ['again', 'tweak']`; `note == null || (note is string && note.size() <= 500)`; `branchId == null`; `createdAt == request.time`; `displayName` null or a string of at most 100; `recipeId` and `rootId` strings of at most 128; `recipeOwnerId` equals `get(/recipes/$(recipeId)).data.createdBy.uid` (the recipe must exist); and the `cook` window moved in the same request with `last` equal to this path.
- [ ] Update: only by the cook, verified, `changedKeys().hasOnly(['branchId'])`, from null to a string of at most 128. Delete: only by the cook, verified.
- [ ] `writeWindows` accepts the `cook` action: `cookCap()` 20, window one day; `capFor()` and `windowMsFor()` extended; `RATE_LIMITS.cook` in `src/lib/rateLimit.ts` and the test that ties them.
- [ ] Count queries work: a `getCountFromServer` on `cooks where recipeId == X` and on `recipeId == X and vote == 'again'` is allowed signed out (public read).
- [ ] Emulator probe codes in Notes: verified create with window (200), without window (403), anonymous (403), wrong uid (403), bad vote (403), note of 501 (403), client `createdAt` (403), recipe missing (403), 21st in a day (403), cook sets branchId once (200) then again (403), someone else deletes (403), signed-out count (200).
- [ ] `docs/data-model.md`: collection table row, rules paragraph and access-call budget, "in the repo, deployed by RL-209".
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
