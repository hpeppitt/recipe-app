## Context

RL-062 repoints the theme tokens. This ticket restyles the shared primitives so they carry
the Organic shapes and type, which every page inherits. Values come from
`docs/design/organic/tokens.css` (the comment block at the bottom holds the component
rules) and the Tailwind names RL-062 adds (`accent-*`, `accent-2-*`, `neutral-*`,
`on-accent`, `font-heading`, `rounded-card`, `text-h*`).

Constraints from earlier fixes that must survive, explained in each component's comments:

- 44px minimum target on every `Button` size, `Chip` with `onClick`, and `SegmentedControl`
  segment (`min-h-11`). The design's 36px input height is a floor of 36, not a ceiling: keep
  44px (`min-h-11`) on `Input`.
- `SegmentedControl` stays a `radiogroup` with `aria-checked`.
- `ConfirmDialog` keeps `aria-labelledby` / `aria-describedby` and its `busy` behaviour.
- `TagList` exists to stop three copies drifting (UX-30); keep it the single source.
- `EmptyState`'s compact variant renders a `<p>`, not a heading; keep that.

Contrast, measured at grooming: the design's primary button (accent `#c67139` fill, cream
text) is 3.03:1 and fails AA at 14px. RL-062 maps `primary-600` to accent-700 (`#8c491a`,
cream text 5.72:1) for that reason, so the button uses `primary-600`. This is an open
question for the author; if they choose the swatch over AA, only the class names below
change.

Light only (RL-065): leave existing `dark:` classes in place, inert, and write no new ones.

## Acceptance criteria

- [ ] `Button`: `rounded-full`, `font-heading` at 14px (`text-sm`), no `font-medium` (Caprasimo has one weight). Primary: `bg-primary-600 text-on-accent hover:bg-primary-700 active:bg-primary-800`. Secondary: transparent fill, `border border-border text-text-primary hover:bg-surface-secondary`. Ghost: `text-primary-600 hover:bg-primary-50` (accent-700 text, per the AA rule). Danger: unchanged colours, pill shape. Disabled: `disabled:opacity-45`. All sizes keep `min-h-11`. `as="a"` still works.
- [ ] `Chip`: inactive `bg-neutral-100 text-neutral-800 border border-border` (9.12:1); active `bg-primary-600 text-on-accent`; pill; 44px when interactive, as today.
- [ ] `TagList` pills are Organic accent tags: `text-[11px] rounded-xl px-2 py-0.5 bg-primary-50 text-primary-700` (accent-100 / accent-800, 9.46:1).
- [ ] `SegmentedControl`: pill track (`rounded-full`, `bg-surface-secondary`, 4px inner padding), selected segment a pill `bg-primary-600 text-on-accent`, unselected `text-text-secondary`. Still a `radiogroup`, still 44px.
- [ ] `Input`: `rounded-full`, `bg-surface-secondary`, `border border-border`, focus `border-primary-500` with the 2px accent ring; error text uses `text-danger-700` (danger-500 `#ef4444` on the cream ground fails AA). Label stays above the field. `min-h-11`.
- [ ] `ConfirmDialog`: `rounded-card shadow-lg bg-surface`, title in `font-heading text-h4` (20px), buttons are pills from `Button`.
- [ ] `Skeleton`: `bg-surface-secondary rounded-card` by default (callers' `className` still overrides).
- [ ] `EmptyState`: full-page title uses `font-heading text-h3` (25px); compact title unchanged in role; description `text-text-secondary`; left-aligned only if every current caller still reads correctly at 390px, otherwise keep centred and note it.
- [ ] `TopBar`: title in `font-heading` at 20px (`text-h4`), no `font-semibold`; back button `rounded-full`; header background `bg-surface/80` with `border-border` unchanged in structure. Back arrow stays the existing inline SVG (icons are RL-064).
- [ ] Existing tests pass unchanged (`EmptyState.test.tsx` and the page tests). No test is weakened.
- [ ] `docs/capabilities.md` needs no row change unless a behaviour changed; if none did, say so in Notes.
- [ ] A `backlog/QA.md` entry: at 390x844 check buttons, chips, filter chips on Library, the theme `SegmentedControl` in Settings, inputs on the edit page, the delete confirm dialog, skeletons while a recipe loads, and an empty state; tab through each with the keyboard and confirm the accent focus ring is visible.
