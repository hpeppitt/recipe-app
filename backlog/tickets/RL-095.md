## Context

The spec (`docs/design/organic/export/App Spec.dc.html`, "Profile (4a + 4c)"): "Blob avatar,
four stat tiles, Started / Grew tabs (4a) over a two-column tile grid (4c). Tiles use the
photo when present, else emoji on a tint." Photos are cut (decision 3), so tiles are always
emoji on a tint. Markup: the `profile` block in `App Prototype.dc.html`; 4a in `Social Auth and
Generate.dc.html`.

This tab also becomes the home of the user's own recipes when RL-098 replaces the Library:
decision 1b splits My Recipes into Created and Branched, and `splitLibrary` (RL-084) already
computes them. Started = own recipes with no parent; Grew = own recipes with a parent.
`useOwnRecipes(uid)` (`src/hooks/useUserRecipes.ts`) reads the user's own Dexie rows with view
and favourite counts but drops `parentId`, `prompt`, `totalTime`; add the fields it needs.
The RL-079 waiting skeleton and the offline line ("You're offline. Showing the recipes saved
on this device.", today in `LibraryPage`) belong here now.

Stats the design shows are Originals, Branches, Credited, Followers. "Credited" (other cooks'
versions grown from this user's recipes) needs a query over other people's recipes per family
and is not built (see Out of scope). The fourth tile is Following, which exists.

**Design token map:** `--color-bg` is `bg-surface`; `--color-surface` is
`bg-surface-secondary`; neutral-700 text is `text-text-tertiary`; neutral-800 text is
`text-text-secondary`. Light only: no `dark:` classes. 44px targets.

Values to copy:

- Header row: right-aligned flat `IconButton` with `Settings`, label "Settings", to
  `/settings`. No "My Profile" `TopBar`.
- Identity row, padding `0 22px`, gap 16px: an 84px blob (`EmojiBlob` shape from RL-088)
  holding the user's `Avatar` content (initials in `font-heading` 36px, emoji, or photo);
  tapping it opens the avatar sheet (RL-094) or, for anonymous users, the existing sign-up
  prompt. Beside it the display name in `font-heading` 26px, line-height 1.1, with the
  existing inline name editing, and a 13px `text-text-tertiary` line: "Guest · this device
  only" for anonymous, otherwise "Cooking since <Month YYYY>" from `profile.createdAt` when
  present.
- Guest card (anonymous only, 5e copy adjusted to decision 1a): `rounded-[28px]
  bg-accent-100`, padding 16px, gap 10px; title 15px 700 "Your bookmarks only live on this
  device"; body 13px `text-accent-900` "Add an email to keep them if you switch or lose this
  device."; then the existing `EmailLinkingForm` content (its form, Terms box and copy), not a
  new flow.
- Stats: 4-column grid, gap 8px; each tile padding `12px 4px`, `rounded-[20px]`
  `bg-surface-secondary`, centred, value `font-heading` 20px, label 11px
  `text-text-tertiary`. Tiles: Originals (Started count), Branches (Grew count), Followers,
  Following. Followers and Following are buttons that toggle the existing inline lists; the
  other two are not interactive. Under the grid a 13px `text-text-tertiary` line with the
  existing totals: "<n> views · <n> favourites", hidden when both are 0.
- Tabs: the shared `SegmentedControl`, options "Started" and "Grew", full width.
- Grid (`RecipeTileGrid`): 2 columns, gap 10px. Each tile is a link to `/recipe/:id`, a
  column with gap 8px: a square (`aspect-ratio: 1`) `rounded-[28px]` with the emoji at 52px
  on a tint rotating by index `bg-accent-200`, `bg-accent-2-200`, `bg-surface-secondary`;
  the title 14px 700 line-height 1.2, padding `0 4px`; meta 12px `text-text-tertiary`,
  `margin-top: -6px`: on Started "<n> branches" (descendants counted across the device's
  rows, as `buildFeed` does) or "No branches yet"; on Grew the prompt in quotes.
- Empty tab: 14px `text-text-tertiary` "Nothing here yet."
- Signed out (Firebase configured, no user): the 19a empty state with a `UserRound` icon
  in a `bg-accent-300` blob (`text-accent-900`), headline "You're browsing", body "Reading
  is free. Sign in to save recipes, branch them and follow cooks.", action "Sign in" opening
  the existing `AuthModal`.
- Local-only mode: no identity block and no stats; a "Your recipes" `font-heading` 26px
  heading over the same Started / Grew tabs and grid, from every Dexie row (all are the
  user's own in local-only mode per `splitLibrary`).

## Notes

- Lists come from `useLocalLibrary` + `splitLibrary` rather than extra fields on `useOwnRecipes`, which still supplies the views and favourites totals. Prompts for Grew meta are looked up by id from the Dexie rows.
- `EmailLinkingForm` gained a `bare` prop (no card shell or heading) so the guest card owns the title and body without nesting a second card.
- `subscribeOnline` moved from `LibraryPage` to `hooks/useOnline.ts`, shared with the profile.
- The signed-out state uses `tone="error"` only because it gives the `bg-accent-300` blob and `text-accent-900` ink the ticket asks for.
- Extra, requested by the orchestrator: the public profile load error (`ProfilePage`) is now `tone="error"` with `CloudOff` and a secondary "Try again" with `RotateCw`. No test covers it (the page test mocks a fixed public profile).
- Stat tiles now always show (the old row was hidden at zero). The old email line under the name is gone; Settings shows the email.
- Not touched: `PublicProfile` still uses the old layout and `StatBox` (RL-096); `TopBar` is still used by it.
