## Context

While Gemini writes a recipe the chat shows `TypingIndicator` (`RecipeChatPage.tsx` ~489) with
"Checking for similar recipes..." or "Generating recipe..." (`loadingPhase`). A first variation
turn shows `GrowingCard` instead (`growingFirst`, ~486), which stays. Generation regularly takes
10 to 20 seconds. The live region (~180-195) already announces the phase; keep it the only
announcement.

## Acceptance criteria

- [x] When `isLoading && loadingPhase !== 'checking' && !growingFirst` has been true for 4000 ms, the `TypingIndicator` is replaced by `<LoadingScreen variant="inline" label="Generating recipe" />` in the same spot; it goes when loading ends (success or error). The 4 s timer resets on each new send and is cleared on unmount.
- [x] The inline screen is `aria-hidden` here (the page's existing live region already speaks); its root `role="status"` is suppressed by passing a prop or wrapping, so nothing is announced twice.
- [x] Tests with fake timers: typing dots before 4 s, loading screen after, gone when the reply arrives; not shown during the checking phase or for the first variation turn.
- [x] A `backlog/QA.md` entry. `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

The variation `GrowingCard`, cold start (RL-141), the dedup check phase.

## Verification

Gates: tests, `ui-reviewer`. Human at 390px: ask for a recipe and wait; after about 4 s the
tree starts growing above the composer and loops until the card arrives; check it does not push
the composer off screen at 320px with the keyboard closed. Watch one full cycle for the RL-141
checks (trunk, branches, leaves, canopy, emoji, captions, bar, fade, restart), in light and
dark, and again with Reduce motion on (grown, still tree; captions still change).

## Notes

Added a `decorative` prop to `LoadingScreen` (drops role, label and sr-only text, sets aria-hidden). The page derives `waiting`; a timer effect sets `slow` after 4000 ms and its cleanup resets it, so a new send, loading end and unmount all clear it. Tests use fake timers and a reduced-motion matchMedia stub.
