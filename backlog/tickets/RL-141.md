## Context

There is no loading screen: `PageFallback.tsx` is a bare `Spinner`, and `index.html` paints
nothing until the bundle runs. The author made the design's loading screen v1 (2026-10-20). It
is a tree growing from soil, used on cold start (this ticket) and on long generation waits
(RL-142).

### The design (copy exactly; the implementer has no other copy)

Full-screen: `bg-surface` (the ground), content centred, gap 28px. An SVG, viewBox `0 0 300 380`,
drawn at 300x380 (scale down to fit `min(300px, 80vw)` wide). Below it, centred, gap 14px: the
caption in the heading font 22px `text-text-primary`, and a 160x8px bar, fully round,
track `neutral-300`, fill `accent`. One cycle is 7 s (`D = 7000`), then a 450 ms fade out, and
it restarts after `D + 700` ms; it loops while shown.

Reference implementation from the design canvas (React.createElement, rAF-driven). Port the

## Acceptance criteria

- [x] `src/components/ui/LoadingScreen.tsx` renders the screen above. Props: `variant: 'full' | 'inline'` (`inline` is used by RL-142: no full-screen container, SVG 180px tall, caption 18px) and optional `label` (accessible name, default "Loading"). The root has `role="status"` and `aria-label`; the SVG is `aria-hidden`; the caption is `aria-hidden` too (it changes every second or two and must not chatter).
- [x] Animation runs on one `requestAnimationFrame` loop that writes SVG attributes through refs, not React state per frame, and stops on unmount. Colours are `var(--color-*)` tokens only; no hex.
- [x] Under `prefers-reduced-motion: reduce` (read once with `matchMedia`, and on change) the tree renders fully grown and still (t = 1, no sway, no bob, no fade), the caption still cycles on the same thresholds by a timer, and the bar steps without transition.
- [x] Cold start: `index.html`'s `<div id="root">` contains a static, CSS-only version (same SVG fully grown with a CSS opacity fade-in, caption "Turning the soil", no script), styled by a small class block in `src/index.css` that uses tokens. React's first render replaces it, so no removal code is needed. It is `aria-hidden` except one visually hidden "Loading Recipe Lab" text.
- [x] `PageFallback` is unchanged (lazy chunks are usually instant and a 7 s tree would flash).
- [x] Tests: renders the status role and name; reduced motion renders the grown tree (all eight canopy circles at full radius) and no rAF is scheduled; unmount cancels the frame.
- [x] `docs/capabilities.md` gains a "Loading screen" row (cold start, long generation waits from RL-142, reduced motion).
- [x] A `backlog/QA.md` entry. `npm test`, `npm run lint`, `npm run build` pass.
