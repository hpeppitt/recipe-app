## Context

`SharedRecipePage.tsx` (RL-113) shows a "Shared by <pill>" banner with an "Open Recipe Lab"
link to `/` (~268-296), and for a branch a sage card "<author> asked for "prompt"." (~300-318)
with no parent and no way into the family. 12b: banner "Shared by **Ola**" and a **Get the app**
pill (32px, ground fill, 13px semibold); lineage card (accent-2-100, accent-2-900 text, 14px,
radius 22px, git-branch icon): "Ola asked for *"less sugar"* on Hana's **Banana bread**.
<u>See all 7 versions</u>". The app is an installable PWA (`vite.config.ts` `VitePWA`), so "Get
the app" keeps linking to `/`, where the browser offers install; this is a copy change, not an
install prompt (log it).

`useRecipeLineage(recipe)` (`src/hooks/useRecipe.ts`) gives `ancestors` (root first, parent
last) and `recipes` (the whole family, local and published) from `rootId`. A hash link
(`/shared#r=`) has no `rootId` in the cloud sense and must keep today's sentence.

## Acceptance criteria

- [ ] The banner link reads "Get the app" (same target `/`, same 44px hit area).
- [ ] For a cloud recipe with a parent, once the lineage has loaded, the sentence reads "<author> asked for *"<prompt>"* on <parent author>'s **<parent title>**." (without the prompt: "<author> branched <parent author>'s **<parent title>**."), followed by an underlined link "See all <N> versions" to `/recipe/<id>/tree` when the family has more than one recipe. While loading, today's sentence shows with no parent part.
- [ ] A cloud original whose family has 2 or more recipes shows the same card with "<N> versions grow from this recipe. See all <N> versions". An original alone shows no card.
- [ ] A hash-link recipe keeps today's sentence and shows no link.
- [ ] Tests: banner copy; branch sentence with parent and count link; original with family; hash link unchanged.
- [ ] A `backlog/DECISIONS.md` row (Get the app links home, no install prompt). A `backlog/QA.md` entry. `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

`/shared` import from a link (12c, not v1). The footer Save and Make it yours (RL-134 handles
signed-out Make it yours). A native install prompt.

## Verification

Gates: tests, `ui-reviewer`. Human signed out at 390 and 320px: open `/shared/<branch id>` and
`/shared/<original with branches>`; read the sentence, tap See all N versions, Back returns to
the shared page.
