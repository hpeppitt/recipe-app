## Context

A branch is saved by `saveRecipe` in `src/hooks/useRecipeChat.ts` (~317-400): cloud first
(`publishRecipe`), then `cacheRecipe`. RL-152 lets the rules accept a `branch` notification from
the branch's author (repo only until RL-156). `notify()` (`services/firestore.ts` ~570) sends a
notification through the write window after the action and never fails it. Activity rows are
built from `NOTIF_VERBS` and `BADGES` (`ActivityPage.tsx`). The 11a design: "**Lin** branched
your **Banana bread**", sub-line `"vegan, no eggs" · 4h`, badge sage (`accent-2-600`) with a
git-branch icon.

## Acceptance criteria

- [ ] `notifyBranched({ branch, parent, from })` in `services/firestore.ts` calls `notify` with `recipientUid = parent.createdBy.uid`, `type: 'branch'`, `recipeId = branch.id`, `recipeTitle = parent.title`, `recipeEmoji = parent.emoji`, `message = truncateNotificationMessage(branch.prompt)` or null, `fromUid`, `fromDisplayName`, `read: false`, `createdAt`.
- [ ] `saveRecipe` calls it after a successful publish of a recipe with a parent, only when the parent's owner is another real account (not the saver, not `'local'`), and never awaits it in a way that can fail or delay the save.
- [ ] `AppNotification['type']` gains `'branch'`; `NOTIF_VERBS.branch = 'branched your recipe'`; `BADGES.branch = { tint: 'bg-accent-2-600', Icon: GitBranch }`. Tapping the row opens the new branch (its `recipeId`).
- [ ] Keep as branch (RL-148) does not send this (the owner branches their own recipe), which the owner check already ensures.
- [ ] Tests: notify called for someone else's parent, not for own or local parent, not on a failed publish; the Activity row text and badge for `branch`.
- [ ] `docs/capabilities.md` Notifications row lists the branch type.
- [ ] A `backlog/QA.md` entry. `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Filtering and toggles (RL-154, RL-155). Notifying the root's author when a deeper version is
branched (only the parent's author is told; log it in DECISIONS.md).

## Verification

Gates: tests, `data-integrity-reviewer`, `ui-reviewer`. Human on the emulator with two
verified accounts: B branches A's recipe and saves; A's Activity shows "B branched your recipe
<title>" with the prompt and a sage badge, and it opens B's branch. B branching B's own recipe
notifies nobody.
