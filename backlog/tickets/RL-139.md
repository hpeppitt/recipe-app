## Context

`src/components/ui/Spinner.tsx` uses `animate-spin` unconditionally, so it spins under
`prefers-reduced-motion`; the skeleton pulse is already guarded (`src/index.css` ~289) and
`TypingIndicator` uses `motion-safe:`. The spinner is a ring with a transparent top segment, so
static it still reads as a loading mark.

## Acceptance criteria

- [ ] `animate-spin` becomes `motion-safe:animate-spin`; nothing else in the component changes.
- [ ] A test asserts the class list contains `motion-safe:animate-spin` and not a bare `animate-spin`.
- [ ] `grep -rn "animate-spin" src` finds no other unguarded use (fix any the same way and list them in the PR).
- [ ] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Replacing spinners with the loading screen (RL-141, RL-142).

## Verification

Gates: tests. Human: with Reduce motion on (macOS or iOS), open a lazy page on a slow
connection: the ring shows without turning.
