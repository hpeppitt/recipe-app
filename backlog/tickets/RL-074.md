## Context

Author decision 2026-10-19: entry points (1) and (3) approved, (2) Compare on carousel cards rejected.

On `RecipeDetailPage`, the lineage block renders only when `recipe.depth > 0`:
`LineageBreadcrumb` then the "Prompt:" box. The new link goes directly under the prompt
box, so a root recipe never shows it (the brief's done-criterion).

## Acceptance criteria

- [x] (1) On a recipe with `depth > 0`, a text link "See what changed" (`text-primary-600`, 14px, 44px tall target, Link to `/recipe/:id/changes`) appears directly below the prompt box. A root recipe has no such link. A test in `RecipeDetailPage.test.tsx` asserts both.
- [x] (3) The Timeline stop sheet (RL-070) shows a ghost button "See what changed" between the change tags and the Open / Branch here buttons, for every stop except the root, navigating to `/recipe/:id/changes`. A test in `TimelineView.test.tsx` asserts it for a child and its absence for the root.
- [x] `docs/capabilities.md` "What changed" row drops "URL-only" and names the entry points.
- [x] A `backlog/QA.md` entry: open a variation, tap See what changed, Back returns to the recipe; open a root recipe and confirm no link; in the Timeline, open a child stop's sheet and use the link.

## Out of scope

- Any Compare button on carousel cards (rejected by the author).
- Any entry point from the Map card or the Tree view (not in the design).

## Verification

`npm test`, `npm run build`, `npm run lint`; `ui-reviewer`. A human checks placement and
Back behaviour (QA.md).

## Notes

Groomed 2026-10-18; entry points decided 2026-10-19.

Implemented: Link under the prompt box (depth > 0 only); ghost Button in the sheet using the same `go` helper as Open and Branch here (nulls the opener, closes, navigates). Ghost button is full width on its own row so the Open / Branch row is unchanged at 320px. Focus ring forced to primary-600 with the important modifier.
