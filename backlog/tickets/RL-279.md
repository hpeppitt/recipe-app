## Context

The author asked for a short bio with a cap between 100 and 200 characters. Groomer's pick:
160, which fits three lines at 390px under the 26px name and is a familiar length. Profiles
are public (`docs/data-model.md`), so the bio is public; the privacy text is RL-283 and needs
the author's sign-off before `/release`. The name edit on `ProfilePage.tsx` (inline `Input`,
Save and Cancel, `useOwnProfile().updateName`) is the pattern to follow. The current rules
accept a `bio` field; RL-278 bounds it.

### The design (the implementer has no other copy)

- Own profile (`/profile`), under the name and "Cooking since" line: the bio in 15px
  `text-text-secondary`, `break-words`, `whitespace-pre-line` not needed (single paragraph).
  It is a button (44px min height, `Pencil` 16px `text-text-tertiary` after it, as the name)
  labelled "Edit bio". Empty: a text button "+ Add a short bio" in `text-accent-700`.
- Editing: a `textarea` (3 rows, existing `textareaClasses` style), placeholder "What do you
  like to cook?", a counter "n/160" in 12px `text-text-tertiary` shown from 140 characters,
  Save (disabled while saving) and Cancel. Newlines become spaces, the value is trimmed, and
  an empty bio saves as null. `maxLength` 160 (UTF-16 length).
- A failed save keeps the editor open with "Couldn't save your bio. Try again." (`role="alert"`).
- Public profile (`/profile/:uid`): the bio paragraph under the avatar and name row, only when
  non-empty, same style, not a button.
- Guests and unverified users get the sign-up dialog on tap, as the name does.

## Acceptance criteria

- [x] `UserProfile` has `bio?: string | null`; `useOwnProfile` exposes `updateBio(bio: string | null)`, verified-only like `updateName`, tracked as `profile_updated` with field `bio`.
- [x] The own profile edits and shows the bio as designed; the public profile shows it when set.
- [x] A bio can never exceed 160 UTF-16 units or contain a newline when saved.
- [x] Tests: add, edit, clear (saves null), cap, failure message, public display, guest gets the dialog.
- [x] `docs/capabilities.md` Profiles row; `docs/data-model.md` profiles row.
- [x] A `backlog/QA.md` entry: "Write a 160-character bio on a phone, check it on your public profile from another account."
- [x] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope
