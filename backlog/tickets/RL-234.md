## Context

Shown on `/create` and `/recipe/:id/vary` when the user is verified, `askedAt` is null and there
are no avoids. It does not block typing.

### The design (the implementer has no other copy)

A card above the composer, `bg-accent-2-100`, 24px radius, padding 14px 16px, gap 10px:
Caprasimo 18px "Anything the kitchen should avoid?", 13px `neutral-800` "We'll ask the AI to
leave these out. Always check the ingredients if it's an allergy." A wrap of toggle chips:
Peanuts, Tree nuts, Dairy, Gluten, Shellfish, Pork, Alcohol, Very spicy (off: `bg-neutral-100`
with an inset 1px `divider` ring; on: `bg-accent-2-700`, `text-accent-2-100`, `aria-pressed`),
and "Something else" which opens a short field. Footer: primary "Save" (disabled with nothing
picked) and ghost "Skip".

## Acceptance criteria

- [x] Save stores the avoids and `askedAt`; Skip stores `askedAt` only; either hides the card for good; a failure keeps the card with "Couldn't save that. Try again."
- [x] The first generation after Save already uses the avoids.
- [x] Tests: shown once, save, skip, not shown when avoids exist.
- [x] `docs/capabilities.md` generation row.
- [x] A `backlog/QA.md` entry: a fresh verified account opens the chat and sees the card; Skip; it never shows again on another device.
- [x] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

The 28a three-question onboarding.

## Verification

Component tests. Human: the QA.md walk.

## Notes

- The chat hook's single mount read now returns the whole profile; it also decides whether the card shows (`askAvoids`). `answerAsk(terms)` saves through `saveTasteProfile` (avoids merged and normalised, `askedAt` now) and seeds the next session with the saved avoids; Skip is `answerAsk([])`.
- The card shows only before the first recipe. `BranchComposer` gained an `above` slot (does not disable Grow).
- Permission-denied (rules not deployed) hides the card, as does a failed read. The 'full' error cannot occur (at most 9 picks, and the card only shows with none stored), so only the duplicate error is shown.
