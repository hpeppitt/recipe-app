## Context

25a's sheet has a row "Add the leftovers to the pantry · No thanks". RL-197 built the sheet
without it because the pantry arrives in Phase 2.

## Acceptance criteria

- [ ] Above "Save to my cook log": a 22px `bg-accent-2-600` check circle, 13px `neutral-700` "Add the leftovers to the pantry ·" and an underlined "No thanks" button that unticks it (and "Add them" to re-tick). On by default.
- [ ] When on, saving the cook also calls `addPantry("<recipe title> leftovers")` in group `fresh`; a pantry failure does not fail the cook (reported as `cook-leftovers`).
- [ ] Hidden when the kitchen is unavailable (local-only).
- [ ] Tests: default on, No thanks, add called after the cook, failure ignored.
- [ ] `docs/capabilities.md` Log a cook row.
- [ ] A `backlog/QA.md` entry: log a cook, the pantry shows "<title> leftovers".
- [ ] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Ageing leftovers.
