## Context

The Timeline view (3b, RL-070) draws a version family as a subway map: the original is the
trunk line, each diverging subtree is its own coloured line, stops are versions ordered by
time. The brief asks for the layout in `src/lib` with tests. Input is the flat `Recipe[]`
that `useRecipeTree` returns (or the `TreeNode` from `buildTree`; implementer's choice,
one of them). Project rule: no imports from `services/` or `hooks/`.

Cloud records may have `createdAt` 0 (`toRecipeLike` in `src/hooks/useRecipeTree.ts`), so
time alone cannot order a parent before its child.

## Acceptance criteria

- [x] `src/lib/timelineLayout.ts` exports `layoutTimeline(recipes, options?)` returning `{ stops, lines, width, laneCount }`. `stops`: `{ id, x, lane, line, stopNumber }` where `stopNumber` is 1-based along its line. `lines`: `{ index, lane, label, colour, stopIds, branchFromId }`. Options: `minGap` (default 56), `maxGap` (default 120), `msPerPx` (default one day per 8 px), `padding` (default 32).
- [x] Lines: line 0 is the trunk, starting at the root. A line continues to the child with the largest subtree (ties: earliest `createdAt`, then id); every other child starts a new line whose `branchFromId` is the parent. Recursively, so every recipe is on exactly one line.
- [x] Labels name directions, not generations: the trunk is "Original"; any other line's label is its first stop's `prompt`, trimmed to 32 characters with an ellipsis, or "Variation" when empty.
- [x] Colours, by line index: 0 `accent`, 1 `accent-400`, 2 `accent-2`, then cycling `accent-600`, `accent-2-400`, `accent-700`, `accent-2-700`. Returned as token names (strings such as `"accent-400"`), not hex, so the view maps them to CSS variables.
- [x] Ordering: stops are ordered by `createdAt`, ties and zeros broken so a parent always precedes its children (stable topological order, then id). x positions are strictly increasing in that order: each step is the time gap scaled by `msPerPx`, clamped to `[minGap, maxGap]`. A child's x is always greater than its parent's.
- [x] Lanes are collision-free: the trunk is lane 0; each other line takes the lowest lane whose already-placed lines do not overlap its x-span, where a line's span runs from its branch-point parent's x to its last stop's x. No two stops share an (x, lane).
- [x] `width` is the last stop's x plus `padding`; an empty input returns empty arrays and width 0; a single recipe returns one stop on line 0.
- [x] `src/lib/timelineLayout.test.ts` (with `makeRecipe`) covers: single recipe; a straight chain stays one line; two children branch one new line; largest-subtree continuation; tie-breaks; label trimming and fallback; colour cycling past seven lines; zero and equal `createdAt` still put parents first; gap clamping; no lane collisions on a 30-version random family (seeded); deterministic output for the same input.
- [x] `docs/architecture.md` adds `timelineLayout` to the `lib/` list.

## Out of scope

## Notes

Groomed 2026-10-18. Defaults are starting values; RL-070 may tune them and log it.

Implemented 2026-10-18. Input is flat `Recipe[]`. Label ellipsis is three dots appended to the first 32 characters. Orphans (parent not in list) become extra lines after the trunk with `branchFromId` null; a parentId cycle is broken at its earliest member. Span inclusive, so lines touching at one x take different lanes.
