## Context

The author approved the Privacy Policy, Terms and Cookie Policy drafts on 2026-10-22 with three
changes. The contact address shown to users is `SUPPORT_EMAIL` in `src/lib/constants.ts`, which
every policy reads. The Terms gained two import duties and a Google sign-in line since v0.3.0 but
kept version 2026-10-17, so existing users were never asked to accept them; the author wants
everyone to accept once. `TERMS_VERSION` is derived from the Terms `lastUpdated`, and the rules
literal in `termsVersion()` must match it (`src/lib/legal.test.ts` fails otherwise). A reviewer
flagged two loose Privacy lines.

- [x] `SUPPORT_EMAIL` is `hpeppitt@gmail.com`. No user-facing text still shows `harry@seidrlab.com`. The git commit identity note in `docs/operations.md` is about GitHub, not user contact, and stays.
