## Context

RL-186 shows a preview card and saves. 30b inserts a review step that reuses the 8a edit rows
(`RecipeEditPage.tsx`, RL-110: pill amount and name fields); extract the ingredient row into a
shared component rather than copying it. "Save and branch" goes to the 6b composer because
importing is usually a prelude to changing something.

### The design (the implementer has no other copy)

- Header: close and Caprasimo 22px "Check the import".
- Source pill: 13px, `bg-neutral-100`, the URL host and path ellipsised (or "Photo"), and a tag
  "Source kept" (`bg-accent-2-200`, `text-accent-2-900`, `Check`).
- Title: Caprasimo 26px editable with a dashed `accent-400` underline, and the emoji at the end.
- Ingredient rows (8a): 72px amount pill and a name pill; a flagged row has `bg-accent-100`, the
  amount shown as read with "?" ("¾ cup?") in `accent-700`, and a 12px semibold `accent-700`
  "Check" at the right; editing the amount clears the flag.
- Summary 13px `neutral-700`: "8 ingredients, 6 steps read. One amount was unclear." (or "All
  amounts read clearly.").
- Footer: secondary "Edit first" (saves, then opens `/recipe/<id>/edit`) and primary "Save and
  branch" (saves, then opens `/recipe/<id>/vary`). Both use RL-186's save. While flags remain, a
  19a confirm asks "Save with 1 unclear amount? It stays blank until you fill it in."

## Acceptance criteria

- [x] The review replaces the preview card for link and photo imports; the dedup notice from RL-186 sits above the footer.
- [x] Unclear amounts are saved as `amount: null`, never a guess.
- [x] The 8a row component is shared with the edit page, whose tests still pass.
- [x] Tests: flags, clearing, confirm, both footer paths.
- [x] `docs/capabilities.md` Import row.
- [x] A `backlog/QA.md` entry: import a link with a fraction; fix the flagged amount; Save and branch.
- [x] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Editing steps on the review screen (Edit first covers it).

## Verification

Component tests. Human: the QA.md walk.

## Notes

The review sits below the link field or photo tray, which stay visible, so editing the link or removing a photo still clears it. The model's reading of an unclear amount is not kept (RL-185 forces null), so a flagged row shows "?" rather than "3/4 cup?". The 19a confirm uses the existing ConfirmDialog. With a family match, an extra ghost "Add to <Title> family" button keeps RL-186's branch-into-family save. `ImportReview.test.tsx` was not added; the page tests cover it.
