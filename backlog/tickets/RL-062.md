## Context

The author's Organic rebrand (Claude Design export, `docs/design/organic/BRIEF.md`) rethemes
the whole app: warm cream ground, terracotta accent, sage second accent, Caprasimo headings
over Figtree body, pills and over-rounded shapes, no greys. Every value is in
`docs/design/organic/tokens.css`; read it, it is the spec for this ticket.

The theme lives in `src/index.css` as a Tailwind v4 `@theme` block. About 28 files use the
semantic tokens (`primary-*`, `surface`, `surface-secondary`, `surface-tertiary`,
`text-primary`, `text-secondary`, `text-tertiary`, `border`, `border-strong`), so repointing
those tokens rethemes the app without touching the components. The light-theme comment in
`index.css` explains why the text greys were chosen against measured contrast; the same
discipline applies here.

This ticket is the token and type layer only. Restyling the primitives (`Button`, `Chip`,
`TopBar` and the rest) is RL-063. Icons are RL-064. Dark mode is RL-065 and is an open
question for the author; this ticket must leave dark mode legible, not redesign it.

**Fonts are self-hosted, not loaded from Google Fonts.** The brief says "load from Google
Fonts", but a request to `fonts.googleapis.com` / `fonts.gstatic.com` sends every visitor's
IP address to a third party that `src/content/legal/privacy.ts` does not list, which would
reopen the policy sign-off (RL-046) on the release path. Self-hosted woff2 files under
`public/fonts/` avoid that, are precached by the existing Workbox `globPatterns` (it already
includes `woff2`), and work offline. Both families are SIL Open Font License, which permits
redistribution with the licence file.

**Contrast decides the primary mapping, not the swatch.** Measured with the WCAG formula
(at grooming): cream `#f5ead8` text on accent `#c67139` is 3.03:1 and on accent-600
`#b2622d` is 3.77:1, both below 4.5:1 for 14px text; white on accent-600 is 4.49:1. Cream on
accent-700 `#8c491a` is 5.72:1 and white on it 6.81:1. accent-700 text on the cream ground
is 5.72:1, on `#ebddc5` 5.09:1. The brief's own done-criterion is "AA contrast holds (accent
text at body size uses accent-700)", so the semantic `primary-600` (the fill and link shade
the app uses most) maps to accent-700, not accent-500. The author is asked about this.

## Acceptance criteria

- [ ] `src/index.css` `@theme` defines the Organic ramps under these Tailwind names, with the exact values from `docs/design/organic/tokens.css`: `--color-accent` and `--color-accent-100` to `-900`; `--color-accent-2` and `--color-accent-2-100` to `-900`; `--color-neutral-100` to `-900` (this deliberately overrides Tailwind's built-in neutral palette); `--color-divider`. Plus one new token `--color-on-accent: #f5ead8` for text on a terracotta fill (not remapped in `.dark`).

  If a measured pair in the running app contradicts a number above, the implementer adjusts the mapping, says so in Notes, and logs it in `backlog/DECISIONS.md`.
- [ ] The `.dark` block in `src/index.css` is left as it is, so dark mode keeps today's dark surfaces with the terracotta `primary` ramp until RL-065 decides. Dark mode remains legible (the dark text tokens already clear 4.5:1).
- [ ] `danger-*`, `success-*` and `warning-*` are unchanged in this ticket.
- [ ] Fonts: `public/fonts/caprasimo-latin-400.woff2` and a Figtree latin woff2 covering weights 400, 600 and 700 (the variable file is fine), plus `public/fonts/OFL.txt`. Downloaded once from the Google Fonts css2 API (latin subset). `@font-face` rules in `src/index.css` with `font-display: swap`. `index.html` preloads the Figtree file (`<link rel="preload" as="font" type="font/woff2" crossorigin>`). Nothing in `index.html`, `src/` or `dist/` references `fonts.googleapis.com` or `fonts.gstatic.com`.
- [ ] `@theme` sets `--font-sans` to `"Figtree", system-ui, sans-serif` (so every existing utility and `body` get Figtree) and adds `--font-heading: "Caprasimo", system-ui, sans-serif` (a `font-heading` utility). `body` drops the hard-coded system font stack, and gets `font-size: 15px; line-height: 1.55`.
- [ ] `h1` to `h6` get, in `@layer base`: `font-family: var(--font-heading)`, `font-weight: 400`, `font-synthesis-weight: none` (Caprasimo has one weight; this stops the browser faking bold when an existing `font-semibold` class lands on a heading), `line-height: 1.12`, `letter-spacing: -0.015em`. No base font sizes are set on headings. The type scale is available as tokens `--text-h1: 42px`, `--text-h2: 32px`, `--text-h3: 25px`, `--text-h4: 20px`, `--text-h5: 16px`, `--text-h6: 13px` (giving `text-h1` to `text-h6` utilities) for later tickets to use.
- [ ] `--shadow-sm`, `--shadow-md`, `--shadow-lg` take the warm values from `tokens.css`. `--radius-card: 32px` is added (Organic `radius-lg * 1.15`, giving `rounded-card`). Tailwind's own `--radius-sm/md/lg` and `--spacing` are **not** overridden: overriding them would silently resize 18 existing `rounded-sm/md/lg` uses and every spacing utility. Log this in `backlog/DECISIONS.md` (alternative: adopt the 4.4px spacing base and 8/16/28px radii globally).
- [ ] Global focus: `:focus-visible { outline: 2px solid var(--color-accent); outline-offset: 2px; }` in `@layer base`, so elements without their own focus style still show one. Existing `focus-visible:outline-primary-500` classes keep working (primary-500 is the accent).
- [ ] `::selection` uses `color-mix(in srgb, var(--color-accent) 30%, transparent)`. The scrollbar thumb keeps `var(--color-border-strong)`.
- [ ] `index.html` light `theme-color` meta is `#f5ead8`; the dark one is unchanged. `vite.config.ts` manifest `theme_color` and `background_color` are `#f5ead8`, and the comment above them is updated to say so.
- [ ] Photo washing (`.washed`) from the tokens file is **not** added: decision 3 in `docs/decisions.md` (no photos, permanently).
- [ ] `docs/architecture.md`: the build section's Tailwind sentence says the theme is Organic, names the token source (`docs/design/organic/tokens.css`) and the self-hosted fonts in `public/fonts/`.
- [ ] `docs/decisions.md` gains an entry "Organic theme adopted (RL-062, date)": the semantic tokens are repointed rather than components rewritten; `primary-600` is accent-700 for AA; fonts are self-hosted to keep a third party out of the privacy policy; Tailwind radii and spacing deliberately not overridden.
- [ ] `docs/capabilities.md` "Theme (light / dark / system)" row notes that light is Organic and dark is an interim mapping pending RL-065.
- [ ] A `backlog/QA.md` entry: on the preview build at 390x844, walk the standing checks and confirm the cream ground, terracotta buttons and links, Caprasimo headings and Figtree body on Library, a recipe, the version tree, Settings and `/shared/:id`; that no heading looks fake-bold; that dark mode is still legible; DevTools Network shows no request to any Google Fonts host and the fonts load from `/fonts/`; offline reload still shows the fonts.

## Out of scope

- Restyling any component, including `Button`, `Chip`, `TopBar` and `BottomNav` (RL-063, and the nav is an open question).
- Any dark palette work beyond leaving `.dark` untouched (RL-065).
- Icons (RL-064).
- Changing `danger`, `success` or `warning` ramps, or replacing the 14 `text-white` and 5 `bg-black/50` uses.
- Legal or policy copy.

## Verification

`npm run build`, `npm run lint`, `npm test` (no test should depend on colour classes; if one
does, update the expectation, never weaken the assertion). `grep -r "fonts.g" dist index.html
src` returns nothing. `ui-reviewer` on the diff. Only a human in a browser can judge the
overall look, fake-bold headings, and font loading offline (QA.md entry above).
