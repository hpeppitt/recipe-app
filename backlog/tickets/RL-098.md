## Context

Spec (`docs/design/organic/export/App Spec.dc.html`, "Explore · landing (1b)"): "Route / ·
replaces LibraryPage". Markup: the `explore` block in `App Prototype.dc.html`. 1b's sections,
"Branching fast this week" and "Most branched", rank families by branching, which needs data
the app does not have (see Out of scope). This ticket ships the 1b page shell with the feed
that exists: the paged, newest-first Explore feed (`useCloudLibrary`, `buildFeed`,
`filterFeed` in `src/lib/library.ts`), its tag chips (RL-009), the Favourites and Following
filters, Load more, and the offline and error states. RL-099 adds a tile row on top.

What leaves with `LibraryPage`: the My Recipes tab (own recipes are now on the You tab, RL-095;
other people's on Saved, RL-091), the header avatar and settings buttons (now nav and You),
the `NotificationBell` (now the Activity tab, RL-092), the FAB (removed in RL-097), and the
`SegmentedControl` of tabs with `getLibraryTab`/`setLibraryTab` storage (leave the storage
helpers if other code uses them; otherwise remove with their tests).

Local-only mode has no shared library, so Explore there lists the device's root recipes
(`buildFeed(localRecords, localRecords)`) under the same header, with no chips beyond All,
and the empty copy "You haven't created a recipe yet" from today's My Recipes.

**Design token map:** `--color-bg` is `bg-surface`; `--color-surface` is
`bg-surface-secondary`; neutral-700 text is `text-text-tertiary`; neutral-800 text is
`text-text-secondary`; `tag-accent-2` is `bg-accent-2-100 text-accent-2-800`, 11px,
padding `3px 10px`, `rounded-full`. Light only: no `dark:` classes. 44px targets.

Values to copy:

- Header: padding `16px 20px 0`, flex, `align-items: flex-end`, gap 10px. Left: a 13px
  `text-text-tertiary` kicker from `dayPartLabel(new Date())` (RL-087), then "What's
  growing" in `font-heading` 30px, line-height 1.05, as the page `h1`. Right: a 44px
  `rounded-full` `bg-neutral-100` `shadow-sm` button with the `Search` icon (19px), label
  "Search".
- Search: the button toggles a search pill under the header (padding `14px 20px 0`): height
  52px, `rounded-full`, `bg-neutral-100`, `shadow-sm`, padding `0 6px 0 16px`, a `Search`
  icon in `text-text-tertiary`, an input 15px with placeholder "Search recipes and
  ingredients" and `aria-label` the same, and the existing 44px clear button. Opening moves
  focus into the input; Escape or clearing and closing restores the button focus. It filters
  with `filterFeed` exactly as today, including the result count line and the "Searching the
  N recipes loaded so far" line.
- Chips row: padding `14px 20px 4px`, horizontal scroll, gap 8px: All, Favourites (when
  `canFavorite`), Following (when allowed) and the followed people, as today, then the tag
  chips. Chip look is the shared `Chip` (RL-063).
- List heading: "Recipes" in `font-heading` 18px, padding `22px 20px 6px`.
- Row (link to `/recipe/:id`, padding `8px 0`, gap 12px, full width): a 48px circle
  `bg-surface-secondary` with the emoji at 24px; a block with the title 15px 700 and a 12px
  `text-text-tertiary` line, gap 8px, `margin-top: 2px`, holding the `UserPill` (RL-088,
  itself linking to the author's profile, lifted above the row link as `RecipeCard` does
  today) and `formatTime(totalTime)`; on the right, when `childCount > 0`, a `tag-accent-2`
  600 with `GitBranch` and the count. A favourited row shows a small filled `Heart` after the
  title as `RecipeCard` does.
- Load more: the existing secondary full-width button and error line, padding `0 20px`.
- States (RL-090): loading shows the 19a list skeleton; the cloud error uses `tone="error"`
  with today's copy and Try again; "Nothing published yet" and the search, favourites,
  following and tag empty states keep today's copy and actions, in the 19a layout. The
  offline case: an inline banner above the list, 13px, `rounded-[18px] bg-accent-100
  text-accent-900`, padding `10px 14px`, `CloudOff` icon, "You're offline. Showing what was
  loaded before." when cached rows exist.
