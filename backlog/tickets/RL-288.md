## Context

The author chose automatic capture and approved `html-to-image` by name as a client
dependency at `/groom` on 2026-10-22 (RL-284), which is the human approval `backlog/README.md`
requires for a client dependency. Why this library: it renders the DOM through
an SVG `foreignObject`, is much smaller than html2canvas, and is imported dynamically so it is
a separate chunk that only users who tap Feedback download. Known limits to state in the docs:
cross-origin images and iframes may be blank, and iOS Safari can drop web fonts on the first
capture.

## Acceptance criteria

- [ ] `services/pageCapture.ts` imports it dynamically, captures `document.body` at device pixel ratio 1 excluding the Feedback tab, and passes the result through `downscaleToJpeg` to at most 200000 characters.
- [ ] The capture happens before the sheet opens, so the sheet is not in it; the preview shows in the RL-287 tile, removable, with "Remove screenshot".
- [ ] A failed or slow capture (over 3 s) opens the sheet without a screenshot and the attach tile still works.
- [ ] `npm run build` output shows the library in its own chunk, not in the main bundle; the chunk size is recorded in Notes.
- [ ] `docs/capabilities.md` Feedback row and `docs/architecture.md` dependency list updated.
- [ ] A `backlog/QA.md` entry: "Tap Feedback on Explore, a recipe and the tree on iOS Safari and Android Chrome; check the preview matches the page."
- [ ] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Annotating or cropping the screenshot.
