## Context

RL-185/186 store `importedFrom` and `importedVia`. The author pill in the metadata row
(`MetadataPills.tsx`) names the recipe's author.

## Acceptance criteria

- [x] Under the title (originals: in place of the description's first line spacing; branches: above the lineage pill), a 13px `neutral-700` line with `ExternalLink`: "Imported from seriouseats.com", a link with `rel="noopener noreferrer nofollow"` and `target="_blank"`; for photo imports "Imported from a photo".
- [ ] "Imported from a photo" for photo imports (deferred: waits on the RL-251 importedFrom decision)
- [x] The author pill reads "via <name>" for imported originals.
- [x] Shown on the recipe page and the shared page when present.
- [ ] Shown on the chat card (not applicable: the chat card never shows imports)
- [x] Tests and `docs/capabilities.md`.
- [x] A `backlog/QA.md` entry: an imported recipe shows the line and the link opens the source.
- [x] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Fetching the source's own author name.

## Verification

Component tests.

## Notes

New `components/recipe/ImportedFrom.tsx`, used by `RecipeHeader` (original and branch) and `SharedRecipePage`. The "via" prefix is a `via` prop on `MetadataPills`, set by `RecipeContent` for a non-branch with `importedFrom`. Not done: "Imported from a photo" (photo imports save no `importedFrom`, rules accept only http(s); pending author decision from RL-251). Chat card shows neither line: it previews a proposed recipe that is never an import.
