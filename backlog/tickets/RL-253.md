## Context

RL-185/186 store `importedFrom` and `importedVia`. The author pill in the metadata row
(`MetadataPills.tsx`) names the recipe's author.

## Acceptance criteria

- [ ] Under the title (originals: in place of the description's first line spacing; branches: above the lineage pill), a 13px `neutral-700` line with `ExternalLink`: "Imported from seriouseats.com", a link with `rel="noopener noreferrer nofollow"` and `target="_blank"`; for photo imports "Imported from a photo".
- [ ] The author pill reads "via <name>" for imported originals.
- [ ] Shown on the recipe page, the shared page and the chat card when present.
- [ ] Tests and `docs/capabilities.md`.
- [ ] A `backlog/QA.md` entry: an imported recipe shows the line and the link opens the source.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Fetching the source's own author name.

## Verification

Component tests.
