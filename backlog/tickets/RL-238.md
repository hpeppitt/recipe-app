## Context

RL-213 assumed kitchen id = uid. Now the id comes from `kitchens where memberUids
array-contains uid limit 1` (first one wins; with none, the user's own id). Member names and
avatars come from `profiles` (public).

## Acceptance criteria

- [ ] `useKitchen` resolves the kitchen id as above before subscribing, and exposes `members: { uid, name, avatar }[]`, `isOwner`, `createInvite()` (returns the `/join/<code>` URL; code from `crypto.getRandomValues`, 20 URL-safe characters), `joinKitchen(code)`, `leaveKitchen()`, `removeMember(uid)`.
- [ ] Errors: expired or missing invite "This invite has expired. Ask for a new one."; full "This kitchen is full."; generic failure copy.
- [ ] The erase script removes the user from any kitchen they are a member of and deletes kitchens and invites they own (a dry run lists the other members affected); export includes membership.
- [ ] Tests for each path.
- [ ] `docs/data-model.md`.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

UI (RL-239, RL-240).

Tests, `data-integrity-reviewer`, emulator walk in Notes.

## Notes
The erase script only reads kitchens/{uid}; query memberUids array-contains uid, arrayRemove the uid and anonymise pantry addedBy for kitchens the user only belongs to.

From RL-237: on remove and before deleting a kitchen, delete the owner's live invites (owner can list them). Generate invite codes with crypto.getRandomValues (at least 20 URL-safe characters). Show the inviter's name from profiles/{ownerUid}.displayName, not the invite's ownerName. Treat 'already in memberUids' as joined. One kitchen per person is the client's job. The join writes joinCode = '<own uid>:<code>' with arrayUnion on memberUids and nothing else; the rules delete a kitchen only when the owner is its sole member.

From RL-237 round 2: Leave and remove send arrayRemove plus updatedAt serverTimestamp and joinCode deleteField(), so the same person can rejoin with a live link. The join is updateDoc with arrayUnion(uid) and joinCode only (no updatedAt), since a non-member cannot read the kitchen.
