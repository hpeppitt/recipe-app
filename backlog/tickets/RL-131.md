## Context

`UserPill` (`src/components/ui/UserPill.tsx`: neutral-100 pill, small `Avatar`, first name, not
a link; callers wrap it) is the design's way to name an author inline. It is already used on
Explore, Saved, Search, metadata pills and suggestions. Three places still name an author in
plain text or not at all:

- `BranchCarousel.tsx` ~121: `{card.title} · {card.createdBy.displayName || 'Anonymous'}`.
- The chat's similar-recipe panel (`RecipeChatPage.tsx` ~399-483): "Shared library, by <name>"
  from `SimilarRecipe.cloudOrigin.creatorName` (`useRecipeChat.ts` ~41-96). The type has no uid.
- `BranchComposer.tsx` ~119-145, the "Branching <title>" disclosure card: no author at all.

The pill is a span, so it can sit inside the composer's button and the carousel card.

## Acceptance criteria

- [x] Carousel card line: title, " · ", then `UserPill` for `card.createdBy` (no link; the card has Open). A `'local'` uid shows no pill, only the title.
- [x] `SimilarRecipe.cloudOrigin` gains `creatorUid: string | null` (set in `toCloudSimilar`); a cloud match by someone else shows "Shared library, by" then a `UserPill`; own matches keep "Your recipe, not on this device"; local matches show nothing new.
- [x] Composer card: "Branching **<title>**" followed by a `UserPill` for `parent.createdBy` when the uid is not `'local'`; the button stays one line with truncation on the title only, and keeps its 44px height.
- [x] Existing tests for the three components still pass; add one assertion per site that the pill's name renders.
- [x] A `backlog/QA.md` entry. `npm test`, `npm run lint`, `npm run build` pass.
