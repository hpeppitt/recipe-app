## Context

Spec (`docs/design/organic/export/App Spec.dc.html`, Original recipe): "Footer Suggest (or
Edit if yours) + Branch this recipe." Markup: the `notSuggest` footer in the `recipe` block of
`App Prototype.dc.html`.

Today the bottom of `RecipeDetailPage` has full-width stacked buttons: on someone else's cloud
recipe (`canSuggest`) "Suggest a Change" (primary) over "Create Variation" (secondary);
otherwise only "Create Variation" (primary). The block is deliberately not sticky (code
comment: pinning cost about 72px of the screen people read while cooking). The design draws a
pinned bar; keep it in the page flow unless the author decides otherwise (question in the
grooming report). Handlers stay: Suggest opens `SuggestChangeModal` (RL-107 later replaces
it), Branch goes to `/recipe/:id/vary`, Edit goes to `/recipe/:id/edit`.

**Design token map:** `--color-bg` is `bg-surface`; `--color-divider` is `border-border`.
Light only: no `dark:` classes. 44px targets.

Values to copy:

- Container: padding `12px 20px 28px` (bottom plus `env(safe-area-inset-bottom)`),
  `bg-surface`, top rule `box-shadow: 0 -1px 0` of the divider, flex, gap 10px, content to
  `max-w-lg`.
- Secondary button, `flex: 1`, height 52px, 15px, gap 6px: "Edit" with `Pencil` when the
  user owns the recipe (`isOwner`); "Suggest" with `MessageCircle` when `canSuggest`.
  Omitted when neither applies (a saved copy of someone else's recipe that is not in the
  cloud), and the primary then fills the row.
- Primary button, `flex: 2`, height 52px, 15px, gap 6px, `GitBranchPlus`, "Branch this
  recipe".
- Edit stays also in the More sheet (RL-100); the footer is the visible shortcut.

## Acceptance criteria

- [ ] The footer renders the buttons above per ownership and `canSuggest`, with today's handlers; the labels "Suggest a Change" and "Create Variation" are replaced by "Suggest" and "Branch this recipe" (search the tests and docs for the old labels and update them).
- [ ] The footer stays in normal flow at the end of the page (not `position: fixed` or sticky).
- [ ] `RecipeDetailPage.test.tsx` covers owner (Edit + Branch), non-owner cloud (Suggest + Branch), non-owner local copy (Branch only).
- [ ] A `backlog/QA.md` entry: the three cases at 390px and 320px; labels fit on one line at 320px; Branch signed out shows the existing sign-up screen on `/vary`.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Making the footer sticky. Suggest mode (RL-107). The sign-in sheet trigger (RL-108). Shared
page footer (RL-113).
