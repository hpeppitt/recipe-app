## Context

Spec (`docs/design/organic/export/App Spec.dc.html`, "Tree intro (16a)"): "Replaces TreeIntro.
Its diagram is a scaled 3a (14px elbows, 36px indent), per the decisions.md rule that the
intro mirrors the real tree. Shown Once per device, on first tree visit." Markup: 16a in
`Recipe Parts and System.dc.html` and the `sh.intro` block in `App Prototype.dc.html`.

`docs/decisions.md` ("Teaching the tree, and when not to", 2026-08-07) sets the timing: not
on the first recipe, not on a variation, once, and it rejects a modal on arrival. It also
notes that since RL-068 the diagram no longer matches the tree and "the redraw is pending
design (brief ticket 8)". The design's move to a sheet on the tree page contradicts those
timing rules, so it is a question for the author and not in this ticket. This ticket redraws
the existing inline card with the 16a visuals and keeps `shouldShowTreeIntro`
(`src/lib/onboarding.ts`) and its placement on `RecipeDetailPage` unchanged.

**Design token map:** `--color-bg` is `bg-surface`; `--color-surface` is
`bg-surface-secondary`; neutral-700 text is `text-text-tertiary`. Light only. 44px targets.

Values to copy (inline card, not a sheet):

- Card: `rounded-card bg-surface`, `shadow-md`, padding `16px`, column, gap 16px, with a
  visible heading.
- Diagram box: padding `16px 14px`, `rounded-[28px] bg-surface-secondary`, `aria-hidden`
  with a visually hidden sentence describing it ("An original recipe with two branches; one
  branch has its own branch, marked Here."). Root row: flex, gap 10px, padding `8px 12px`,
  `rounded-[20px] bg-surface`; 18px emoji 🍞, "Banana bread" 13px 700 flex 1, "Original"
  11px `text-text-tertiary`. Under it, `margin-left: 26px`, three child rows, each
  `position: relative; padding-top: 8px`:
  1. indent 0: a full-height rail `border-left: 3px solid` neutral-400 at left 0; an elbow at
     left 0, 14px wide, 28px tall, `border-left` and `border-bottom` 3px accent,
     `border-bottom-left-radius: 12px`; a node `margin-left: 18px`, padding `7px 12px`,
     `rounded-[18px] bg-surface`, 12px 700 "\"less sugar\"".
  2. indent 36px: the same rail at left 0; an accent elbow at left 36px; a node with
     `box-shadow: 0 0 0 2px` accent, "\"extra banana\"" flex 1, and a "Here" tag
     (`bg-accent text-on-accent` is 3.03:1 at 10px, so use `bg-primary-600 text-on-accent`),
     10px, padding `2px 8px`.
  3. indent 0: no rail; a neutral-400 elbow at left 0; "\"add chocolate\"".
- Heading `font-heading` 24px, line-height 1.1: "Every recipe can grow branches".
- Steps, column gap 10px, 14px, each flex gap 10px with a 24px `rounded-full
  bg-accent-2-200 text-accent-2-800` 12px 700 number disc: "1 Someone asks for a change,
  like "less sugar"." / "2 A new version grows off it. The original never changes." /
  "3 The terracotta line shows how you got here."
- Actions: primary 52px full width "Got it" (dismisses, as today); when the recipe has
  children, a secondary "See the tree" (today's `onOpenTree`).
