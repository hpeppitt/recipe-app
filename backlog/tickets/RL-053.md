## Context

The author is adding PostHog product analytics. `posthog-js` ships in the client bundle, and
adding such a dependency is on the "What needs a human" list in `backlog/README.md`. Choosing
a data host and creating an account with a third party are the author's too. RL-054 is the
implementation and cannot start until this is done.

## Acceptance criteria

- [ ] A PostHog project exists. The host is chosen and recorded; EU Cloud is recommended for GDPR.
- [ ] In the project settings: IP capture is discarded or anonymised, session recording is off, autocapture is off, and the data retention period is set and written down for the Privacy Policy.
- [ ] The project API key (public by design, like the Firebase config) and the host URL are handed to the implementer for `.env`, never committed.
- [ ] The author approves adding `posthog-js` as a client dependency, and `docs/decisions.md` records the decision and the host, next to "Firestore as its own error sink, not Sentry".
- [ ] The same `docs/decisions.md` entry records the decision already made on 2026-10-14: PostHog replaces GA4, which RL-058 removes.
