## Context

The Units preference is a local setting (`services/storage.ts` `getUnitSystem`, synced across
mounted screens by `hooks/useUnitSystem.ts` with a window event and `storage`). The new toggle
follows the same pattern. Settings already renders a switch (`role="switch"`, analytics consent,
~348). RL-182 provides `estimateGrams`.

### The design (the implementer has no other copy)

In the Appearance card under Units: a row "Weigh spoons and liquids" (15px) with a 13px
`neutral-700` sub-line "Show tbsp, tsp, cups and ml as estimated grams", and a 44x26 switch at
the right (track `accent-2-600` on, `neutral-400` off; 20px knob on the ground colour, 3px
inset). On a recipe, an affected amount reads "≈15 g" in place of "1 tbsp"; it still turns
terracotta when scaled.

## Acceptance criteria

- [ ] Stored as `recipe-lab-weigh-volumes` (`'1'` or absent) through `services/storage.ts` (never throws, defaults off), exposed by `useWeighVolumes()` with the same change event pattern.
- [ ] When on, `IngredientList` renders `estimateGrams` output for affected rows after scaling and unit conversion, as "≈<n> g", with `title="<original amount>"` and a visually hidden "(estimated from <original>)" for screen readers. Rows it cannot estimate are unchanged. Applies on the recipe page, the shared page and the chat card.
- [ ] Suggest mode and the edit page always show the stored amounts (never estimates).
- [ ] `docs/decisions.md` gains "Weighing spoons and liquids is an opt-in estimate (RL-183, 2026-10-xx)": the default still refuses to guess a density; the opt-in uses the density table or water and marks every estimate with ≈; this reverses the "leave unconvertible amounts as written" rule only while the toggle is on, on the author's 2026-10-20 roadmap.
- [ ] `docs/capabilities.md` Unit system row.
- [ ] Tests: storage default and toggle, rendering with and without, scaled amounts, suggest mode unaffected.
- [ ] A `backlog/QA.md` entry: turn it on in Settings, open a recipe with tbsp and ml; amounts read ≈ grams; long-press or hover shows the original; scaling updates them; off restores.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Syncing the setting to the account. Changing stored amounts.
