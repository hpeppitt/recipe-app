## Context

`/new` (RL-125, `lib/createPrompt.ts` `buildCreatePrompt`) builds "Something <a> with <b> for
<c>". This adds profile terms after it: ", no peanuts, under 30 min". "Under 30 min" appears
when "Quicker" is in tendToChange (RL-229). Avoids also go into the system prompt (RL-233), so
a dropped avoid must also leave that chat's system prompt: Write it passes
`state: { suggestion, dropAvoids: string[] }` and `useRecipeChat` omits those for that chat only.

## Acceptance criteria

- [ ] `buildCreatePrompt(selection, terms)` appends the kept terms; tests for none, one, several.
- [ ] The terms render bold (`font-semibold`) as buttons ("Drop no peanuts for this recipe"); a dropped term is struck through and can be tapped back; drops reset each visit.
- [ ] Only for verified users with a profile.
- [ ] Tests and `docs/capabilities.md` Create tab row.
- [ ] A dropped avoid is passed as `dropAvoids` and omitted from that chat's system prompt only (hook test).
- [ ] A `backlog/QA.md` entry: with an avoid set, the sentence shows it bold; drop it and Write it: the composer text omits it and the recipe may use it; the next chat respects it again.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Changing the stored avoids from this screen.

## Verification

Component tests.
