## Context

The 4b Forest view (RL-175) draws each family a person took part in as a small 140x74 SVG with
their versions in accent. This is the pure geometry and copy, tested in node. Tree helpers
live in `src/lib/tree.ts` (`buildTree`, `ancestorChain`); reuse them rather than re-deriving
depth.

## Acceptance criteria

- [x] `layoutForestFamily(recipes, personUid)` returns `{ dots: { id, x, y, r, mine }[], path: string, planted: boolean, grewCount: number, target: string }` using the prototype's rule: depth from the root via the parent chain (not stored `depth`); x = 14 + depth * 112 / maxDepth (70 when the family is one node); y = (j + 1) * 74 / (nodesAtDepth + 1); root radius 7, others 5; `mine` when `createdBy.uid === personUid`; `path` is one SVG path of cubic curves `M ax ay C ax+18 ay bx-18 by bx by` from each parent to child; `planted` when the person owns the root; `grewCount` = the person's non-root versions; `target` the root id when planted, else the person's first version.
- [x] `forestSummary(families, personUid)` returns `{ planted, grown }`: planted = families whose root is theirs, grown = branches by anyone under those roots.
- [x] `forestHeadline(planted, grown)` returns "Planted 12 recipes. 31 branches have grown from them." with the singular forms "1 recipe", "1 branch has", "it".
- [x] Families with more than 40 versions are drawn from the first 40 by `createdAt` (comment the shortcut).
- [x] Tests for one-node, chain, wide and mixed-owner families, and every headline form.
- [x] `npm test`, `npm run lint`, `npm run build` pass.
