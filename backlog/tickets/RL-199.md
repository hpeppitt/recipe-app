## Context

Public, so it shows signed out (RL-192 answer 4). Data from `useRecipeCooks` (RL-196); copy
from `madeByLine` and `recentCooks` (RL-195). Avatars use the generated avatar like other
recipe surfaces (`components/ui/Avatar.tsx`).

### The design (the implementer has no other copy)

Directly under the metadata pills, 8px top margin: a row on `bg-neutral-100`, 24px radius,
padding 12px 14px, gap 10px: an overlapping stack of up to three 28px avatars (each -8px margin,
2px `neutral-100` ring), then 13px text with "**Made 31 times**" bold and " · 27 would make
again", flex 1, then a 13px semibold `accent-700` "Notes" button (only when at least one note
exists). Hidden while loading, at zero cooks, on failure (reported) and in local-only mode.

**Notes sheet**: Caprasimo 24px "Notes from cooks", then up to 20 notes newest first: 32px
avatar, name 14px bold, `cookWhen` 12px `neutral-700`, the vote as a small tag (Again on
`accent-2-200`, Tweak on `accent-100`), and the note 14px italic. A note the viewer wrote has a
"Delete" text button (calls `deleteCook` after a 19a confirm "Delete this cook? It leaves your
cook log too.").

## Acceptance criteria

- [x] The row and sheet render as above on the recipe page (originals and branches) and `/shared/:id`, not on the chat card.
- [x] Accessible: the row reads as one sentence; Notes has `aria-haspopup="dialog"`.
- [x] Tests: hidden at 0, singular and plural copy, avatars capped at 3, notes listed, own delete.
- [x] `docs/capabilities.md` row for Made-by.
- [x] A `backlog/QA.md` entry: log two cooks from two accounts (emulator or live after RL-209), open the recipe signed out: the row shows both, Notes lists them.
- [x] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Paging notes beyond 20. Cook counts on the tree (RL-246).
