## Context

`MetadataPills.tsx` shows author, time (clock), difficulty (gauge), kcal (flame, accent tag)
and optional servings and prep/cook. RL-102 left macro pills and the diet pill out ("no such
field"). The author decided on 2026-10-20: macro pills per serving, and a diet pill only from
`recipe.tags` when a known diet tag exists, with no new field. `Nutrition` (`src/types/recipe.ts`)
is per serving already (`calories`, `protein`, `carbs`, `fat`, grams); scaling never touches it
(decisions.md "Serving scaling is a display transform"). `Wheat`, `Droplet`, `Drumstick` exist
in `src/components/ui/icons.tsx`; `Leaf` does not.

### Design

Pill order: author, time (clock), difficulty (gauge), diet (leaf), kcal (flame, accent),
carbs (wheat), fat (droplet), protein (drumstick), then the existing servings and prep/cook pills.
Diet and macro pills use the existing neutral style (`NEUTRAL`: neutral-100 fill,
neutral-800 text, 13px, 5px 12px padding, 14px icon). Text: "Vegetarian", "34 g carbs",
"11 g fat", "4 g protein" (rounded to whole grams). Each macro pill has
`aria-label="34 g carbs per serving"`.

## Acceptance criteria

- [ ] New pure `dietLabel(tags: string[]): string | null` in `src/lib/diet.ts`: case-insensitive, ignores spaces and hyphens, and returns the first match in this priority: vegan "Vegan", vegetarian "Vegetarian", pescatarian "Pescatarian", gluten-free "Gluten-free", dairy-free "Dairy-free", keto "Keto", paleo "Paleo". Unknown tags give null. Imports nothing from `services/` or `hooks/`.
- [ ] `src/lib/diet.test.ts`: each label, priority (vegan beats vegetarian), case and hyphen variants ("Gluten Free", "glutenfree"), empty and unknown.
- [ ] `MetadataPills` takes an optional `tags` prop and renders the diet pill when `dietLabel` returns one; callers that render a recipe page (`RecipeContent`) pass `recipe.tags`.
- [ ] With `nutrition` present the three macro pills render after kcal in the order above; with nutrition absent none render. Zero grams still render ("0 g fat").
- [ ] `Leaf` added to `icons.tsx` from Lucide (ISC), same `Icon` wrapper: paths `M11 20A7 7 0 0 1 9.8 6.1C15.5 5 17 4.48 19 2c1 2 2 4.18 2 8 0 5.5-4.78 10-10 10Z` and `M2 21c0-3 1.85-5.36 5.08-6C9.5 14.52 12 13 13 12`.
- [ ] `MetadataPills.test.tsx`: order of pills, macro text and aria-labels, no macros without nutrition, diet pill present and absent.
- [ ] `docs/capabilities.md` "Per-serving macro estimates" row mentions the pills; the diet pill note says it reads tags, no field.
- [ ] A `backlog/QA.md` entry. `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Nutrition panel Per serving / Total toggle and bars (kept out by the author). A `diet` field.
Changing what tags the generator writes. The chat card's pills beyond what the shared component
gives it for free.

## Verification

Gates: tests, `ui-reviewer`. Human at 390 and 320px: a recipe with nutrition and a "vegetarian"
tag shows the pills in order and wraps cleanly; a recipe without nutrition shows no macros. Dark
theme contrast of the neutral pills.
