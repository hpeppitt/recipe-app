## Context

The Organic design export (`docs/design/organic/export/App Spec.dc.html`, with markup in
`App Prototype.dc.html`) needs three small pieces of text logic that later layout tickets
render. They are pure, so they belong in `src/lib` with tests, and nothing in `lib/` may
import from `services/` or `hooks/` (`docs/architecture.md`).

1. **Explore kicker (1b).** Above the "What's growing" heading the design shows a 13px line
   such as "Tuesday evening".
2. **Lineage collapse (17a).** The sage lineage strip on a branch shows the path from the
   original to the parent. Rule from the spec: "Root and parent always shown; deeper paths
   collapse to "+N"", and "+N" expands inline when tapped. Example from
   `Recipe Parts and System.dc.html` 17a: at depth 5 the strip reads
   `🍞 Banana bread > +3 > Walnut > this`.
3. **Scaled note (18a).** When the serving stepper moves off the stored count the design
   shows a strip "Scaled ×1.5 from 8." with a Reset link. `formatAmount` in
   `src/lib/amount.ts` already renders halves and quarters as glyphs (1.5 becomes "1½").

## Acceptance criteria

- [ ] `dayPartLabel(date: Date): string` in `src/lib/utils.ts` returns `"<Weekday> <part>"` in local time, weekday in full English ("Tuesday"), part `morning` from 05:00 to 11:59, `afternoon` 12:00 to 16:59, `evening` 17:00 to 21:59, `night` 22:00 to 04:59. Tests cover each boundary and a night that crosses midnight (Tuesday 02:00 reads "Tuesday night").
- [ ] `collapseLineage<T>(ancestors: T[], expanded: boolean)` in `src/lib/tree.ts` takes the ancestors ordered root first, parent last (the current recipe excluded) and returns a list of `{ kind: 'item', item: T }` and `{ kind: 'more', count: number }`. With two or fewer ancestors, or `expanded` true, every ancestor is an item. Otherwise it returns root, one `more` with `count = ancestors.length - 2`, then parent. Tests: 0, 1, 2, 3 and 5 ancestors, collapsed and expanded.
- [ ] `scaleNote(servings: number, original: number): string | null` in `src/lib/scale.ts` returns `null` when they are equal or `original` is not positive, otherwise `` `Scaled ×${formatAmount(round2(servings / original))} from ${original}.` `` where `round2` rounds to two decimals. Tests: 12 from 8 is "Scaled ×1½ from 8.", 4 from 8 is "Scaled ×½ from 8.", 10 from 8 is "Scaled ×1¼ from 8.", 8 from 8 is null.
- [ ] No new imports into `src/lib` from `services/` or `hooks/`.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
