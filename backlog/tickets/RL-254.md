## Context

The PWA manifest is generated by `VitePWA` in `vite.config.ts`. The Web Share Target API
(`share_target` in the manifest, GET with `url`, `text`, `title` params) works for installed PWAs
on Android Chromium. iOS does not support share targets for web apps, and native apps are a
rejected approach (decisions.md), so iOS is out (say so in capabilities).

## Acceptance criteria

- [ ] Manifest `share_target: { action: '/import', method: 'GET', params: { title: 'title', text: 'text', url: 'url' } }`.
- [ ] `/import` reads `url`, or the first http(s) URL found in `text`, normalises it (RL-185) and starts reading at once.
- [ ] Tests for param parsing.
- [ ] `docs/capabilities.md` Import row states Android only.
- [ ] A `backlog/QA.md` entry: on an Android phone with the app installed, share a recipe page from Chrome to Recipe Lab; the review opens.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

iOS. Sharing images to the app.
