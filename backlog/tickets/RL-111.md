## Context

Spec (`docs/design/organic/export/App Spec.dc.html`, "Chat (6a)"): "Replaces RecipeChatPage.
The recipe is a collapsible card at the top; refinement chips sit above the composer. Save
creates an original." Markup: 6a in `Social Auth and Generate.dc.html` and the `chat` block
of `App Prototype.dc.html`.

Today `src/pages/RecipeChatPage.tsx` serves `/create` and `/recipe/:id/vary`. It has a
`TopBar` ("New Recipe" or "New Variation"), the sign-up gate for users who cannot generate
(`canGenerate`), notices (generation unavailable, parent loading, parent failed, parent
missing), the collapsible parent preview for variations, starter chips (`SUGGESTION_CHIPS`),
user bubbles, a `RecipeCardMessage` per assistant turn with Save on every version ("Save
Recipe", "Save Variation", "Save This Version"), the similar-recipes panel (dedup,
first message only), `TypingIndicator` ("Checking for similar recipes...", "Generating
recipe..."), the error box with Try again, `ChatInput`, and the discard dialog with the
sentinel history guard. All behaviour stays. The variation-specific first screen is RL-112;
this ticket restyles everything shared and the `/create` flow.

Refinement chips: after a recipe exists, three chips send a fixed message through the existing
`sendMessage`, the same as typing it: "Make it spicier", "Fewer dishes", "No dairy". They are
static strings in `src/lib/constants.ts`, beside `SUGGESTION_CHIPS`.

**Design token map:** `--color-bg` is `bg-surface`; `--color-surface` is
`bg-surface-secondary`; neutral-700 text is `text-text-tertiary`; neutral-800 is
`text-text-secondary`; filled terracotta with cream is `bg-primary-600 text-on-accent` (the
design's user bubble uses `bg-accent`, which is 3.03:1 for 15px cream text; use primary-600).
Light only. 44px targets.

Values to copy:

- Header: padding `12px 12px 8px`, flex, align centre: a flat `IconButton` with `X`, label
  "Close", running today's back and discard guard; title in `font-heading` 18px flex 1,
  "New recipe" (or "New variation").
- Body: padding `4px 18px 12px`, column, gap 12px.
- User bubble: `align-self: flex-end`, max-width 280px, padding `12px 16px`, radius
  `24px 24px 6px 24px`, `bg-primary-600 text-on-accent`, 15px.
- Recipe card: padding 16px, `rounded-[30px] bg-surface-secondary`, column, gap 10px. Top
  row, gap 12px: a 52px `EmojiBlob` tinted `bg-surface`, emoji 28px; title `font-heading`
  20px, line-height 1.1; meta 12px `text-text-tertiary` "<time> · <difficulty> · <n>
  ingredients"; a 36px round `bg-surface` toggle with `ChevronDown` or `ChevronUp`,
  `aria-expanded`, label "Show full recipe" or "Hide full recipe". Collapsed: a 13px
  `text-text-secondary` line of ingredient names joined by " · ", cut at about 8 with an
  ellipsis, and a 40px secondary `bg-surface` "Read full recipe" button that expands.
  Expanded: today's full content (pills, ingredients, method, nutrition, notes, tags). The
  newest card starts expanded, older ones collapsed. Save button: primary 46px full width,
  `Bookmark` icon, today's labels and saving state.
- Similar recipes panel: same content and actions, restyled as a `rounded-[24px]
  bg-accent-2-100 text-accent-2-900` card, padding `12px 14px`, 13px, `GitBranch` icon in the
  heading; rows in `bg-surface rounded-[20px]`; buttons as today.
- Typing indicator: three 8px dots `bg-accent-400`, `bg-accent-300`, `bg-accent-200`, gap
  4px, then the label 13px `text-text-tertiary`; dots animate only without reduced motion.
- Error: inline `rounded-[18px] bg-accent-100 text-accent-900` 14px box, today's message and
  Try again and Open Settings.
- Chips: when a recipe exists and nothing is loading, a horizontal row above the composer,
  padding `0 16px 10px`, gap 8px: 36px pills `bg-accent-200 text-accent-900`, 13px. Before
  any recipe, today's starter chips in the same style, under "What would you like to cook?"
  in 15px.
- Composer (`ChatInput`): padding `0 16px 28px` (plus safe area); a 52px pill
  `bg-neutral-100 shadow-sm`, padding `0 6px 0 18px`, the input 15px (placeholder "Ask for a
  change…" once a recipe exists, otherwise today's placeholders), a 40px round
  `bg-primary-600 text-on-accent` send button with `ArrowUp`, label "Send".
- Sign-up gate (cannot generate): the 19a empty-state layout with a `Sparkles` icon, today's
  headline and body, the `EmailLinkingForm` invite form under it, the "You can keep
  browsing..." line and "Back to recipes".
- Notices (unavailable, parent loading, failed, missing): `rounded-[22px]` cards,
  `bg-surface-secondary`, 14px, today's copy and buttons.

## Acceptance criteria

- [ ] `/create` renders as above; every behaviour listed in Context still works, including saving any version, the dedup panel, retry, the discard guard and the sign-up gate.
- [ ] Refinement chips call `sendMessage` with their label and are hidden while loading.
- [ ] The newest recipe card is expanded and older ones collapsed; the toggle is keyboard operable with `aria-expanded`.
- [ ] Tests: add `RecipeChatPage` or component tests for the chip send, card collapse and the composer placeholder switch (there is no page test today; keep it light and mock generation as other tests do).
- [ ] A `backlog/QA.md` entry: on the preview as a verified user at 390px: generate, refine with a chip and by typing, collapse and expand cards, save an older version, trigger the similar panel with a common dish, go offline and retry, press Back with an unsaved recipe; signed out see the gate; iOS keyboard does not hide the composer.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
