## Context

Explore's 1b design ranks families by how often they were branched ("Most branched, all time",
top 3). Published recipes carry no branch counter (`favoriteCount` and `viewCount` only, see
docs/data-model.md "Counter integrity"), and adding one would need a rules change for a foreign
bump. RL-126 solved the same problem for "Branching fast this week" with one bounded
`createdAt` query (`getRecentPublishedRecipes`, `useBranchingThisWeek`, decisions.md
"Branching fast this week uses one bounded createdAt query"). This ticket does the same for a
wider window. It is the data half; RL-167 draws the section.

## Acceptance criteria

- [ ] `mostBranched(recipes, { sinceMs, now, limit = 3 })` in `src/lib/library.ts`: counts branches (rows with a `parentId`) per `rootId`, only those with `createdAt >= sinceMs` when `sinceMs` is a number (null means all), drops families with zero, sorts by count descending then by the newest branch, and returns `{ rootId, count }[]` of at most `limit`. Tests cover the windows, ties, a root missing from the input, and an empty input.
- [ ] `useMostBranched(range)` in `src/hooks/useMostBranched.ts` with `range: 'all' | '30' | '90'`: one `getAllPublishedRecipes(300)` read per session (module-level cache like `useBranchingThisWeek`, bounded at 6 s, failure reported as `most-branched`), the ranking recomputed in memory when the range changes, and the root of each ranked family resolved from the result or with at most 3 `getDoc` reads for roots outside it.
- [ ] Honest window: the hook returns `allTimeAvailable: false` when the read returned the full 300 (the library is bigger than the window), so RL-167 can hide "All time" and default to "Last 90 days". Comment it as `shortcut: counts only the newest 300 published recipes, upgrade to a server-side counter`.
- [ ] Local-only mode returns an empty list and reads nothing.
- [ ] `docs/data-model.md` gains a paragraph under the RL-126 one with the read cost (at most 303 reads per session) and the window; `docs/capabilities.md` Explore row says the ranking exists (the section ships in RL-167).
- [ ] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

The Explore section and its range picker (RL-167). A stored branch counter. Cook-based ranking (RL-243).

## Verification

Unit tests for the pure function and the hook (Firestore mocked). No browser check on its own.
