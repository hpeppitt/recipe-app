## Context

Written for RL-210's item shape. Ingredients are `{ amount: number | null, unit: string | null,
name, notes, group }` (`types/recipe.ts`). Scaling is `scaleIngredients` (`lib/scale.ts`);
units normalise with `canonicalUnit` (`lib/units.ts`); diffs already match ingredients by the
name before the first comma (spec §3), so use the same key. Pure logic first, tested.

## Acceptance criteria

- [ ] `itemKey(name)`: lower case, before the first comma, trimmed, simple plural folded ("eggs" and "egg" match; "tomatoes" and "tomato").
- [ ] `AISLES = ['Produce', 'Dairy', 'Meat and fish', 'Bakery', 'Pantry', 'Frozen', 'Other']` and `aisleFor(name)` from a keyword table (about 80 common words, e.g. banana, onion, spinach → Produce; butter, milk, egg, cheese, yoghurt → Dairy; flour, sugar, miso, rice, pasta, oil, salt → Pantry). Unknown → Other. Comment that it is a heuristic.
- [ ] `addRecipe(list, recipe, servings)`: scales, then for each ingredient merges into an existing line with the same key and the same canonical unit (summing amounts, adding the source once), else adds a line; an ingredient with a null amount merges by key only and shows no amount. Different units for the same key stay separate lines.
- [ ] `removeSource(list, recipeId)` subtracts that recipe's contribution, dropping lines that reach nothing.
- [ ] `splitByPantry(list, pantry)` returns `{ toBuy, inPantry }` by key; `listSummary` gives "11 to buy · 5 already in the pantry" (singulars, "Nothing to buy" at 0).
- [ ] `groupByAisle(lines)` in `AISLES` order, alphabetical inside.
- [ ] `boughtItAll(list, pantry, now, uid)` returns the emptied list and the pantry with every line added (group `fresh` for Produce, Dairy, Meat and fish, Bakery; else `cupboard`), skipping keys already there.
- [ ] `formatLineAmount(line)` uses `formatAmount` and `formatUnit` ("230 g", "2 × 90 g" is out of scope: show "180 g").
- [ ] Tests for each function, including the canvas example: butter 115 g from two recipes sums to 230 g with both emoji.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Persistence (RL-213). Unit conversion between systems when summing (separate lines are fine).

## Verification

Unit tests.
