## Context

`SuggestionList.tsx` (RL-105) renders open cards (UserPill, time, Open tag, raw `message`,
Decline / Replies / Approve) and closed one-line rows tagged Approved or Declined. RL-148 gives
`apply`, `keepAsBranch`, `decline` and the errors; RL-145 gives `describeEdit`,
`hasApplicableEdits` and the `edits` model. The visibility of suggestions (owner sees all, others
their own) is unchanged; it is a rule (RL-018).

### Design (10b)

Section header unchanged ("Suggestions", "1 open · 2 closed"). Open card: `bg-surface`
(ground), radius 28px, padding 14px, `shadow-md`, gap 10px:
1. Avatar row: UserPill (linked to the profile), time, `Open` tag (accent-100, accent-800, semibold).
2. **Diff rows**, one per ingredient or step edit, in a new `SuggestionDiffRow` component (reused
   by RL-150): accent-100 fill, radius 16px, padding 8px 12px, 14px text, flex gap 10px.
   Ingredient: **new amount** (bold), the name (flex 1), the old amount struck at the right (12px,
   neutral-700, `<s>`, with sr-only "was"). Step: "Step N" bold, the new text (flex 1, clamp 2
   lines), no struck text. A general note is not a diff row.
3. The note (14px): the general edit's text, else the ingredient/step `why`s joined, else for an
   old free-text suggestion the `message`.
4. Replies link: 13px semibold accent-700, MessageCircle icon, "Replies" (or "Reply" for the
   suggester), to the thread.
5. Owner actions, 44px, flex gap 8px: **Decline** (secondary, flex 1), **Apply** (primary, flex 1;
   reads **Mark applied** when there are no applicable edits), and a 44px secondary icon button
   "More options" (Ellipsis) opening a small `Sheet` with one row "Keep as branch" (GitBranch
   icon), shown only when `hasApplicableEdits`.

Closed rows: avatar, the first `describeEdit` (or the message), and a tag: Applied
(accent-2-100, accent-2-800), Branched (same sage; the row links to the branch), Declined
(neutral-100, neutral-800), Approved for old documents (sage).

## Acceptance criteria

- [ ] Open cards and closed rows render as above for suggestions with and without `edits`; Approve is gone.
- [ ] Apply and Keep as branch call RL-148's hook and disable every review button while one is in flight ("Working…" on the pressed one); Decline keeps its confirm dialog; errors show in the section's alert line.
- [ ] A Branched row opens `/recipe/<branchId>`; other closed rows open the thread as today.
- [ ] `SuggestionDiffRow` is accessible as text: "Change light brown sugar from 150 g to 100 g" via an sr-only sentence, visual parts `aria-hidden`.
- [ ] Tests: diff rows for ingredient and step edits; Mark applied for a free-text suggestion; Keep as branch only with applicable edits; tag labels for each status including legacy approved; the suggester sees no actions.
- [ ] A `backlog/QA.md` entry. `npm test`, `npm run lint`, `npm run build` pass.
