## Context

Data and actions from `useKitchen` (RL-213), grouping and copy from `lib/shopping.ts` (RL-212).
Outside `AppShell` with its own back button. Shop mode is RL-217.

### The design (the implementer has no other copy)

- Top row: back (`ChevronLeft`) and, at the right, a 44px Share icon button (`Share`): Web Share
  API with the list as plain text ("Shopping list\n\nPRODUCE\n- Spring onions, 1 bunch\n..."),
  falling back to copying it with a "Copied" toast.
- Caprasimo 30px "Shopping list", 13px `neutral-700` `listSummary`.
- Source chips (14px 22px 0, gap 8px, scroll sideways): one per recipe, 34px pills, 13px
  semibold, "<emoji> <title> ×N" (×N when added N times), on rotating `accent-200`/`accent-2-200`
  with matching 900 text, each with an `X` that calls `removeSource` (name "Remove <title>").
  Then a 34px round `Plus` button (inset `divider` ring) linking to Explore (name "Add a recipe").
- Aisles (16px 22px 0, 14px gap): 12px bold `neutral-700` upper-case aisle name, then lines:
  9px vertical padding, hairline divider (`border-divider`), gap 12px: a 26px check circle
  (unticked: inset 2px `neutral-400` ring; ticked: `bg-accent-2-600` with a white `Check`), the
  name 15px (ticked: struck through, `neutral-600`), the amount 13px semibold, and the source
  emoji. The whole line toggles (a native checkbox named "<name>, <amount>").
- Pantry notice when `inPantry` is not empty: `bg-accent-2-100`, `text-accent-2-900`, 20px
  radius, padding 10px 14px, `Refrigerator` icon, 13px "Bananas, eggs and flour are in your
  pantry." Those lines are not in the aisles.
- Footer (12px 20px 28px, gap 10px): "Shop mode" (52px, inset 2px `divider` ring, Caprasimo 15px,
  `Store` icon) and primary "Bought it all" (52px, `bg-accent`, `ShoppingBag` icon). Bought it all
  asks a 19a confirm "Move everything to the pantry?" (Keep it / Move) then calls `boughtItAll`.
- Empty: 19a empty state "Nothing to buy" · "Add a recipe's ingredients from its menu." · "Explore
  recipes".
