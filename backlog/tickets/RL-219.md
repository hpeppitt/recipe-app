## Context

`VersionTreePage` (Tree, Timeline and Map views, `?view=`) has the family loaded. Each
version's change against the original comes from `diffRecipes` and `summariseChanges`
(`lib/recipeDiff.ts`). Explore tiles have no designed affordance for this, so only the tree page
gets the entry (groomer choice, log it).

### The design (the implementer has no other copy)

- Entry: a 44px icon button `ShoppingBasket` ("Add to shopping list") in the tree page header,
  visible in every view, verified users only (others: the sign-in sheet).
- Sheet (12px 22px 28px, gap 14px): Caprasimo 24px "Which <family title, lower case> are you
  shopping for?". Radio rows (gap 8px), padding 12px 14px, 24px radius, `bg-surface-secondary`;
  selected `bg-accent-100` with an inset 2px `accent` ring. Each: a 22px radio dot (inset 2px
  `neutral-400`, selected 7px `accent`), title 15px bold over a 12px `neutral-700` sub ("The
  original · <author>", "<author>", plus " · you made this" when the user has a cook of it, and
  "Most cooked" once RL-245 exists), and at the right a 12px `neutral-700` change summary
  ("−50 g sugar, +1 banana", first two `summariseChanges` tags). Default selection: the version
  the user is on.
- Makes stepper: a pill on `bg-surface-secondary`, padding 8px 8px 8px 18px: "Makes" 14px, then
  40px round −/+ on the ground and Caprasimo 18px "12 slices" (servings with the recipe's unit
  word when it has one, else "servings").
- Primary 52px "Add 6 things to the list" (`ShoppingBasket`), the count excluding pantry lines.

## Acceptance criteria

- [ ] Header button, sheet and add behave as above; at most 30 versions listed (the tree's readable limit), scrolling inside the sheet.
- [ ] Adding toasts like RL-218 and closes the sheet.
- [ ] Tests: default selection, change summary, stepper, count excludes pantry, add called with the chosen recipe and servings.
- [ ] `docs/capabilities.md` Version tree row.
- [ ] A `backlog/QA.md` entry: on a family with three versions, pick a branch, change Makes, add; the list shows that branch's amounts.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
