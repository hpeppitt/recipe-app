## Context

**Author's decision (2026-10-19, /groom):** the user-facing word "favourite" becomes "Saved"
(and "save" as the verb and count noun), and the Explore "Favourites" filter chip is dropped
because the Saved page covers it. RL-121 lists favourites on the Saved page; RL-122 turns the
heart into a bookmark "Save" toggle and already replaces the toggle's aria-labels ("Add to
favorites" / "Remove from favorites" become "Save" with `aria-pressed`). This ticket is the
rest of the copy that RL-122 left out on purpose (its Out of scope and Notes).

**Only words change.** The data model stays as it is: Dexie table `favorites`, Firestore
collection `favorites`, field `favoriteCount`, notification `type: 'favorite'`, hooks
`useFavorite`/`useCloudFavorite`/`useFavoriteIds`, `filterFeed`'s `favoriteIds` option, the
`reportError` tags (`favorite`, `unfavorite`, `favorite-lookup`, `favorites-hydrate`,
`favorites-upgrade`, `favorites-hydrate-local`), console messages, and code comments.
Analytics events stay too: `trackFavoriteToggled` in `src/services/analytics.ts` sends
`recipe_favorited` / `recipe_unfavorited`, and renaming them would break PostHog history.
`src/lib` has no event names.

**Notifications render from the type, not stored text.** `addCloudFavorite` in
`src/services/firestore.ts` writes `{ type: 'favorite', message: null, ... }`; the sentence
is built at render time from `NOTIF_VERBS` (today in
`src/components/notifications/NotificationBell.tsx`, moved to `src/lib/notifications.ts` by
RL-092). So changing the verb also changes every old notification, with no data migration.
`functions/src` (`index.ts`, `prompts.ts`) never mentions favourites or notifications.

**Data export is not touched.** `src/lib/dataExport.ts` (`DATA_EXPORT_VERSION = 1`) uses the
keys `favorites` and `bookmarks`; these are the file's contract and stay. No user-facing export
label contains the word (the Settings rows say "Download my data"; `ANONYMOUS_NOTE` says
"bookmarks"), so nothing there changes and the version is not bumped.

**The word "bookmark" stays.** Anonymous copy already says "bookmarks on this device"
(`AuthModal.tsx`, `ProfilePage.tsx` line ~373, `RecipeChatPage.tsx` line ~172), which matches
the bookmark icon from RL-122.

**Copy choices (agent-decidable, log them in `backlog/DECISIONS.md`):** the verb is "save",
the count noun is "save"/"saves" via `pluralize`, the list is "Saved". Australian spelling
elsewhere is unaffected.
