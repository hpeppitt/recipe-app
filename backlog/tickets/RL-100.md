## Context

Spec (`docs/design/organic/export/App Spec.dc.html`, "Original recipe (2a)" and "Branch
recipe (2a + 2b)"); markup in the `recipe` block of `App Prototype.dc.html` (`headerRoot`,
`headerBranch`, the title blocks and the `menu` sheet). An original shows "Title + emoji blob
(76px, organic radius), description". A branch shows a "230px hero (photo, or emoji on
accent-200) with floating 44px controls", the title, and a family label "Under the title, bold
accent-2-700 "Banana bread variation", so a branch name like "Chocolate chunk" always reads in
context." Photos are cut (decision 3), so the hero is always the emoji.

Today `src/pages/RecipeDetailPage.tsx` uses `TopBar` with the title, a heart (favourite) and a
`EllipsisVertical` dropdown menu (Share, Version tree, and for owners Edit and Delete, with a
pending-suggestions count badge). `RecipeContent` renders the emoji, title and description at
the top of the body. Every action keeps its current behaviour, including `handleBack`
(history first, then parent, then `/`; the design's "back goes up the family" is a question
for the author), the favourite sign-in prompt, Share's publish and clipboard fallbacks, and the
delete flows.

The family root is available from `useRecipeLineage(recipe).ancestors[0]` (root first). On a
branch the label is "<root emoji> <root title> variation". If the ancestors have not loaded,
show no label rather than a wrong one.

**Design token map:** `--color-bg` is `bg-surface`; `--color-surface` is
`bg-surface-secondary`; neutral-800 text is `text-text-secondary`. Light only: no `dark:`
classes. 44px targets.

Values to copy:

- **Original, header row**: padding `12px 12px 0` (the design's 50px top is the status bar),
  flex, gap 2px: back (flat `IconButton`, `ChevronLeft`), spacer, `Network` (label "Version
  tree", to `/recipe/:id/tree`), the favourite (heart, as today, filled `text-red-500` when
  on; label unchanged), `Ellipsis` (label "More options", with the pending badge as today).
  Hidden heart in local-only mode as today.
- **Original, title block**: padding `8px 22px 0`; flex, align start, gap 16px, margin-top
  4px; `h1` `font-heading` 34px, line-height 1.04, flex 1; a 76px `EmojiBlob` on
  `bg-accent-200`. Description: 15px `text-text-secondary`, margin-top 10px,
  `text-wrap: pretty`.
- **Branch, hero**: 230px tall, full width, `bg-accent-200`, the emoji in a 150px
  `EmojiBlob` tinted `bg-surface` with the emoji at 78px, `margin-top: 20px`, centred.
  Controls float at `top: 12px` (plus `env(safe-area-inset-top)`), `left` and `right` 14px,
  gap 8px: the same four buttons as `IconButton variant="floating"` (44px, `bg-surface`,
  `shadow-md`).
- **Branch, title block**: `h1` `font-heading` 32px, line-height 1.04, margin `14px 0 0`,
  padding `0 22px`; family label 16px, 700, `text-accent-2-700`, margin-top 6px. The
  description is not shown on a branch (the lineage strip, RL-101, replaces it).
- **More menu** as a `Sheet` (RL-089): rows `flex`, gap 14px, padding `12px 4px`, 16px text,
  each with a 40px `bg-surface-secondary` circle holding an 18px icon: for the owner "Edit
  recipe" (`Pencil`) and "Delete" (`text-accent-700`, `X` or trash icon); for others
  "Suggest a change" (`MessageCircle`, only when suggesting is possible today); then "See
  the family" (`Network`), "Copy share link" (`Link`, runs today's Share). The sheet has a
  visually hidden heading "Recipe options".
- `RecipeContent` gains a prop to omit its own emoji, title and description header on this
  page; the chat preview and the shared page keep it until their own tickets.

## Acceptance criteria

- [ ] `src/components/recipe/RecipeHeader.tsx` renders the original and branch variants above; `RecipeDetailPage` uses it instead of `TopBar` once the recipe has loaded. Loading, not-found and cloud-error states keep a simple back header.
- [ ] Branch detection is `recipe.parentId != null` (spec: "when parentId is set"); the family label uses the root from the lineage.
- [ ] The menu is a `Sheet` listing the actions above with today's handlers; the pending-suggestions badge and its accessible name are unchanged.
- [ ] Only one `h1` on the page (the recipe title).
- [ ] `RecipeHeader.test.tsx` covers both variants, the family label text and its absence before ancestors load; `RecipeDetailPage.test.tsx` tests that used the old menu or `TopBar` title are updated, none deleted.
- [ ] A `backlog/QA.md` entry: open an original and a 2-deep branch at 390x844 and 320px; floating buttons readable over the peach hero and clear of the iPhone notch; menu sheet as owner and non-owner; Share, Delete, Edit, tree from the sheet and the header; favourite signed out opens sign-in.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
