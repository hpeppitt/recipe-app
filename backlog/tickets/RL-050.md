## Context

What the rules cannot do, and what is left for detection on Spark with no Cloud Functions.
All of it is console work, so human only.

- **App Check on Firestore.** The client already initialises App Check with reCAPTCHA v3
  when `VITE_RECAPTCHA_SITE_KEY` is set (`services/firebase.ts`), and Firebase AI Logic
  enforces it. Firestore does not yet, so a script with the public config can call Firestore
  directly. Enforcing it stops that, but enforcement before the released client sends valid
  tokens would lock everyone out, hence the dependency on RL-022's release.
- **AI generation.** The rules cannot see generation. Firebase AI Logic has a per-user
  request limit in its console settings; the groomer could not confirm the exact name or
  default from the sandbox. RL-001 tracks the wider AI path decision; this ticket only sets
  the limit available today.
- **Detection.** No server code means no automatic alerting from the app. Signals that exist:
  `clientErrors` entries with context `rate-limited-*` (RL-048, RL-049), the Firestore usage
  tab and the AI Logic monitoring page in the Firebase console, and possibly a Cloud
  Monitoring alert on Firestore write counts if the free tier allows one on Spark
  (unverified).

## Acceptance criteria

- [ ] App Check metrics for Cloud Firestore show that nearly all recent requests carry valid tokens; then Firestore enforcement is turned on, and the live app is checked signed out, anonymous and verified.
- [ ] Debug tokens for local development are registered and `docs/operations.md` says how to add one.
- [ ] The Firebase AI Logic per-user request limit is found in the console, set (suggested: 10 requests per minute per user), and the setting name and value are recorded in `docs/operations.md`.
- [ ] Whether a Cloud Monitoring alert on Firestore writes per day can be created on Spark is checked. If yes, one is created that emails the author; if not, that is recorded.
- [ ] `docs/operations.md` gains a short "Abuse watch" section: what to look at weekly (clientErrors filtered by `rate-limited-`, Firestore usage, AI Logic usage) and what to do (disable the account in Firebase Auth, delete its content from the console).

## Out of scope

Cloud Functions, Blaze, an admin UI, automatic suspension.
