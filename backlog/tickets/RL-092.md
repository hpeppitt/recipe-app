## Context

The spec (`docs/design/organic/export/App Spec.dc.html`, "Activity (11b)") makes `/activity` a
tab that "replaces the NotificationBell dropdown". The author's pick, 11b, leads with a
"Needs you" section and rolls the rest up per family; those rollups are a new feature and are
NOT in this ticket (see Out of scope). This ticket ships the screen with the data that exists
today: the notifications from `useNotifications()` (`src/hooks/useNotifications.ts`), the same
list `src/components/notifications/NotificationBell.tsx` renders, laid out like the prototype's
`activity` block in `App Prototype.dc.html`. RL-097 adds the route and the tab badge.

Notification types today: `favorite`, `suggestion`, `suggestion_approved`,
`suggestion_rejected`, `suggestion_reply`, `follow` (`docs/capabilities.md`, Notifications).
There is no "branched your recipe" notification, so the design's branch rows cannot appear.
Verbs come from `NOTIF_VERBS` in `NotificationBell.tsx`; move that table to
`src/lib/notifications.ts` so both use one copy. Click behaviour is unchanged: mark read, then
go to `/recipe/<recipeId>` or `/profile/<fromUid>`.

**Design token map:** `--color-bg` is `bg-surface`; neutral-700 text is `text-text-tertiary`;
neutral-800 text is `text-text-secondary`; filled terracotta with cream is
`bg-primary-600 text-on-accent`. Light only: no `dark:` classes. 44px targets.

Values to copy:

- Header: padding `16px 20px 0`, flex baseline; "Activity" `font-heading` 30px, flex 1; when
  there are unread items a "Mark all read" button, 13px, 600, `text-accent-700`, 44px target.
- Section labels "Today" and "Earlier": 12px, 600, `text-text-tertiary`, margin `10px 0 4px`
  (Earlier `14px 0 4px`). Today is notifications created since local midnight.
- Row (button): full width, flex, gap 12px, padding `10px 0`, align start. Left: a 40px
  avatar (existing `Avatar`, generated look) with a 20px type badge at `right:-4px;
  bottom:-4px`, `rounded-full`, icon 10px in cream, ring `0 0 0 2px` of `bg-surface`. Badge
  colours: suggestion and suggestion_reply `bg-accent` with `MessageCircle`; approved
  `bg-accent-2-600` with `Check`; rejected `bg-neutral-700` with `X`; follow
  `bg-neutral-700` with `UserPlus`; favorite `bg-neutral-700` with `Heart`. Middle: 14px,
  line-height 1.4, "<b>who</b> verb <b>emoji title</b>", then a 12px `text-text-tertiary`
  line with the message excerpt (one line, truncated) and `timeAgo`. Right: a 9px unread dot
  `bg-accent`, `margin-top: 8px`, with screen-reader text "unread".
- Signed out, anonymous, or local-only: the 19a empty state from RL-090 with a `Bell` icon in
  the blob (`bg-accent-2-300`, `text-accent-2-900`), headline "Nothing to see yet", body
  "Sign in and this is where suggestions on your recipes, replies and new followers show
  up.", and (only when Firebase is configured and the user is not verified) a "Sign in" action
  that opens the existing `AuthModal`. In local-only mode, no action.
- Signed in with nothing: 14px `text-text-tertiary` "Nothing here yet." with padding 20px 0.
- Loading: three 19a skeleton rows. Error: the existing "Couldn't load notifications" copy in
  the `tone="error"` empty state.

## Acceptance criteria

- [ ] `src/pages/ActivityPage.tsx` exports `ActivityPage` rendering the states above from `useNotifications()`, newest first, split into Today and Earlier; an empty group renders no label.
- [ ] `NOTIF_VERBS` lives in `src/lib/notifications.ts` and `NotificationBell.tsx` imports it from there (the bell is removed later by RL-098; until then both work).
- [ ] A pure `groupByDay(items, now)` in `src/lib/notifications.ts` splits by local midnight, with tests in `src/lib/notifications.test.ts` (an item at 00:00 today is Today, at 23:59 yesterday is Earlier).
- [ ] Each row is a button with an accessible name that includes the who, verb, title and "unread" when unread; badge icons are `aria-hidden`.
- [ ] "Mark all read" calls the existing `markAllRead`; a rejection is caught and shows "Couldn't mark those as read. Try again." under the header (the bell currently swallows it, an unticketed observation).
- [ ] `ActivityPage.test.tsx` covers: grouping, verbs per type, unread dot and name, signed-out empty state, mark all read failure message.
- [ ] No route is added here (RL-097 does it).
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
