## Context

`components/chat/BranchComposer.tsx` (RL-112) shows `BRANCH_CHIPS` in fixed order; each tap
appends its lower-case label to the instruction. The family is available through
`useRecipeTree(rootId)` (device) or `getPublishedRecipeTree` (cloud) as the tree page loads it.
RL-177 has `orderChips` and `splitChips`. The spec shows the split when branching from a dedup
match; it is useful on every branch, so it applies whenever the parent has children (groomer
choice, log it). RL-131 already puts the author's `UserPill` on the Branching card.

### The design (the implementer has no other copy)

- When the parent has no children: one row of chips as today, in `orderChips` order.
- When it has children: two labelled groups, 12px semibold `neutral-700` labels, 8px gap:
  - "Nobody's tried these yet": chips on `bg-accent-2-100` with a `Sprout` icon in
    `accent-2-700`; tap appends as today.
  - "Already a branch, open it instead": chips on `bg-neutral-100` with an `ArrowUpRight`;
    tap opens `/recipe/<childId>` (accessible name "Open the <chip> branch").
- Under the chips, the free text box placeholder stays; its label reads "Or describe your
  change…" when the split shows.
- Arriving from a dedup match (RL-178/RL-179 pass `state: { fromDedup: true }`), the Branching
  card shows a 13px `accent-700` "Change" text button that goes Back to the chat.

## Acceptance criteria

- [x] Order and split as above, computed from the family's prompts once the family has loaded; while loading the chips show in the default order with no split (no flash of a different order: render the split only if it arrives within 500 ms, else keep the default until the next visit; log the choice).
- [x] The "tried" chip never appends text.
- [x] Tests: ordering from family prompts, split with a matching child, navigation on a tried chip, Change shown only from dedup.
- [x] `docs/capabilities.md` Variations row.
- [x] A `backlog/QA.md` entry: on a family with a "less sugar" branch, Branch from the original: Less sugar sits under "Already a branch" and opens it; the others append text.
- [x] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

## Notes

Family read lives in `hooks/useBranchFamily.ts` (500 ms wait, 40-doc cloud cap), passed to the composer as props so it stays router-free. Change calls `goBack`. Added `Sprout` and `ArrowUpRight` icons. The "Or describe your change…" line is a visible hint below the chips; the textarea keeps its heading label. Chips for tried children come from direct children only; ordering uses all family prompts.
