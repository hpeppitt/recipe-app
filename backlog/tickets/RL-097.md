## Context

The design brief (`docs/design/organic/BRIEF.md`) and every prototype screen use a five-slot
nav: Explore, Saved, Create (raised terracotta circle), Activity, You. Today
`src/components/layout/BottomNav.tsx` has three `NavLink`s (Library `/`, Profile `/profile`,
Settings `/settings`), and `AppShell` wraps `/`, `/profile` and `/settings`. Routes are a plain
`BrowserRouter` (`docs/architecture.md`, Routing; do not migrate to `createBrowserRouter`,
`docs/decisions.md`).

How each slot ships without the features the design assumes:

- **Explore** `/`: still `LibraryPage` until RL-098 replaces it. Icon `Compass`.
- **Saved** `/saved`: `SavedPage` from RL-091. Icon `Bookmark`.
- **Create**: navigates to `/create` (the existing chat page, full screen, no nav). The
  design's Create tab (6c sentence builder) is a new feature and not built. Icon `Plus`.
- **Activity** `/activity`: `ActivityPage` from RL-092. Badge: the unread count from
  `useNotifications()` (only when signed in with Firebase configured and the count is above
  0; "99+" above 99). Icon `Bell`.
- **You** `/profile`: the own profile (RL-095). Icon `UserRound`.

Settings moves out of the nav. It is reached from the gear on the You tab (RL-095) and has its
own back button (RL-093), so `/settings` moves outside `AppShell` like the other detail views.

**Design token map:** `--color-bg` is `bg-surface`; `--color-divider` is `border-border`;
neutral-700 text is `text-text-tertiary`. Light only: no `dark:` classes.

Values to copy (`showTabs` block in `App Prototype.dc.html`):

- Bar: fixed bottom, height 78px including `padding: 8px 14px 22px` (replace the 22px bottom
  with `max(8px, env(safe-area-inset-bottom))` plus 14px so it sits above the iOS home
  indicator), `bg-surface`, top rule `box-shadow: 0 -1px 0` of the divider, `z-40`, content
  centred to `max-w-lg`.
- Item: `flex: 1`, column, centred, gap 2px; label 11px, 600; colour `text-accent-700` when
  active, `text-text-tertiary` otherwise. Icon box 30px circle, icon 21px.
- Create: icon box 44px circle `bg-accent` with a cream icon (non-text contrast 3.03:1 meets
  the 3:1 rule; label stays under it in the normal label colour). It is a link, not a tab
  with an active state.
- Badge: positioned `top: -3px; right: -8px` on the icon box, min 18px tall and wide,
  `padding: 0 5px`, `rounded-full`, 10px 700 text, `bg-primary-600 text-on-accent` (AA,
  instead of the design's `bg-accent`), ring `0 0 0 2px` of `bg-surface`.
- `AppShell` main padding-bottom grows from `pb-16` to fit the 78px bar.

Active state: Explore is active on `/` only; Saved on `/saved`; Activity on `/activity`; You
on `/profile`. Use `NavLink` so `aria-current="page"` is set.

## Notes

- 2026-10-19: Implemented. `BottomNav` is five `NavLink`s; the Activity badge reads the real `useNotifications()`, which returns 0 signed out and local-only; the nav also requires a verified email (reviewer fix), since ActivityPage lists nothing without one. The badge is `aria-hidden` and the count lives in the link's `aria-label`.
- Bar: `pt-2 px-3.5`, content row 48px, bottom padding `max(8px, safe-area) + 14px`, so 78px with no safe area. The Create circle (44px plus label) is taller than the 48px row and overflows it, as in the prototype.
- `AppShell` main padding is `78px + max(8px, safe-area)` (bar plus 8px). `UpdatePrompt` (mounted in `App.tsx`, on every route) moved from `bottom-14` to the bar's height so it no longer covers the nav. The `bottom-24` toasts are only on `RecipeDetailPage`, which has no nav; `ConsentBanner` is in flow. Sheets and dialogs use `showModal` (top layer).
- `FAB.tsx` deleted; `LibraryPage` was its only importer.
- `BottomNav.test.tsx` mocks `services/firestore`, not the hook, so the signed-out and local-only cases exercise the hook's gating. Each negative assertion was mutation-checked: an always-on badge, removing the hook's gate, and dropping the `aria-label` each fail the relevant tests.
- jsdom cannot check layout: the 78px height, safe area, 320px fit and the Create circle overflow are for the QA walk.
