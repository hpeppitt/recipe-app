## Context

The roadmap lists "full-screen 14b avatar editor", but the spec's Overrides keep the avatar
editor as a sheet (route names unchanged). This ticket takes 14b's contents into the existing
sheet (`components/profile/AvatarEditor.tsx`, RL-094: Photo, Initials and Emoji modes, six
swatches, base64 upload rules unchanged) and leaves the full-screen route as a question for the
author. If the author wants full screen, regroom.

### The design (the implementer has no other copy)

- Top row: "Cancel" ghost (44px) at the left, primary "Save" (40px, padding 0 18px) at the right.
- Preview: 170px blob (`58% 42% 52% 48% / 46% 56% 44% 54%`) in the chosen colour with the emoji
  at 84px (or the initials, or the cropped photo).
- Swatches: six 36px circles, 10px gap, centred, the selected one ringed (2px `text` ring with a
  2px ground gap). Keep the RL-094 palette (token references, per RL-140).
- Emoji grid: five columns of 48px buttons: 🥐 🍞 🍳 🍜 🥟 🍋 🧄 🌶️ 🥑 🍅 🧀 🍰 🥕 🍄 🫖. The
  selected one on `bg-accent-100` with a 2px `accent` ring.
- Footer: two secondary buttons side by side, "Use a photo" (`Camera`, opens the existing upload
  and crop) and "Initials" (switches to initials on the chosen colour). The default avatar is
  initials; nobody is forced to upload.

## Acceptance criteria

- [x] The sheet matches the above; saving writes exactly what RL-094 writes today for each type.
- [x] Every control has an accessible name ("Colour <name>", the emoji's name or the emoji, "Use a photo", "Initials"); the grid is navigable by Tab.
- [x] Tests updated for the three types.
- [x] `docs/capabilities.md` Custom avatars row.
- [x] A `backlog/QA.md` entry: open the editor from the You tab and Settings, pick an emoji and colour, Save; upload a photo; switch to initials. 390px, light and dark.
- [x] `npm test`, `npm run lint`, `npm run build` pass.
