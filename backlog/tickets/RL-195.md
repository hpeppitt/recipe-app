## Acceptance criteria

- [ ] `Cook` type in `src/types/social.ts` matching RL-192's fields (with `createdAt: number` on the client).
- [ ] `madeByLine(total, again)` returns "Made 31 times · 27 would make again", "Made once · would make again" (1 and 1), "Made once" (1, 0), "Made 2 times" (again 0 drops the second part); `null` for 0.
- [ ] `recentCooks(cooks, max = 3)` returns distinct cooks by uid, newest first, for the avatar stack.
- [ ] `cookLogSummary(cooks)` returns "14 cooks · 9 recipes · 3 branches grew from notes" with singular forms ("1 cook", "1 recipe", "1 branch grew from a note"), dropping the last part at 0.
- [ ] `cookTag(cook)` returns `'branched'` when `branchId`, else `'again'` or `'tweak'` from the vote; `COOK_TAGS` maps them to label and icon name: Branched (`GitBranch`), Again (`Repeat`), Tweak (`Wrench`).
- [ ] `cookWhen(createdAt, now)` returns "Sunday" within the last 6 days, "Last week" for 7 to 13, else "12 Oct"; combined with the vote as "Sunday · would make again" / "needs a tweak".
- [ ] `noteToBranchPrompt(note)` trims, collapses whitespace and cuts at 200 characters on a word boundary; empty returns null.
- [ ] Tests for every function and boundary.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
