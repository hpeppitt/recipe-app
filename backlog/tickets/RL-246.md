## Context

`TreeView.tsx` (3a, RL-068) draws nodes with emoji, title and `"prompt" · author`; the subtitle
comes from `familySubtitle` (`lib/tree.ts`). The original keeps its place at the top: lineage,
not popularity, so nothing is reordered.

### The design (the implementer has no other copy)

- Each node: at the right, a 13px semibold count with `ChefHat` ("27"), `neutral-700`; zero
  shows nothing.
- The leader: a sage tag before the count, `bg-accent-2-200`, `text-accent-2-900`, 11px semibold,
  `Trophy` icon, "Most cooked".
- Subtitle: "7 versions · cooked 61 times · started by X in Month" (the cooked part only when
  above zero).
- The ancestry path stays terracotta; nothing else changes.

## Acceptance criteria

- [ ] Counts, trophy and subtitle as above; counts load after the tree and do not shift layout (reserve the count slot's width only when the hook has data; a late arrival may widen nodes, which is acceptable; log it).
- [ ] Accessible names include "cooked 27 times" and "most cooked".
- [ ] `familySubtitle` gains an optional cooked total, tested.
- [ ] Tests for the node and subtitle.
- [ ] `docs/capabilities.md` Version tree row.
- [ ] A `backlog/QA.md` entry: a family with a branch cooked 3 times and an original cooked once shows the trophy.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
