## Context

The collection page (RL-224) has a More menu. Only published recipes are visible to visitors
(RL-255 answer 3), so the owner is told when some are not.

## Acceptance criteria

- [ ] More menu row "Share as a cookbook" opens a sheet: Caprasimo 22px "Share as a cookbook", a description field (280 max, placeholder "What makes these worth cooking?"), 13px `neutral-700` "Anyone with the link can see it. Recipes only on your device stay hidden." and primary "Share"; afterwards the sheet shows the link with Copy and Web Share, and "Stop sharing".
- [ ] `addToCollection` also sets `lastAddedAt` when the collection is public.
- [ ] When some recipes are unpublished, a 13px line under the description says "2 recipes aren't published and won't show."
- [ ] Tests and `docs/capabilities.md` Collections row.
- [ ] A `backlog/QA.md` entry: share a collection, open the link signed out in another browser, stop sharing, reload the link.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
