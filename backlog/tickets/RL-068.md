## Context

RL-067 builds the version tree page shell; the Tree view body is still the old nested
`TreeNodeView` in `VersionTreePage.tsx`. This ticket replaces it with the Organic 3a design,
as its own component so the Timeline and Map tickets do not collide with it in the page file.

Input is the `TreeNode` from `buildTree` (`src/lib/tree.ts`; children are sorted by
`createdAt`) plus the current recipe id. `ancestorChain` (RL-067) gives the path. Nodes can
be local or cloud; cloud nodes may have an empty `prompt` (AUDIT FUN-11 fix note: fall back
to "Variation") and a null `createdBy.displayName` (show "Anonymous", as the recipe page
does for collaborators).

AUDIT UI-11: deep chains must scroll horizontally rather than crush the cards; the current
code does this with a `min-w-56` card and 12px per level. Keep that property.

`docs/decisions.md` "Teaching the tree" says the `TreeIntro` diagram reuses the tree's
borders so recognising it later is the point. After this ticket it no longer matches; the
redraw is design work (brief ticket 8). Record that consequence; do not edit `TreeIntro`.

Design 3a, to copy exactly:

- Root card on `bg-surface-secondary`, `rounded-card`. Other nodes are lighter cards
  (`bg-surface`, 1px `border-border`, `rounded-card`).
- Node content: emoji, title (one line, truncated), then `"<prompt>" · <author>` in
  `text-text-tertiary` 12px. Root shows `Original · <author>`.
- Connectors 3px wide with rounded elbows (radius about 16px) from the parent's rail into
  each child; a vertical rail continues past a child only while later siblings follow.
  Lines `neutral-400` (`#c0b6a5`).
- The ancestry path (root to current, inclusive) is terracotta: its rails, elbows and node
  borders use `primary-500` (accent). The current node has a 2px accent ring and a "Here"
  tag (Organic accent tag: 11px, `rounded-xl`, `bg-primary-50 text-primary-700`).

## Notes

Groomed 2026-10-18.

Implemented with plain CSS: per child row, a `rail-in` segment, a rounded `elbow` (border-b and border-l, radius 16px) and a `rail-out` segment that continues only while later siblings follow. Each carries `data-child`, `data-segment` and `data-path`. `rail-in` and `rail-out` are terracotta while the path continues through that child or a later sibling, so the rail stays one colour down to the path child; the elbow is terracotta only for the path child itself.

Contrast: lowest text pair is text-tertiary 12px on surface-secondary at 4.92:1 (5.53:1 on surface). "Here" tag primary-700 on primary-50 is 6.21:1. Focus outline primary-600 is 5.72:1 on surface and 5.09:1 on surface-secondary. Connectors are non-text: accent against neutral-400 is 1.80:1 by luminance, so the path is told apart mainly by hue; accent on surface is 3.03:1.

Cards are w-60 (240px) with min-w-56 (224px); title and the `prompt · author` line truncate. Node buttons are min-h-11. The scroll region has tabIndex 0 and a label. The current node's name gets an sr-only "current version".
