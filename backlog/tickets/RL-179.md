## Context

When the on-send dedup finds matches, `RecipeChatPage.tsx` (~400-490) shows an inline panel
with Open and "Branch from this" per match and "Create New Recipe Anyway" (`dismissSimilar`).
7b turns that into a bottom sheet (`components/ui/Sheet.tsx`). RL-162 (in the backlog) changes
what "Create New Recipe Anyway" saves (it records `relatedFamilyId`); keep calling the same
`dismissSimilar` so whichever lands second still works, and say in the PR which order happened.

### The design (the implementer has no other copy)

Sheet, padding 12px 22px 28px, gap 16px:
- Caprasimo 24px "Someone's already baked this", then 14px `neutral-800` "Branch theirs to make
  it your way, or write your own."
- Up to five match rows (as many as dedup returns), each a card on `bg-surface-secondary`, 24px
  radius, padding 12px 14px, gap 12px: 44px emoji circle on the ground, title 15px bold, the
  author `UserPill` and a 12px meta, and a tag at the right: "Same" (`tag` on `bg-accent-2-200`,
  `text-accent-2-900`) or "Similar" (`bg-neutral-100`). The row is a link to the recipe (Open).
- Footer: primary 52px block "Branch <top match title>" (`GitBranch`) opening
  `/recipe/<id>/vary` for the first Same match, or the first match when none is Same; then a
  ghost 44px "Mine's different, write a new one", which calls `dismissSimilar`.
- Dismissing the sheet by backdrop or Escape keeps the typed text and does not generate (same as
  doing nothing with today's panel).
