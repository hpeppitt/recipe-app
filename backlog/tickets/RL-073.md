## Context

The author decided the 3e "What changed" diff is an on-demand comparison, computed
client-side (`docs/design/organic/BRIEF.md`). The diff is `diffRecipes(parent, child)` from
RL-066. Both recipes load with `useRecipe` (`src/hooks/useRecipe.ts`), which falls back to
the cloud with a 6 second bound and reports `cloudError` and `retry`; the detail page's
"Could not load this recipe" / "Recipe not found" states are the pattern to follow
(`docs/capabilities.md`, Manual recipe editing row, describes them).

Routes are flat in `src/App.tsx`, each page lazy-loaded as its own chunk. This ticket adds
one route and no history handling, so it is `standard`.

How users reach this screen is an open question for the author (RL-074). This ticket ships
the screen reachable by URL only; nothing links to it yet, which is harmless.

Design 3e, to copy:

- Header: round back button, title "What changed" in `font-heading` 30px.
- Two pills under it: left the compared version (`<emoji> <title>`, neutral tag style
  `bg-neutral-100 text-neutral-800`), an arrow, right this version (accent tag style
  `bg-primary-50 text-primary-700`). Each pill links to its recipe.
- Prompt bubble: `<author> asked: "<prompt>"` on sage `bg-accent-2-100 text-accent-2-800`,
  `rounded-card` with one square-ish corner (bottom left 8px), padding 13px. Author
  fallback "Someone"; hidden when the prompt is empty.
- Toggle: `SegmentedControl` labelled "Comparison", options "Changes only" and "Side by
  side". Local state, default Changes only.
- Ingredients, Changes only: one row per non-unchanged entry. `~` changed rows on accent
  tint `bg-primary-50`, showing the old amount and unit struck through
  (`line-through text-text-tertiary`) then the new; `+` added rows on sage
  `bg-accent-2-100`; `-` removed rows on `bg-neutral-200` with the whole line struck
  through. The symbol is visible text and each row also has a screen-reader prefix
  ("Changed:", "Added:", "Removed:").
- Ingredients, Side by side: two columns, left the compared version's list, right this
  version's, rows aligned by match, unmatched cells empty, same tints.
- Method: each changed step shows inline highlights from the word spans: inserts
  `bg-accent-2-200` (no strike), deletes `line-through text-text-tertiary`; added and
  removed steps tinted as ingredients. Unchanged steps are hidden in Changes only and shown
  in Side by side.
- Time and servings deltas as a one-line summary when non-zero ("Total time 45 min, was 30
  min", "Serves 6, was 4"), using `formatTime` from `src/lib/utils.ts`.
- Sticky footer: secondary "Cook parent" to the compared version and primary "Cook this
  one" to this version. With `?vs=`, the left label is "Cook that one".

## Acceptance criteria

- [ ] `src/App.tsx` adds `<Route path="/recipe/:id/changes" element={<RecipeChangesPage />} />`, lazy-loaded like its neighbours.
- [ ] `src/pages/RecipeChangesPage.tsx` compares `:id` against `?vs=<id>` when present, otherwise against the recipe's `parentId`.
- [ ] A root recipe with no `?vs=` shows an `EmptyState` "This is the original" with description "There is nothing before it to compare with." and a secondary button "Back to recipe". `?vs=` equal to `:id` shows the same state.
- [ ] Loading shows skeletons; a `cloudError` on either recipe shows "Could not load this comparison" with Try again (calls both `retry`s); a missing recipe on either side shows "Recipe not found".
- [ ] An identical diff shows "No changes to the ingredients or method." instead of empty sections.
- [ ] Layout, copy, tints and the footer are as in Context. Side by side works at 320 px: two columns of at least 136 px, text wraps, no horizontal page scroll.
- [ ] `src/pages/RecipeChangesPage.test.tsx` covers: parent comparison; `?vs=` comparison and the "Cook that one" label; root recipe state; changed, added and removed rows with their screen-reader prefixes and struck-through old values; method insert and delete spans; the identical state; toggling Side by side shows unchanged steps.
- [ ] `docs/capabilities.md` gets a row "What changed (compare versions)" (shipped, local, `pages/RecipeChangesPage.tsx`, `lib/recipeDiff.ts`, `/recipe/:id/changes`, noting it is URL-only until RL-074) and the routes table gets `/recipe/:id/changes`. `docs/architecture.md` lists the page if it enumerates pages.
- [ ] A `backlog/QA.md` entry: open `/recipe/<a variation id>/changes` and `/recipe/<id>/changes?vs=<cousin id>`; check the rows read correctly against the two recipes, struck-through values, method highlights, the toggle, the root recipe state, and Side by side at 320 px; with VoiceOver, rows announce Changed/Added/Removed.
