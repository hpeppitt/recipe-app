## Context

The prototype (`docs/design/organic/export/App Prototype.dc.html`, `hasSugs` part of the
`recipe` block) puts suggestions in a section after the nutrition card: a heading with
"<n> open · <m> closed", open suggestions as raised cards, closed ones collapsed to one line
with a status tag. Status tags per the spec ("Suggestion thread (10a)"): "Open accent ·
Applied / Branched accent-2 · Declined neutral".

Today `RecipeDetailPage` renders suggestions above the recipe body: owners see all with
Approve and Reject; others see only their own (RL-018). Each row includes the inline
`SuggestionThread`. Statuses are `pending`, `approved`, `rejected` (`src/types/social.ts`).
Approve adds the suggester as collaborator and opens the variation composer seeded with the
message (RL-017); Reject asks first and notifies. "Applied", "Branched" and "Keep as branch"
do not exist (see Out of scope). Mapping: `pending` shows "Open", `approved` shows
"Approved", `rejected` shows "Declined". Owner action labels: "Decline" (was Reject, same
confirm, its title becomes "Decline this suggestion?") and "Approve" (unchanged behaviour).

The section moves below the recipe body. The comment in the page explains why it was moved
up ("the owner's action item"); keep the owner's attention with the pending count badge on
the More button (RL-100) and the Activity tab, and note the move in the PR.

**Design token map:** `--color-bg` is `bg-surface`; neutral-700 text is
`text-text-tertiary`; `tag-accent` is `bg-accent-100 text-accent-800`; `tag-accent-2` is
`bg-accent-2-100 text-accent-2-800`; `tag-neutral` is `bg-neutral-100 text-neutral-800`.
Light only. 44px targets.

Values to copy:

- Heading row: margin `26px 0 10px`, flex baseline; `h3` "Suggestions" (owner) or "Your
  suggestion" (others), flex 1; 13px `text-text-tertiary` "<n> open · <m> closed".
- Open card: padding 14px, `rounded-[28px] bg-surface shadow-md`, column, gap 10px. Top row
  13px: `UserPill` of the suggester (link to profile), `timeAgo` in `text-text-tertiary` flex
  1, `tag-accent` 600 "Open". The message 14px. Owner actions row, gap 8px, each `flex: 1`,
  height 44px, 14px: "Decline" secondary, "Replies" secondary with `MessageCircle`, "Approve"
  primary. Non-owner: one secondary 44px button "<n> replies · join the chat" (or "Reply")
  with `MessageCircle`.
- Closed rows: column gap 2px, margin-top 8px; each a button, flex, gap 10px, padding
  `10px 4px`, 14px: `UserPill`, the message on one line truncated, the status tag
  (`tag-accent-2` "Approved" or `tag-neutral` "Declined").
- "Replies", "join the chat" and a closed row open the thread. Until RL-106 lands they expand
  the existing inline `SuggestionThread` under the card; RL-106 points them at the thread
  screen.
