## Context

Prompts: `RECIPE_SYSTEM_PROMPT` and `getVariationSystemPrompt` (`lib/prompts.ts`), sent through
AI Logic (`services/gemini.ts`). The undeployed Cloud Function has its own prompt copy
(`functions/src/prompts.ts`); leave it, as RL-118 did, and say so. Generation path, hence tier
hard. Avoids must never reach analytics (`$ai_generation` sends no prompt text today; keep it so).

## Acceptance criteria

- [ ] `withAvoids(systemPrompt, avoids)` appends "The cook never eats: peanuts, pork. Leave these out entirely, including as optional garnishes, and do not mention them." only when avoids exist; tests for empty and several.
- [ ] `useRecipeChat` passes the current avoids when it opens a chat session (new recipe and variation); changing avoids mid-chat applies from the next session, not mid-conversation (comment why).
- [ ] Import (RL-185) is not affected: it reads a recipe as written.
- [ ] Analytics and telemetry carry no avoid text (test).
- [ ] `docs/architecture.md` AI path and `docs/capabilities.md` generation row.
- [ ] A `backlog/QA.md` entry: set Peanuts as an avoid, ask for a satay; the recipe leaves peanuts out (or says it cannot); branch a peanut recipe "make it quicker": peanuts are dropped.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
