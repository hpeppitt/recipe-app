## Context

Prompts: `RECIPE_SYSTEM_PROMPT` and `getVariationSystemPrompt` (`lib/prompts.ts`), sent through
AI Logic (`services/gemini.ts`). The undeployed Cloud Function has its own prompt copy
(`functions/src/prompts.ts`); leave it, as RL-118 did, and say so. Generation path, hence tier
hard. Avoids must never reach analytics (`$ai_generation` sends no prompt text today; keep it so).

## Acceptance criteria

- [x] `withAvoids(systemPrompt, avoids)` appends "The cook never eats: peanuts, pork. Leave these out entirely, including as optional garnishes, and do not mention them." only when avoids exist; tests for empty and several.
- [x] `useRecipeChat` passes the current avoids when it opens a chat session (new recipe and variation); changing avoids mid-chat applies from the next session, not mid-conversation (comment why).
- [x] Import (RL-185) is not affected: it reads a recipe as written.
- [x] Analytics and telemetry carry no avoid text (test).
- [x] `docs/architecture.md` AI path and `docs/capabilities.md` generation row.
- [x] A `backlog/QA.md` entry: set Peanuts as an avoid, ask for a satay; the recipe leaves peanuts out (or says it cannot); branch a peanut recipe "make it quicker": peanuts are dropped.
- [x] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Sending learned tastes. The function's prompts.

## Notes

- `withAvoids` in `src/lib/prompts.ts` re-normalises with `normaliseAvoids` and lowercases each term for the line. No avoids returns the prompt unchanged (tested byte for byte).
- `useRecipeChat` reads `getTasteProfile` once when the session opens, verified users only, no listener and no cooks. The read is bounded by its own 5 s `rejectAfter`; a failure or timeout is reported as `taste-avoids` and the session opens with no avoids.
- `createRecipeChat(avoids = [])` and `createVariationChat(parent, avoids = [])` take the avoids; `importRecipeFromUrl` is untouched and tested to keep `IMPORT_SYSTEM_PROMPT` as is.
- Tests cover that reportError, trackRecipeCreated and captureAiGeneration carry no avoid text.
- `functions/src/prompts.ts` left unchanged, as RL-118 did.
- Live check needs RL-249's rules deploy so avoids can be saved.
- Review fixes: the read starts on mount and is awaited at session open. A failed read (not permission-denied, not a missing doc) shows a status notice in the chat and the session is not kept, so the next send retries and opens a fresh session, losing that one turn of history. Terms are quoted in the line; `clean()` in `src/lib/taste.ts` now drops `\p{Cf}` characters.
