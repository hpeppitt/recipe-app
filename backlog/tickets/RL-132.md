## Context

`RecipeEditPage.tsx` (RL-110) edits servings, prep and cook through `FactPill` number inputs
(~436) and difficulty through a `SegmentedControl` (~451). 8a draws them as pills that are
pickers: neutral-100 fill, inset 1.5px neutral-400 ring, 13px text, 6px 12px padding, icon,
value, chevron-down. Total time is derived from prep plus cook and is never edited
(decisions.md "Edits apply in place"); keep the line saying so. The draft holds numbers as
strings and `validateDraft` / `draftToPatch` (`src/lib/recipeEdit.ts`) parse them; keep that.

Use native `<select>` elements styled as the pill (no new dependency, accessible by default).

## Acceptance criteria

- [x] Four pills in one wrapping row: Servings (user-round icon) "8 servings"; Prep (clock) "Prep 15 min"; Cook (clock) "Cook 55 min"; Difficulty (gauge) "Easy". Each is a `<select>` with `appearance-none`, the pill styling above, the icon before and a `ChevronDown` after, min height 44px, and an accessible name ("Servings", "Prep time", "Cook time", "Difficulty").
- [x] Options: servings 1 to 24; prep and cook 0, 5, 10 ... 60, then 75, 90, 105, 120, 150, 180, 210, 240 minutes, labelled with `formatTime`; difficulty Easy, Medium, Hard. A current value not on the list (37 minutes, 30 servings) is added as an extra option so it is never lost.
- [x] The selects write the same draft fields as today, so `isDraftDirty`, validation and save are unchanged; the error display for servings, prep and cook still reaches the field.
- [x] `FactPill` and the difficulty `SegmentedControl` are removed from this page if unused.
- [x] `RecipeEditPage.test.tsx`: changing each select updates the draft and saves the parsed value; an off-list value is preserved and selected; the tests for the old inputs are updated, not deleted, and the PR lists them.
- [x] A `backlog/QA.md` entry. `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Ingredient drag handles and the collapsed method (RL-133). `servingUnit` ("slices"): no field.

## Verification

Gates: tests, `ui-reviewer`. Human on iOS Safari and Android Chrome at 390px: each pill opens
the native picker, the chevron is visible, focus ring shows on keyboard focus. Dark theme ring
contrast.
