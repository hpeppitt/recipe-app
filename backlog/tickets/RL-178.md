## Context

Today dedup runs once, on the first send of a new-recipe chat (`searchSimilarRecipes` in
`src/hooks/useRecipeChat.ts`), and reads the newest 200 published recipes
(`searchPublishedRecipes` → `getAllPublishedRecipes`, 200 reads) each time. 7a moves the hint
earlier: after a short typing pause. Doing a 200-read query per pause is not acceptable, so the
cloud window is read once per chat and reused by both the pause card and the send check. This
touches the generation page's hook, hence tier hard; the generation call itself must not change.

### The design (the implementer has no other copy)

A sage card directly above the composer (not over the keyboard: in the flow above it), 24px
radius, `bg-accent-2-100`, padding 14px 16px, gap 10px:
- Line 1, 14px: "**Banana bread** is already growing here · 7 versions by 5 cooks" (the
  top match's title bold; version and cook counts from the family when known on the device or in
  the window, else just "is already growing here").
- Up to three rows: 40px emoji circle on the ground, title 14px bold, the author `UserPill`,
  and a 12px meta (total time · difficulty), with a 36px secondary pill "Branch" (`GitBranch`)
  at the right that opens `/recipe/<id>/vary`.
- A 44px close button ("Hide matches") dismisses it for this chat.

## Acceptance criteria

- [ ] On a new-recipe chat with no recipe yet, 700 ms after the last keystroke with at least 3 characters, the hook ranks local recipes and the cached cloud window with the existing scoring (threshold 0.5, 5 slots, 2 reserved for cloud) and the card shows the top three. It updates on later pauses and hides when the text no longer matches.
- [ ] The cloud window is read at most once per chat session (first pause or first send, whichever comes first) and reused; a failure degrades to local-only silently as today.
- [ ] Send is never blocked by the card; the existing on-send dedup still runs, using the cached window (no second read).
- [ ] Not shown on `/recipe/:id/vary`, after the first recipe, in local-only mode (the composer is disabled there), or for a photos-only message.
- [ ] Screen readers hear one polite announcement when the card first appears ("3 similar recipes already here").
- [ ] Tests: debounce timing with fake timers, single cloud read across pause and send, hide on mismatch, dismiss.
- [ ] `docs/capabilities.md` Duplicate detection row and `docs/data-model.md` read cost updated.
- [ ] A `backlog/QA.md` entry: on a phone, type "banana bread" slowly into a new chat; the card appears after the pause above the composer and keyboard, Branch opens the composer for that recipe, Send still generates. Check the network panel shows one recipes query.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
