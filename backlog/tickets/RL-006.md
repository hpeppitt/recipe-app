## Context

`npm run build` warns that the main chunk exceeds 500 kB after minification. Nothing is
code-split, so the whole app ships as one bundle, which works against the mobile-first
premise and against the PWA precache in RL-007.

## Acceptance criteria

- [ ] Pages are loaded with `React.lazy` behind a `Suspense` fallback that uses the shared `Spinner`, with the Library page kept eager so first paint is unchanged.
- [ ] The Firebase SDK is in its own chunk (manual chunk or natural split) so local-only mode does not download it eagerly if that is achievable without a client-visible behaviour change; if not, say so in Notes.
- [ ] The 500 kB warning is gone and the largest chunk size is recorded in the ticket Notes.
- [ ] Navigating between routes shows no flash of empty content longer than the spinner.

## Out of scope

Tree-shaking individual Firebase modules or changing imports in `services/`.

## Verification

`npm run build` output. Human QA: the standing walk, watching for a visible loading flash.
