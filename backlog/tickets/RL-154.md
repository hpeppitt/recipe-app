## Context

`ActivityPage.tsx` lists every notification under "Today" and "Earlier"
(`groupByDay` in `src/lib/notifications.ts`). 11a: a chip row under the title, "All" selected by
default (selected chip: `bg-text-primary` with `text-surface`; others neutral tag), 13px, padding
7px 14px, gap 8px, padding 14px 20px 4px; then day headers 12px semibold `neutral-700`
(`text-text-tertiary` today), margin 10px 0 4px. Depends on RL-153 so the Branches chip has
something to show.

Chip to types: Branches = `branch`, `suggestion_branched`; Suggestions = `suggestion`,
`suggestion_reply`, `suggestion_approved`, `suggestion_rejected`, `suggestion_applied`; Follows =
`follow`. `favorite` (saved your recipe) shows under All only. Unknown types show under All only.

## Acceptance criteria

- [ ] Pure `filterByChip(items, chip)` and `groupByDays(items, now)` in `src/lib/notifications.ts`, replacing `groupByDay` (update its callers and tests). `groupByDays` keeps input order within a group and returns `[{ label, items }]`: "Today", "Yesterday", the weekday name ("Monday") for 2 to 6 days ago, then "12 Oct" (with the year when not the current year), all by local midnight. Tests cover each label, midnight edges, year boundary and DST-safe day counting.
- [ ] The chip row uses the existing `Chip` primitive (or its classes) as a `radiogroup` with arrow-key movement, or as toggle buttons with `aria-pressed`; pick one and keep 44px hit targets. The selection is component state (resets on leave), not the URL.
- [ ] A chip with no matching rows shows "Nothing here yet." under the chips; "Mark all read" still marks everything, not only the filtered rows (say so in its `aria-label` only if the filter is not All: "Mark all read, all types").
- [ ] Tests: chip filtering per chip, header labels rendered, empty filtered state.
- [ ] `docs/capabilities.md` Notifications row mentions chips and day headers.
- [ ] A `backlog/QA.md` entry. `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Hiding types by preference (RL-155). The tab badge count. 11b grouping (not chosen).

## Verification

Gates: tests, `ui-reviewer`. Human with a week of seeded notifications on the emulator at 390
and 320px: the chips filter, headers read Today, Yesterday, a weekday and a date, VoiceOver
announces the selected chip.
