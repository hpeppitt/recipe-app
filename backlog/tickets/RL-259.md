## Context

Activity (`ActivityPage.tsx`, RL-092, RL-154 filters and day groups) lists notifications. This
adds computed rows: read the user's `cookbookFollows` (at most 30), then each followed
collection (one read each), and show a row when `lastAddedAt > lastSeenAt`. Opening the row
sets `lastSeenAt`. The unread badge counts these rows too.

## Acceptance criteria

- [ ] `useCookbookUpdates()` (verified only, once per Activity visit and once per session for the badge) returns rows `{ collectionId, name, ownerName, lastAddedAt }`.
- [ ] Row: the owner's avatar with a 20px `BookOpen` badge on `bg-accent-2-600`, "**<owner>** added to **<cookbook>**", sorted into the day groups by `lastAddedAt`, an unread dot; tapping opens `/c/<id>` and marks seen.
- [ ] The Follows filter chip (RL-154) includes these rows.
- [ ] Read cost in `docs/data-model.md` (1 + up to 30 reads per visit).
- [ ] Tests for the hook and the rows.
- [ ] A `backlog/QA.md` entry: follow a cookbook from account A, add a recipe to it from B, A's Activity shows the row and badge; opening clears it.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Push notifications.
