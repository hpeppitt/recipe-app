## Context

Spec: `docs/design/organic/export/App Spec.dc.html`, "Search (1a)": route `/search?q=`, "One
pill searches titles and ingredients across originals and branches. 'Write it' sends the
query to Chat as the prompt. Chips filter: All, Under 30 min, Easy, Branches." Empty result:
"Accent-100 card that turns the query into a new recipe. Never a dead end." Markup: the
`search` block in `App Prototype.dc.html`. The Pantry chip and sheet (1c) are not built and
are dropped (author, 2026-10-19).

**Scope of what is searched, stated on the screen.** There is no search index and this ticket
adds no Firestore query ([docs/decisions.md](../../docs/decisions.md), "Full-text search" is
rejected). The page searches:

- every recipe on this device, `useLocalLibrary()` (Dexie: own recipes synced from the cloud,
  saved copies, imports), originals and branches;
- the shared library pages loaded by its own `useCloudLibrary(isFirebaseConfigured)`
  (`src/hooks/useRecipeLibrary.ts`), which fetches the newest page (`FEED_PAGE_SIZE` 30, plus
  one look-ahead document: up to 31 reads per visit) and pages further with Load more.
  `getPublishedRecipesPage` returns branches as well as originals, so both are searchable.

Pass Dexie rows first to `searchLibrary` (RL-123) so a device copy wins over its cloud twin.

**Write it** reuses the existing hand-over: `navigate('/create', { state: { suggestion: text } })`
seeds the composer through `suggestionSeed` and `initialValue` in
`src/pages/RecipeChatPage.tsx` (already used by the suggestion-approval and dedup flows). It
fills the composer and does not send, so no generation starts without the user's tap. Who may
generate is decided by `/create` as today.

**Explore entry.** RL-098 gives Explore a Search button that toggles an inline pill filtering
the loaded feed. With 1a there is one search: the button becomes a link to `/search`, and the
inline pill, its state and its tests leave `ExplorePage`. Explore keeps its chips, tags and
Load more.

**Token map:** `--color-surface` is `bg-surface-secondary`; neutral-700 text is
`text-text-tertiary`; neutral-800 is `text-text-secondary`; `tag-accent-2` is
`bg-accent-2-100 text-accent-2-800`, 11px, padding `3px 10px`, `rounded-full`. Light only: no
`dark:` classes. 44px targets. Lucide icons at stroke 2.75 (RL-064).

- [x] A `backlog/QA.md` entry (below).
