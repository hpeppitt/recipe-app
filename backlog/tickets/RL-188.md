## Context

Written for RL-187's recommendations; regroom if the author chose otherwise. Auth tier: the
email-link completion order (decisions.md 2026-08-07) and the terms recording (RL-047) must be
kept for both paths. The Auth emulator supports the Google provider with fake accounts, so the
whole flow is testable before RL-191 enables it live. Until RL-191 is done, this must not be
released (the button would fail live): say so in QA.md.

### The design (the implementer has no other copy)

In the sheet's first step, above "Continue with email": a 52px secondary block button with the
Google "G" mark (an inline SVG in `components/ui/icons.tsx`, the official four colours are the
one allowed exception to token colours; comment it) and "Continue with Google". The Terms box
moves above both buttons on this step; both stay disabled until it is ticked, with the existing
hint.

## Acceptance criteria

- [ ] `signInWithGoogle()` in `services/firebase.ts`: popup first, redirect on `auth/popup-blocked` or when `navigator.standalone` is true; an anonymous current user is linked with `linkWithPopup`/`linkWithRedirect`; the redirect result is completed on load after `auth.authStateReady()`.
- [ ] Credential already in use: sign in with that credential (`GoogleAuthProvider.credentialFromError`) and run the same local carry-over as the email path; the RL-109 "already has an account" outcome copy is reused.
- [ ] The Terms entry is stored before the popup opens and recorded through `checkTerms` exactly as for email; Decline still signs out.
- [ ] Popup closed by the user: nothing happens, no error shown. Other errors: "Couldn't sign in with Google. Try again or use your email."
- [ ] `AuthContext` tests (emulator-style mocks) for: new user, anonymous link, existing account, popup closed, redirect completion.
- [ ] `docs/capabilities.md` Passwordless email sign-in row becomes "Sign-in" covering both; `docs/architecture.md` auth section.
- [ ] A `backlog/QA.md` entry: blocked on RL-191 for live. On the emulator: sign in with Google from the Save sheet as a guest with a bookmark; the bookmark survives; sign out, sign in again with Google; then with an email that already has an account.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.
