## Notes

Cooks outlive deleted recipes: resolve each ranked recipeId/rootId against recipe docs (Dexie, then the published read), drop and backfill missing ones, and never navigate to familyLeader's result without that check.

useFamilyCooks counts can include deleted versions: look counts up by existing node id only, and check leaderId against the loaded tree before offering to open it.

Implementation: `useFamilyLeaders` (useCookSections.ts, reuses `resolve`, now exported) maps each shown original to its resolved same-family leader, capped at 8 leaders per call; Explore calls it once for tiles and rows, Search once for results. Known limit: the cap is per call, so a list that grows (Load more) can look up more than 8 in total (reads are cached per session).
