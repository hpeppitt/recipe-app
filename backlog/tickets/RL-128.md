## Context

A branch today shows the 17a sage strip (`src/components/recipe/LineageStrip.tsx`, RL-101): a
collapsible breadcrumb (`collapseLineage` in `src/lib/tree.ts`), the prompt as a sentence, and
"See what changed" against the parent only. RL-101 left the 17b pill out of scope; the author
made 17b v1 on 2026-10-20. `RecipeChangesPage` already accepts any `?vs=<id>`
(`src/pages/RecipeChangesPage.tsx` ~243), so only the entry points are missing.

`ancestors` comes from `useRecipeLineage` (root first, parent last, empty while loading).
Links inside the recipe must keep passing the list origin (`carriedListOrigin`,
`src/lib/paneMode.ts`; decisions.md "Wide-screen two-pane mode", 2026-10-20 paragraph).

### The design (the implementer has no other copy)

**Pill**, one line, on `bg-surface-secondary` (the spec's "surface"), height 46px, fully round,
padding 0 6px, gap 10px, `mx-[22px] mt-[14px]` like the strip it replaces:
- Generation dots: 8px circles, 3px apart, 8px left padding. One dot per generation from the
  root to this recipe: ancestors `neutral-500`, the current one `accent`. Cap at 6 dots (the
  first 5 then the current); the cap is a groomer choice, log it.
- Text 13px, flex 1, one line with ellipsis: **"Generation N"** (bold) then " · from <parent title>".
  N is `ancestors.length + 1` once the lineage has loaded (do not use the stored `depth`, which
  a later reparent can leave stale); while loading show `Generation {depth + 1}` with no
  "from" part, so a wrong parent never shows and swaps.
- **Path** button: 34px tall pill, `bg-surface` (the ground), padding 0 12px, 13px semibold,
  "Path" plus a chevron (down when closed, up when open). Give it a 44px hit area the way
  `HIT_PILL` does today. `aria-expanded`, `aria-controls` the panel.

**Path panel** (a disclosure in flow under the pill, not a floating popover, so there is no
focus trap to build): `mx-4 mt-2.5`, padding 14px 16px, radius 30px, `bg-surface`, `shadow-lg`.
One row per recipe from root to current, each row `flex gap-3`:
- left rail 20px wide: a 16px dot, then a 3px vertical line (min 18px) down to the next row.
  Root dot: ground fill with a 3px inset ring in `text-primary`. Ancestor dot: ground fill with
  a 3px inset `accent` ring. Current dot: filled `accent`. Lines `accent`; none under the last row.
- body, padding-bottom 14px: title 15px bold (the root prefixed with its emoji), and a 12px
  `neutral-700` sub-line: root "Original · <author>"; others `"<prompt>" · <author>`; the current
  row adds " · you are here". Author is `createdBy.displayName` or "Someone"; a missing prompt
  drops the quoted part.
- right: "Compare", 13px semibold `accent-700`, a link to `/recipe/<current id>/changes?vs=<row id>`.
  No Compare on the current row.
- Tapping a row's title navigates to that recipe (carry the list origin) and closes the panel.

**Under the pill** keep the existing sage sentence card (accent-2-100, "<Author> asked for
*"prompt"* on <parent author>'s **<parent title>**." and the "See what changed" pill to the
parent diff). Drop the breadcrumb `<nav>` and `collapseLineage` use from this component.

Escape closes the panel and returns focus to Path. The panel closes when the recipe id changes.

## Acceptance criteria

- [x] On a branch the 17a breadcrumb is gone and the pill, panel and sentence render as above; an original (no parent) shows none of it, as today.
- [x] "Generation N" equals the number of recipes from the root to this one once loaded (a depth-2 branch says "Generation 3 · from <parent title>"), and shows no "from" part while `ancestors` is empty.
- [x] Dots: one per generation up to 6, the last in accent; a 9-generation chain shows 6.
- [x] Path toggles the panel; rows list root to current in order with the sub-lines above; Compare on every row except the current one links to `/recipe/<this id>/changes?vs=<that id>`; tapping a title opens that recipe with the list origin carried.
