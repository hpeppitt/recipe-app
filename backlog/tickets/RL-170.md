## Context

The 1b Explore design ends its editorial sections with a Pantry entry card. RL-169 built the
sheet on `/search` and accepts `?sheet=pantry` to open it on load.

### The design (the implementer has no other copy)

A full-width button card, padding 18px, 30px radius, `bg-accent-2-200`, `text-accent-2-900`,
gap 14px, placed after the Most branched section (RL-167) or, if that is hidden, after the tile
row, with 18px 20px 0 outer padding: a 48px circle on the ground (`bg-surface`) holding a
`Refrigerator` icon in `accent-2-700`, then Caprasimo 18px "What have you got?" over 13px "Find
or write a recipe from your fridge.", and a `ChevronRight` at the right.

## Acceptance criteria

- [x] The card links to `/search?sheet=pantry`, which opens the sheet with focus inside it; closing it leaves the user on Search.
- [x] Shown in local-only mode (Search works on the device; RL-169 hides only the write action). Hidden under a tag or the Following chip, like the other editorial sections.
- [x] Tests: renders, links with the param, hidden under a tag chip.
- [x] `docs/capabilities.md` Explore row mentions the card.
- [x] A `backlog/QA.md` entry: tap the card on Explore, the sheet opens over Search; at 1280px it opens in the list pane.
- [x] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

A stored pantry (Phase 2).

## Verification

Component test. Human: the QA.md check.
