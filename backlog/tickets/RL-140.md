## Context

Two places hold hex copies of tokens from `src/index.css`:

- `AvatarEditor.tsx` ~16-23 `SWATCHES`: Peach `#ffe1d0` (accent-200), Apricot `#ffc6a5`
  (accent-300), Sage `#e1eecc` (accent-2-200), Moss `#ccdbb2` (accent-2-300), Sand `#dcd3c4`
  (neutral-300), Tangerine `#f6a06b` (accent-400). The chosen value is stored as
  `photoBgColor` on the public profile and rendered inline by `Avatar.tsx` (~51
  `backgroundColor: photoBgColor || uidToColor(uid)`). There is no rule on `photoBgColor`.
- `useTheme.ts` ~12 sets the `theme-color` meta to `#1e1915` / `#f5ead8`.

Storing `var(--color-accent-200)` instead of the hex makes the avatar follow the theme (dark
mode reverses the ramps) and removes the copy. Avatars saved with a hex keep rendering it.

## Acceptance criteria

- [ ] `SWATCHES` hold `var(--color-accent-200)`, `var(--color-accent-300)`, `var(--color-accent-2-200)`, `var(--color-accent-2-300)`, `var(--color-neutral-300)`, `var(--color-accent-400)` with the same names; saving stores that string.
- [ ] A stored legacy hex equal to one of the six old values shows that swatch as pressed (a small legacy map in the component, commented); any other stored value presses none, as today.
- [ ] `useTheme.applyTheme` reads `getComputedStyle(document.documentElement).getPropertyValue('--color-surface').trim()` after toggling the class and writes it to the meta, falling back to leaving the meta untouched when empty (jsdom). `index.html`'s pre-paint script keeps its literal values (it runs before the stylesheet; add a comment there naming the tokens they mirror).
- [ ] `grep -rnE "#[0-9a-fA-F]{6}\b" src --include='*.ts' --include='*.tsx'` outside tests finds only `imageDownscale.ts`'s canvas `#ffffff` (a JPEG flattening colour, not a style; leave it and say so in the PR).
- [ ] Tests: saving a swatch stores the `var(...)` string; a legacy `#ffe1d0` shows Peach pressed.
- [ ] `docs/capabilities.md` Custom avatars row notes the swatch storage change.
- [ ] A `backlog/QA.md` entry. `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

Migrating stored hex values on existing profiles (production data). The avatar editor layout
(stays a sheet, SPEC Overrides). `uidToColor`.

## Verification

Gates: tests, `ui-reviewer`. Human: pick each swatch, save, check the avatar in light and dark;
an avatar saved before this change still shows its colour; the browser chrome colour follows
Light and Dark on Android Chrome.
