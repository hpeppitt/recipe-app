## Context

The author picked 8a, "Edit in place": "Editing changes this version only. Branches below it
keep their own copy, so the save bar says so." Spec (`docs/design/organic/export/App
Spec.dc.html`, "Edit (8a)"): "Title with dashed accent-400 underline; amount (76px) and name
pills on neutral-100; drag handle; remove; dashed "Add ingredient". Footer States how many
branches keep their own copy. Method editing uses the same row pattern." Markup: 8a in
`Collaboration and Account.dc.html` and the `edit` block of `App Prototype.dc.html`.

Today `src/pages/RecipeEditPage.tsx` (route `/recipe/:id/edit`, owner only) has a `TopBar`,
Emoji and Title inputs, a description textarea, Servings, Prep and Cook inputs, a Difficulty
control, ingredient rows (name, amount, unit, notes, remove), steps (textarea, remove, Add
step), notes, tags, and Cancel and Save at the bottom. Validation (RL-036: negative amounts,
title and list caps), cloud-first save (RL-083), the missing-cloud-copy state, the unsaved
guard (`useUnsavedGuard`) and its discard dialog all stay. There is no reorder today, so the
design's drag handle is not drawn (reordering is a new feature). Direct children for the
footer note come from `useRecipeLineage(recipe).children`.

An unticketed observation also applies and is in scope because it is layout: the footer is
not sticky today.

**Design token map:** `--color-bg` is `bg-surface`; neutral-700 text is `text-text-tertiary`;
neutral-800 is `text-text-secondary`; `--color-divider` is `border-border`. Light only. 44px
targets (the design's 42px pills become 44px).

Values to copy:

- Header: padding `12px 12px 0`, flex, gap 6px: a ghost "Cancel" button (15px, padding
  `0 10px`, `text-text-primary`) that runs today's back-with-guard; "Editing" centred, flex 1,
  14px 700 `text-text-tertiary`; a 76px spacer.
- Body: padding `10px 22px 20px`, column, gap 14px.
- Title row, flex, align start, gap 14px: the title input in `font-heading` 30px,
  line-height 1.08, no box, `border-bottom: 2px dashed` accent-400 (`border-accent-400`),
  padding-bottom 6px, flex 1, `aria-label="Title"`; a 72px `EmojiBlob` on `bg-accent-200`
  with a 28px `rounded-full bg-text-primary` badge at `right:-4px; bottom:-4px` holding a
  cream 13px `Pencil`; the blob is a button that focuses a small emoji input (the existing
  Emoji field, now visually under the title row, 44px pill).
- Description: the existing textarea in `bg-neutral-100 rounded-[22px]`, 15px.
- Facts row: flex wrap, gap 6px. Servings, Prep (min), Cook (min) and Difficulty as pill
  fields: `bg-neutral-100`, inset ring `0 0 0 1.5px` neutral-400, `rounded-full`, 13px,
  padding `6px 12px`, gap 5px, an icon (`UserRound` for servings, `Clock` for the
  times, `Gauge` for difficulty; all from RL-088), a visible short label and the input or select inside.
  Errors stay attached to each field.
- Ingredients: `h3` "Ingredients" (`font-heading` 20px), margin `6px 0 0`. Rows, gap 8px,
  each flex, align centre, gap 8px: amount pill 76px wide, unit pill 64px wide, name pill
  flex 1 (each `h-11 rounded-full bg-neutral-100`, padding `0 12px`, 14px, amount 700, focus
  ring accent), a 44px remove button with a 32px visual `X` in `text-text-tertiary`. The
  notes field sits under the row as a full-width 44px `bg-neutral-100` pill, placeholder
  "Notes (optional)". "Add ingredient": a tag-style button, `border: 1.5px dashed`
  neutral-500, `text-neutral-800`, 14px, padding `7px 14px`, gap 6px, `Plus`.
- Method: the same row pattern for steps (number disc 30px `bg-surface-secondary`
  `font-heading` 14px, the step textarea in `bg-neutral-100 rounded-[22px]`, remove), and
  "Add step" as the dashed button. Notes and Tags keep their fields in the same pill style.
- Footer: sticky to the bottom of the viewport, padding `12px 20px 28px` (plus safe area),
  `bg-surface`, top rule of the divider, column, gap 8px. When the recipe has direct
  children: 12px `text-text-tertiary`, gap 6px, `GitBranch` icon, "1 branch below this keeps
  its own copy." or "<n> branches below this keep their own copy." Then a primary 52px full
  width "Save changes" (was "Save"), showing the existing saving label while saving. The
  bottom Cancel button is removed (Cancel is in the header).
