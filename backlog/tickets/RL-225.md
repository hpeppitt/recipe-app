## Context

Two-pane mode (RL-116, `lib/paneMode.ts`, `ListOrigin = '/' | '/saved'`, decisions.md
"Wide-screen two-pane mode") keeps a 420px list pane and shows the recipe beside it when a row
is opened from a list origin. This extends the origins to `/kitchen`, `/kitchen/list`,
`/kitchen/pantry` and `/kitchen/log`. The rail already shows Kitchen (RL-215). Routing state,
hence tier hard; the RL-116 resize guarantees (state survives crossing 1024px) must hold.

## Acceptance criteria

- [ ] `ListOrigin` gains the four Kitchen paths; opening a recipe from a shopping list source chip, a cook log card, a Kitchen Saved tile or a collection tile at 1024px or wider shows it beside the pane.
- [ ] The pane shows the page's mobile layout at 420px; footers stay inside the pane.
- [ ] Resize across 1024px keeps ticks, the shop mode flag and scroll as RL-116 does for Explore.
- [ ] `paneMode` tests extended; page tests for the origin state.
- [ ] `docs/capabilities.md` two-pane paragraph and `docs/decisions.md` RL-116 entry gain a dated line.
- [ ] A `backlog/QA.md` entry: at 1280px open each Kitchen page and a recipe from it; resize to 390px and back.
- [ ] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

A plan pane.
