## Context

Two-pane mode (RL-116, `lib/paneMode.ts`, `ListOrigin = '/' | '/saved'`, decisions.md
"Wide-screen two-pane mode") keeps a 420px list pane and shows the recipe beside it when a row
is opened from a list origin. This extends the origins to `/kitchen`, `/kitchen/list`,
`/kitchen/pantry` and `/kitchen/log`. The rail already shows Kitchen (RL-215). Routing state,
hence tier hard; the RL-116 resize guarantees (state survives crossing 1024px) must hold.

## Acceptance criteria

- [x] `ListOrigin` gains the four Kitchen paths; opening a recipe from a shopping list source chip, a cook log card, a Kitchen Saved tile or a collection tile at 1024px or wider shows it beside the pane.
- [x] The pane shows the page's mobile layout at 420px; footers stay inside the pane.
- [x] Resize across 1024px keeps ticks, the shop mode flag and scroll as RL-116 does for Explore.
- [x] `paneMode` tests extended; page tests for the origin state.
- [x] `docs/capabilities.md` two-pane paragraph and `docs/decisions.md` RL-116 entry gain a dated line.
- [x] A `backlog/QA.md` entry: at 1280px open each Kitchen page and a recipe from it; resize to 390px and back.
- [x] `npm test`, `npm run lint`, `npm run build` pass.

## Out of scope

A plan pane.

## Verification

Tests. Human: the QA.md walk.

## Notes

- The four Kitchen sub-pages moved under a second layout route, `<AppShell bare />`, instead of a routing restructure. Below lg a bare page shows no nav, banner or nav padding, so phones see no change; from lg it gets the rail. The nav wrapper is always rendered, so it never remounts.
- `ListOrigin` also accepts `/kitchen/c/<id>` (collection tiles, named in the first criterion). Pantry is an origin but has no recipe links.
- Shopping list source chip titles became links (the criterion needs a chip that opens a recipe); this shows at every width.
- With a recipe beside them the Kitchen pages demote their h1 to h2 (and section or aisle h2s to h3) and mark the open row `aria-current`, as Explore and Saved do (`RecipeTileGrid` gained `currentId`).
- Review fixes: the consent banner shows on bare pages from lg; `UpdatePrompt` treats the Kitchen pages as shell routes; the beside column drops its `pt-3` on bare pages only (Explore and Saved keep it).
- The shopping list toast centres on its column from lg.
