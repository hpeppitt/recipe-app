## Context

The author picked 19a ("Soft: blobs and Caprasimo headlines") for dialogs, empty, error and
loading states. Markup: `docs/design/organic/export/Recipe Parts and System.dc.html`, section
19a; spec summary in `App Spec.dc.html` ("Saved · empty state (19a)"). RL-063 already gave
these primitives Organic colours and pill buttons; this ticket changes their layout.

**Design token map:** `--color-bg` is `bg-surface`; `--color-surface` is
`bg-surface-secondary`; neutral-800 text is `text-text-secondary`; ramps keep their names;
a filled terracotta control with cream text is `bg-primary-600 text-on-accent`. Light only:
no `dark:` classes. Keep 44px targets.

Values to copy:

- **Dialog** (`ConfirmDialog`): centred, backdrop `neutral-900` at 40%, panel `bg-surface`,
  `rounded-card` (32px), padding 22px, `shadow-lg`, gap 10px. Title `font-heading` 22px.
  Message 14px `text-text-secondary`. Actions row with `margin-top: 8px`, gap 8px, both
  buttons `flex: 1`, height 48px: cancel is secondary, confirm is primary. A destructive
  confirm is the primary button with `background: accent-700` (`bg-accent-700`, cream text
  5.72:1), not the red `danger` fill. Example copy from the design: "Delete this version?" /
  "Keep it" / "Delete".
- **Empty state, full page**: content bottom-aligned and left-aligned so the action is in
  thumb reach, padding `0 24px 28px`, gap 10px. An off-canvas circle 240px
  `bg-accent-2-200` at `top: -60px; right: -70px` (decorative, `aria-hidden`, clipped by the
  container). An 84px `EmojiBlob` (RL-088) tinted `bg-accent-2-300` holding a 36px icon in
  `text-accent-2-900`. Headline `font-heading` 26px, line-height 1.1. Body 14px
  `text-text-secondary`. One action, `align-self: flex-start`, height 46px, padding 0 20px,
  `margin-top: 6px`, primary. Example: "Nothing saved yet" / "Tap the bookmark on any recipe
  and it'll wait for you here." / "Explore recipes".
- **Error state**: same layout, circle `bg-accent-200` at `top: -60px; left: -70px`, blob
  `bg-accent-300` with the `CloudOff` icon in `text-accent-900`, action is a secondary
  button with the `RotateCw` icon and "Try again". Example: "Couldn't load the family" /
  "You're offline. Recipes on this device still open."
- **Skeleton**: pulses between `neutral-200` and `neutral-300` (not opacity on
  `surface-secondary`). The list skeleton from 19a: a 30px tall bar at 60% width, a 52px
  pill, then rows of a 30px-radius `surface-secondary` card with a 56px circle and two bars
  (14px at 55/70/45% width, 10px at 90%).

`EmptyState` today takes an emoji `icon`, a `compact` variant (renders a `<p>`, keep that),
and an `action` node. Callers: `ErrorBoundary`, `ProfilePage`, `VersionTreePage`,
`LibraryPage`, `RecipeChangesPage`, `LegalPage`. `LibraryPage` is replaced by RL-098; leave
it working but do not polish it.
