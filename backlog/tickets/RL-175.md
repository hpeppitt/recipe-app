## Context

Routes keep their current names (spec Overrides), so the view lives at `/profile/forest` (own)
and `/profile/:uid/forest`, outside `AppShell` with its own back button like `/settings`.
Families: the roots of every recipe the person published (own profile: their Dexie own rows,
which mirror the cloud per decision 1b; another cook: `useUserRecipes`). Each family's members
come from `getPublishedRecipeTree(rootId)` (one query per family). RL-174 has the layout.

### The design (the implementer has no other copy)

- Header (50px top padding on mobile, 12px sides, gap 8px): 44px back button (`ChevronLeft`,
  name "Back"), the person's 36px avatar, name bold, and on another cook's profile a 38px
  Follow / Following button reusing `useFollow`.
- Headline (16px 22px 0): Caprasimo 28px, line-height 1.12: "Planted **12** recipes.
  **31** branches have grown from them." with the first number in `accent` and the second in
  `accent-2-600` (body-size accent text rule: at 28px it is large text, fine).
- Legend (16px 22px 0, 12px `neutral-700`, gap 14px): a 12px `accent` dot "<Name>'s" (own:
  "Yours") and a 12px `neutral-400` dot "Other cooks'".
- Grid (14px 18px 0): two columns `minmax(0,1fr)`, gap 10px. Each tile a button, padding 14px,
  28px radius, background `accent-100` when planted, else `bg-surface-secondary`, gap 8px: the
  SVG (width 100%, height 74, viewBox 0 0 140 74; path stroke `neutral-400` 3px round; dots
  `accent` when mine else `neutral-400`), "<emoji> <title>" 14px bold, and 11px `neutral-700`
  meta "Planted · N branches" or "Grew N on <owner>'s".
- Tap a tile: `/recipe/<target>/tree`.
- At most 12 families (newest root first); the rest are summarised as "and N more" under the grid
  (comment the shortcut). Loading: two skeleton tiles. A family whose tree read fails is drawn
  from the person's own versions only. Whole failure: the 19a error with Try again.
- Profile header: a 44px icon button with `Trees` (name "Forest view") beside the Settings cog
  on the own profile and at the right of the back row on another cook's profile.
