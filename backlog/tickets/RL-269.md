## Context

On "Check the import" (RL-252, `components/recipe/ImportReview.tsx`) the primary button is
"Save and branch", which saves a new original and then opens the branch composer
(`/recipe/<id>/vary`). The author found that wrong for Snap a page and for imports
generally: importing should save the recipe as a new original, and branching should only be
offered when the library already has the same dish. That offer already exists: when
`findFamily` in `hooks/useImportRecipe.ts` finds a `same` match (`matchKind`, `lib/search.ts`)
the review shows the RL-186 family notice and a ghost "Add to <Title> family" button, which
saves the import as a branch of that family's original (decision "Import reads through AI
Logic and is credited", RL-184, in `docs/decisions.md`).

### The design (the implementer has no other copy)

- Footer row, unchanged layout: secondary "Edit first" (left, unchanged behaviour: saves,
  opens `/recipe/<id>/edit`) and primary "Save recipe" (right) in place of "Save and branch".
- Save recipe saves a new original through the same `save(false, edits, 'recipe')` call and
  opens `/recipe/<id>` with the saved toast, as the family save already does.
- With a family match, the notice and the ghost "Add to <Title> family" button stay exactly as
  they are, below the row.
- The "Saving..." spinner, focus return on a failed save and the unclear-amounts confirm apply to
  Save recipe as they did to Save and branch.

## Acceptance criteria

- [x] No button on the review reads "Save and branch", and nothing on the review navigates to `/recipe/<id>/vary`.
- [x] Save recipe saves a new original (no `parentId`, `rootId` its own id, depth 0) and opens `/recipe/<id>` with the saved toast.
- [x] Without a family match the review offers exactly two actions, Edit first and Save recipe; with one it also offers Add to <Title> family, unchanged.
- [x] `ImportDest` no longer has `'vary'` if nothing else uses it.
- [x] `ImportPage.test.tsx`: the existing Save and branch tests become Save recipe tests (new original, opens the recipe page); the family path and Edit first tests still pass.
- [x] `docs/capabilities.md` Import row describes Save recipe instead of Save and branch.
- [x] A `backlog/QA.md` entry: "Snap a page and Paste a link: Save recipe opens the new recipe; import a dish you already have and check Add to <family> is offered."
- [x] `npm test`, `npm run lint`, `npm run build` pass.
