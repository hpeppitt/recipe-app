## Context

Spec: `docs/design/organic/export/App Spec.dc.html`, "Create tab (6c)": "Each underlined word
cycles through three options. Write it builds the same prompt text the chat would and hands
over to Chat. 'My own way' goes to Search, whose Write it also feeds Chat." Final markup: the
`create` block in `App Prototype.dc.html`, with its options in `const OPTS` and its prompt in
the `cr.write` handler. The earlier option canvas, `Social Auth and Generate.dc.html` #6c
("Make me a weeknight dinner with chicken and lemon...", plus Avoid, Cuisine and Equipment
chips), is superseded by the prototype and is not built.

**What this replaces in RL-097.** RL-097's Create slot is a plain link to `/create` (the chat,
full screen, no nav) with no active state, because 6c was not built. This ticket adds the 6c
screen at a new route, `/new`, inside `AppShell` (the prototype shows the tab bar with Create
active), and points the Create slot there as a `NavLink`. `/create` itself is unchanged and is
still where Write it, Search (RL-124), the dedup flow and suggestion approval land.

**Hand-over.** Write it calls `navigate('/create', { state: { suggestion: prompt } })`, the
existing seed read as `suggestionSeed` in `src/pages/RecipeChatPage.tsx`. It fills the composer
and does not send, the same choice as RL-124, so a tap on a word never spends a generation.
Whether the user can generate is decided by `/create` as today (sign-up gate, local-only
"unavailable").

**Copy, exactly as the prototype:**

- Hint: "Tap the underlined words"
- Sentence: "I want something [a] with [b] for [c]."
- a: quick, one-pan, slow-cooked. b: chickpeas, salmon, mushrooms. c: two, a crowd, lunchboxes.
- Prompt sent to the composer: "Something [a] with [b] for [c]", for example "Something quick
  with chickpeas for two".
- Buttons: "Write it", "Describe it my own way".

**Token map:** `--color-neutral-700` text is `text-text-tertiary`; accent-700 is
`text-accent-700`. Light only: no `dark:` classes. 44px targets. Lucide icons at stroke 2.75.

Values to copy (the design's 60px top includes the status bar):

- Page: `relative`, flex column, fills the space above the nav, padding `0 24px 24px`,
  `overflow-hidden` (it clips the circle).
- Decorative circle: `absolute`, `right: -90px; top: -60px`, 260px, `rounded-full
  bg-accent-2-200`, `aria-hidden`.
- Hint: `relative`, padding-top 24px, 13px `text-text-tertiary`, with an id.
- Sentence: an `h1`, `relative`, margin-top 30px, `font-heading` 36px, line-height 1.25. Each
  word is a `<button>` with `font: inherit`, no background or padding, `text-accent-700`,
  `underline decoration-[3px] underline-offset-[6px]`, a visible focus ring, accessible name
  the word itself and `aria-describedby` the hint. A visually hidden `aria-live="polite"`
  element holds the whole sentence, so the new word is announced after a tap.
- Spacer `flex-1`.
- Actions: `relative`, column, gap 8px. The primary `Button` full width, 56px, 16px, gap 8px,
  `Sparkles`, "Write it". A ghost `Button` 44px, 14px, "Describe it my own way", to `/search`
  (RL-124), which focuses its input.

## Out of scope

The Avoid, Cuisine and Equipment chips and the longer sentence of the 6c option canvas. More
than three options per word, or user-entered words. Remembering the last selection.
Auto-sending the prompt. Any change to `RecipeChatPage` or the chat restyle (RL-111).

## Verification

`npm test`, `npm run lint`, `npm run build`; `ui-reviewer` (the inline word buttons as 44px
targets at 36px type, focus ring, live region).

Human, on the preview at 390x844 and 320px:

- The Create tab opens the sentence; the nav shows Create active.
- Tap each word through all three options; the sentence wraps cleanly at 320px.
- Write it opens the chat with "Something one-pan with salmon for a crowd" (or whatever was
  picked) in the composer, unsent; as a verified user, send it and a recipe comes back.
- Describe it my own way opens Search with the keyboard up.
- VoiceOver: each word reads as a button with the hint; after a tap the new sentence is
  announced.
