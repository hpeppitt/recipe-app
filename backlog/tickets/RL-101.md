## Context

The author picked 17a ("Sentence strip, collapses when deep"). Spec
(`docs/design/organic/export/App Spec.dc.html`, Branch recipe): "sage lineage strip (17a)
replaces the description", "Breadcrumb: Root and parent always shown; deeper paths collapse to
"+N". Each crumb navigates. "See what changed" opens the diff vs parent." Markup: 17a in
`Recipe Parts and System.dc.html` and the `isBranch` block of `App Prototype.dc.html`.

Today, for `recipe.depth > 0`, `RecipeDetailPage` renders `LineageBreadcrumb` (ancestors as
small links), a "Prompt:" box and a "See what changed" link to `/recipe/:id/changes` (RL-074).
`collapseLineage(ancestors, expanded)` comes from RL-087. Ancestors come from
`useRecipeLineage(recipe)` (root first, parent last). The parent's author is
`ancestors[last].createdBy.displayName`.

**Design token map:** ramps keep their names; `--color-bg` is `bg-surface`;
`--color-text` is `text-text-primary`. Light only: no `dark:` classes. 44px targets.

Values to copy:

- Strip: margin-top 14px, padding `12px 16px`, `rounded-[22px]`, `bg-accent-2-100`,
  `text-accent-2-900`, 14px, column, gap 8px. It sits under the title and family label
  (RL-100), padding `0 22px` from the page edge.
- Crumbs row: `nav` named "Recipe lineage", flex wrap, align centre, gap 4px, 600. The root
  crumb is "<root emoji> <root title>"; other crumbs are the title. Each crumb is a link to
  `/recipe/:id` truncated to 18 characters with an ellipsis (full title in `title` and the
  accessible name). Separators are `ChevronRight` icons, `aria-hidden`. A collapsed middle
  is a button "+N" with `padding: 0 8px`, `rounded-full`, `bg-accent-2-200`, accessible name
  "Show N more", which expands inline. The current recipe ends the row in 400 weight,
  truncated at 200px, with `aria-current="page"`. Crumb hit areas are 44px tall without
  changing the visual line height (padding plus negative margin, or an overlaid hit area).
- Sentence: "<b>author</b> asked for <i>"prompt"</i> on <parent author>'s
  <b>parent title</b>." The author name is a link to their profile. Missing names read
  "Someone". If the prompt is empty, the sentence is "Branched from <b>parent title</b>."
- Button: "See what changed", `align-self: flex-start`, height 34px (44px hit area),
  padding `0 14px`, `rounded-full`, `bg-surface`, `text-text-primary`, 13px 600, gap 6px,
  `Diff` icon, to `/recipe/:id/changes` as today.
- Not rendered on an original.
