## Context

RL-067's shell lists available views; this ticket appends Map. Positions come from
`layoutRadial` (RL-071); the ancestry path from `ancestorChain` (RL-067). The design says
the map is best up to about 20 versions and asks for a defined fallback; this ticket picks
the cheapest one that keeps the map honest: above 20 versions, a notice suggests the
Timeline, and full-screen mode gives room to pan.

Design 3c, to copy:

- SVG. Dashed rings per generation: 1.5px `neutral-400`, dash 4 6. Edges 3px `neutral-400`,
  the ancestry path edges 5px `primary-500` (accent).
- Nodes: 40px circles showing the emoji on `surface-secondary` with a 2px `border-strong`
  outline. The root is a dark fill (`text-primary` colour, `#201e1d`) with its emoji. The
  current node has a 3px accent ring at 3px offset. Path nodes have accent outlines.
- Selection: tapping a node selects it (default selection: the current recipe). A card
  pinned under the map (`bg-surface-secondary rounded-card shadow-md`, padding 13px):
  eyebrow `Generation <n> · by <author>` (13px uppercase 0.08em, `text-text-tertiary`;
  author fallback "Anonymous"; generation 0 reads "The original · by <author>"), the title
  in `font-heading` 20px, and a primary "Open" button to `/recipe/:id`.
- An expand button (44px round, top right of the map, accessible name "Full screen map")
  opens the map in a full-screen `<dialog>` at twice the scale inside an `overflow-auto`
  container so the user pans by scrolling, with a Close button (accessible name "Close
  map"). Escape closes it.

## Notes

Groomed 2026-10-18. The fallback choice (notice plus full-screen pan, rather than pinch
zoom) is a reversible grooming decision; log it in `backlog/DECISIONS.md` when shipped.

Implemented 2026-10-18. The over-20 fallback is logged in `backlog/DECISIONS.md`. Hit targets are
44px HTML buttons over the SVG in generation order; where a crowded ring puts neighbours closer
than 44px the deeper node wins the overlap, and the notice is the answer to crowding. Contrast
(computed): path terracotta on the page 3.03:1, on node discs 2.69:1 (lowest for a path mark, so
the path edge is also thicker and the current node keeps its ring); neutral-400 edges and rings
1.68:1; node outline on disc 1.50:1; eyebrow text-tertiary on the card 4.92:1; focus outline
primary-600 on the page 5.72:1. Selected non-current nodes get a dark ring so selection differs
from the terracotta current ring. Outer-ring nodes render about 22px at 320px width because the
SVG is scaled to fit; full screen restores them to twice the viewBox scale.

Review fixes: the notice also fires at 5 generations (max generation 4) because at 288px a generation-4
node is 17.6px (40 * 288 / 656) with an emoji under 9px, while generation 3 is 22px. Inline width is capped
at 1.5x the viewBox. Full screen centres the selected node. Rings paint first, then edges. `cn` is a plain
join, so `border-border-strong` could lose to `border-border`; the secondary buttons here and in
TimelineView now use `border-border-strong!` (Tailwind v4 important), checked in the built CSS. The expand
button is first in DOM order.
