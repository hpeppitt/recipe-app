## Context

RL-067's shell lists available views; this ticket appends Map. Positions come from
`layoutRadial` (RL-071); the ancestry path from `ancestorChain` (RL-067). The design says
the map is best up to about 20 versions and asks for a defined fallback; this ticket picks
the cheapest one that keeps the map honest: above 20 versions, a notice suggests the
Timeline, and full-screen mode gives room to pan.

Design 3c, to copy:

- SVG. Dashed rings per generation: 1.5px `neutral-400`, dash 4 6. Edges 3px `neutral-400`,
  the ancestry path edges 5px `primary-500` (accent).
- Nodes: 40px circles showing the emoji on `surface-secondary` with a 2px `border-strong`
  outline. The root is a dark fill (`text-primary` colour, `#201e1d`) with its emoji. The
  current node has a 3px accent ring at 3px offset. Path nodes have accent outlines.
- Selection: tapping a node selects it (default selection: the current recipe). A card
  pinned under the map (`bg-surface-secondary rounded-card shadow-md`, padding 13px):
  eyebrow `Generation <n> · by <author>` (13px uppercase 0.08em, `text-text-tertiary`;
  author fallback "Anonymous"; generation 0 reads "The original · by <author>"), the title
  in `font-heading` 20px, and a primary "Open" button to `/recipe/:id`.
- An expand button (44px round, top right of the map, accessible name "Full screen map")
  opens the map in a full-screen `<dialog>` at twice the scale inside an `overflow-auto`
  container so the user pans by scrolling, with a Close button (accessible name "Close
  map"). Escape closes it.

## Acceptance criteria

- [ ] `src/components/tree/MapView.tsx` renders per Context; `VersionTreePage` adds `map` to its view list (order Tree, Timeline, Map), so `?view=map` shows it.
- [ ] Each node is a focusable button with an accessible name `"<title>, generation <n>"`, plus "current version" for the current one; Enter, Space or a tap selects it and updates the card; the card's Open navigates.
- [ ] The map fits the content width at 320 to 512 px (SVG `viewBox` from `size`, width 100%).
- [ ] Above 20 versions, a notice above the map reads "This family is big for the map. The timeline reads better." with a secondary button "Show timeline" that sets `?view=timeline` (same `replace` behaviour as the switch). The map still renders below it.
- [ ] Full-screen mode as in Context; focus moves into the dialog and returns to the expand button on close.
- [ ] `src/components/tree/MapView.test.tsx` covers: root-only family; path edges carry the path styling (assert a `data-path` attribute); default selection is the current recipe; selecting another node updates the card; generation 0 card copy; the over-20 notice and its button; full-screen open and close.
- [ ] `docs/capabilities.md` "Version tree view" row mentions the Map view and its over-20 fallback.
- [ ] A `backlog/QA.md` entry: on families of 1, about 8 and over 20 versions, open `?view=map`, check rings, the terracotta path to the ringed current node, selecting nodes updates the card, Open works, the notice appears above 20 and its button switches to Timeline, full screen pans by scrolling and closes with Escape and the button. At 390 and 320 px.
